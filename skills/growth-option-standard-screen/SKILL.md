# 个人成长选题筛选与标准池

## R — 原文 (Reading)

> "没有筛选，就谈不上选择。"
>
> — 粥左罗，第一章 第一节 筛选思维

## I — 方法论骨架 (Interpretation)

这个方法把"选择"前置为一个筛选系统。  
不要在只有一个选项时就问"要不要";先扩大备选池，再写最低准入线和淘汰标准。  
对学习、职业、合作、课程、创业项目等成长选题，真正的判断不是哪个看起来诱人，而是哪一个经得起标准和比较。  
越重要的选择，越要投入信息搜集、样例比较、试用和反证。  
完成后应得到一个排序表：保留项、淘汰项、待补证据项，而不是一个情绪化答案。

## A1 — 书中的应用 (Past Application)

### 案例 1: 随意选择反成最糟选择
- **问题**: 个人面对职业、学习或机会选择时，常说"没得选"，实际只是没有筛选。
- **方法论的使用**: 作者要求先培养筛选意识，凡事提高标准，把备选和淘汰标准摆出来。
- **结论**: 没有筛选的"默认接受"也是选择，而且往往是低质量选择。
- **结果**: 选择从被动接受变成主动经营，为后续赛点机会判断提供前提。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 想报课、买服务、加入项目或合作，但只有一个广告页/熟人推荐。
2. 职业方向、学习方向、副业方向太多或太少，无法判断先做哪个。
3. 机会看起来都不错，但没有准入线、淘汰线和证据标准。
4. 想避免因焦虑、从众或限时优惠做成长决策。

### 语言信号

- "这个课/项目/合作要不要接?"
- "我只有这一个选择，看起来还不错"
- "怎么筛选成长机会 / screen options?"
- "我怕错过，但也怕踩坑"

### 与相邻 skill 的区分

- `advisor-source-quadrant-audit` 审计顾问、课程、老师和商业教育的来源可信度；本 skill 先建立成长选项池和淘汰标准。
- `asymmetric-opportunity-sprint` 用于已经筛出关键机会后的集中投入；本 skill 用于还没确认机会质量之前。

## E — 可执行步骤 (Execution)

1. **建立选项池**
   - 写出至少 3 个备选；不足 3 个时先补信息，不急着决策。
   - 完成标准: 每个备选都有来源、成本、承诺、预期产出和验证方式。

2. **设准入线和淘汰线**
   - 准入线包括: 真实案例、反馈机制、可交付作业、时间/金钱成本、失败损失。
   - 判停条件: 若唯一理由是焦虑、限时、关系压力或身份包装，先停止购买/承诺。
   - 完成标准: 每个选项被标记为保留、淘汰或待补证据。

3. **做小额验证**
   - 对保留项设计最小试用: 试听、访谈、样例任务、一次合作或公开作品检查。
   - 完成标准: 选择结果包含下一步、投入上限、复核日期和退出条件。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 已经确定项目，只需要拆执行计划时，转项目规划或任务拆解。
- 涉及高金额投资、法律合同、医疗教育等高风险事项时，本 skill 只能做前置筛选，不能替代专业尽调。
- 用户已经被欺诈、威胁或强制交易时，不继续做"选项比较"，先安全退出和留痕。

### 作者在书中警告的失败模式

- 不设标准、不做备选比较，让默认选项或眼前诱惑替自己决策。

### 作者的盲点 / 时代局限

- 本书强依赖新媒体和个人成长市场语境，不能把收入跃迁承诺当成普遍证据。
- 作者成功路径有幸存者偏差，筛选时必须加入失败样本和当前市场条件。

### 容易混淆的邻近方法论

- 与赛点冲刺不同: 筛选解决"选不选"，赛点解决"已经选中后投多少"。
- 与顾问审计不同: 顾问审计更关心老师/机构可信度，本 skill 更关心个人成长选项组合。
