# 文化历史与非遗 DNA

## 适用场景

适合历史文化、非遗、传统、艺术、书院、文物，重在讲清文化如何重新进入当下生活。

## 结构指标

- 训练样本：0
- 每千字段落数：0.0
- 段落中位字数：0.0
- 20 字以内短段比例：0.0
- 连续短段 run 中位：0.0
- 图片数中位：0.0
- 常见推进链：现象开场 -> 材料铺陈 -> 判断收束

## 写稿方式

1. 先让一个物件、技艺、地方或记忆进入当下生活。
2. 解释传承逻辑：谁在做、怎么做、为何还能被今天的人需要。

## 反例

- 不要写成百科词条。
- 不要只堆历史名词。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
