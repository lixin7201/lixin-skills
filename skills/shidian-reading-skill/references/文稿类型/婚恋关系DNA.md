# 婚恋关系 DNA

- **适用场景**：夫妻相处、爱情保鲜、家务与情绪劳动、婆媳边界、伴侣责任与沟通方式。
- **标题 DNA**：抓人的家庭现场/原话加冒号后的婚姻判断；“新型 X 正在流行”加三方收益；“夫妻是否 X，看这 1 个地方”。标题可以尖锐，正文必须回到关系机制。
- **开头 DNA**：一段可视化家庭冲突或网友吐槽，迅速补上评论区共鸣，再提出“为什么会这样”。虽然统计偏引用开路，深读高互动样本更显示“生活冲突开路”有强吸引力。
- **推进链**：冲突现场 → 多方声音 → 结构/身份机制 → 错位责任 → 正向夫妻案例 → 2—4 条沟通或边界动作 → 降期待/共同经营。
- **材料偏好**：网友帖子、夫妻对话、家庭细节、综艺、关系研究、身边故事。对话要承担人物立场，不能只当热闹。
- **段落节奏**：句长中位 22 字，为 11 类最短；适合高密度对白、单句反转、短段判断。长理论段要拆开，并用生活细节缓冲。
- **情绪温度**：8/10 起步，5—6/10 收尾。前段允许有怨气和代入，中后段必须降温，区分结构问题、责任问题与个体恶意。
- **结尾 DNA**：把责任落到双方可做的动作，或明确距离/边界；常有留言问题，让读者交换经验。
- **事实核查**：离婚比例、心理学研究、名人婚姻、网络“神贴”真实性需核查；匿名故事不能伪装成调查。避免性别本质主义、羞辱婆婆/儿媳、把一方贴成“妈宝”“恶妇”后停止分析。
- **像 / 不像警告**：像的是先替读者说出委屈，再把冲突翻译成角色、边界和反馈机制；不像煽动性别对立，或把“女人应该怎么做”写成唯一答案。
- **深读样本与置信度**：`2a5fde7b300a4ec5`《“新型婆媳关系”正在流行：婆婆不受气，儿媳不委屈，老公不为难》、`f7140685baa34f13`《“凌晨2点，婆婆偷摸进儿子卧室，我怒了”：婚姻好不好，看婆婆就知道》、`5b4f5439a93ecae7`《夫妻是不是真的恩爱，看这1个地方，一目了然》、`e288be9a9589a28d`《“女人，永远别把老公当亲人，无论你爱得有多深！”》。**置信度：高**；冲突开场、机制解释、动作收尾高度一致。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
