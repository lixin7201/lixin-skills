# 良性债务不良债务筛选

## R — 原文 (Reading)

> 良性债务就是有人为你还钱，不良债务就是你要付出你的血汗努力还钱。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸致富需要做的6件事》第4件事

## I — 方法论骨架 (Interpretation)

这个方法不按债务名称判断好坏，而按谁偿还、现金流从哪里来、最坏情况下谁承担来判断。
良性债务必须由可验证资产现金流覆盖，并且在压力情境下不拖垮个人系统。
不良债务通常由未来劳动收入偿还，用来购买消费、面子或无法产生现金流的东西。
所有债务都需要敬畏；书中把债务比作上膛的枪，意味着即使候选良性也要设停止线。

## A1 — 书中的应用 (Past Application)

### 案例 1: 用资产现金流购买保时捷
- **问题**: 作者想购买昂贵汽车，但直接贷款会形成消费负债。
- **方法论的使用**: 他先寻找能产生现金流的资产，让资产收益支付车贷。
- **结论**: 消费欲望不必道德化压制，但购买顺序必须改变。
- **结果**: 案例被用来说明资产支付负债，而非工资支付负债。
### 案例 2: 良性债务变成不良债务
- **问题**: 项目或债务一旦现金流失控，原本的投资债务会落回个人劳动偿还。
- **方法论的使用**: 作者反思错误，强调债务必须被持续监控。
- **结论**: 良性债务不是永久标签，而是现金流状态。
- **结果**: 债务 skill 必须包含压力测试和止损。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想判断某笔贷款、分期、融资是不是良性债务。
2. 用户准备用债务买资产、设备、课程、房产或创业资源。
3. 用户混淆低利率、抵押、长期贷款和良性债务。

### 语言信号 (用户的话里出现这些就应激活)

- "这是良性债务吗"
- "贷款买这个值不值"
- "谁来还钱"
- "杠杆风险"
- "分期会不会拖垮我"

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **写债务条款**
   - 操作: 列本金、利率、期限、月供、抵押、违约后果和总成本。
   - 完成标准: 条款不是凭感觉。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **找还款现金流**
   - 操作: 说明谁还钱、钱从哪个资产或业务来、是否已发生。
   - 完成标准: 还款来源可验证。
 3. **做压力测试**
   - 操作: 模拟收入下降、空置、延期、利率变化、客户流失和退出失败。
   - 完成标准: 最坏情形不致命或有止损。
 4. **分类与动作**
   - 操作: 可覆盖且可控为候选良性；无法覆盖或靠工资硬扛为不良或暂停。
   - 完成标准: 给出借/不借/缩小规模/先验证结论。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要具体贷款产品、利率预测、税务优化方案。
- 用户想用借新还旧掩盖消费债而不改变支出模式。

### 作者在书中警告的失败模式

- 把低利率、长期、抵押贷款直接等同良性债务。
- 忽略空置、违约、维护、利率变化和流动性断裂。

### 作者的盲点 / 时代局限

- 债务、房地产和融资强依赖本地法律、利率和个人信用。
- 作者较推崇杠杆，但普通人必须更重视最大损失和家庭责任。

### 容易混淆的邻近方法论

- 与 `bad-debt-rolldown-plan` 的区别: 本 skill 做借债前或债务性质筛选；后者处理已形成的不良债务清理顺序。
- 与 `control-prior-leverage-check` 的区别: 本 skill 以债务现金流为核心；后者检查更广义的杠杆控制权。
