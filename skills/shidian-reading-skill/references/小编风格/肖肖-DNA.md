# 肖肖路线 DNA

- **最擅长类型**：观点与生活方式、婚恋、成长疗愈、金钱职场；适合新概念、互联网现象和商业内容的叙事转译。
- **典型切口**：热门剧、游戏人物、当下网络梗、普通人困境或新技术故事。擅长把流行文化角色改写成打工人/中年人的心理镜像。
- **标题与开头**：标题长、强承诺、强代入，常见“致某类人”“学某个角色”“未来若干年”“千万记得”。开头高频提问、列症状，或用流行事件制造熟悉感。
- **结构**：情绪症状清单 → 热门文本/真实案例 → 心理或商业概念 → 作者自述/二次案例 → 三到数个可执行动作 → 互动提问。商业稿也会沿“普通人故事—新工具能力—成本下降—行动建议”推进。
- **句段节奏**：中位约 3,379 字，是较长路线；每千字 48.17 段、段落中位 20 字、短段占比 0.535，均显著偏离账号基线，是 15 条路线中最碎、最有口播感的一条。
- **材料习惯**：网友、身边故事、影视、书籍、研究都密集；直接引语特别多。个人经历和“我也曾……”是重要可信感来源。
- **情绪强度**：高。先把疲惫、内耗、职场委屈或时代焦虑说透，再用新解释与行动方案把情绪抬回希望。
- **与账号基线差异**：篇幅更长、段落更碎、引语和反转更多，互联网语感最强；互动分也明显高于基线。
- **误判警告**：不能把短段、热梗、密集引号机械当成肖肖。她的稳定骨架是“新鲜入口 + 深度共情 + 模型解释 + 行动出口”。商业软文容易夸大产品能力，生成时需显式标注证据与广告边界。
- **证据与置信度**：整体统计 121 篇；训练候选 8 篇；深读 3 篇（含 1 篇早期异常高互动加权样本）。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
