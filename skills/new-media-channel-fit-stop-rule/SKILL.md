# 新媒体渠道适配与停止条件审计

## R — 原文 (Reading)

> 依据品牌调性、产品属性选择合适的传播渠道。前期可以多尝试几个平台，同步数据监测3-6个月没效果的建议停掉。
>
> — 《分章节P3-05 新媒体运营模型》Slide 21

> 这个模型帮助企业根据自身的特定需求、目标受众、资源状况等因素，挑选最适合的品牌传播渠道。
>
> — 《分章节P3-05 新媒体运营模型》Slide 11

## I — 方法论骨架 (Interpretation)

新媒体渠道选择不是“哪个平台热门就去哪”，而是匹配品牌调性、产品属性、用户属性、内容供给、转化路径和团队资源。平台只是触点，真正要验证的是用户是否在那里、内容是否适配、团队是否供得上、转化是否能承接。

这个 skill 的核心是把渠道当作实验，而不是承诺。进入前写清假设、指标、预算、人效和停止线；运行中持续监测；3-6 个月仍无有效信号且无法归因，就停、改或迁移。

它不提供小红书、抖音、京东等具体平台旧打法；涉及平台规则和广告产品时，要调用平台时效审计并做当前核验。

## A1 — 书中的应用 (Past Application)

### 案例 1: 不同平台营销选择

- **问题**: 企业面对微信、微博、抖音、快手、B站、小红书等平台，不知道如何选择。
- **方法论的使用**: PPT 按平台特征、用户群体、流量特点、机会品类和营销形式比较平台。
- **结论**: 渠道要依据目标受众、资源状况和品牌传播目标选择。
- **结果**: 选择从“全平台都做”变成“按用户、内容和转化目标试验”。

### 案例 2: 渠道建设停止条件

- **问题**: 品牌同时尝试多个渠道，消耗大量人效。
- **方法论的使用**: PPT 建议依据品牌调性、产品属性选择渠道，前期多尝试，同步数据监测，3-6 个月没效果建议停掉。
- **结论**: 渠道必须有观察周期和退出机制。
- **结果**: 好渠道加大内容生产投放，无效渠道停止，避免长期消耗。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户想做多个平台，但资源有限，不知道先选哪个。
2. 某个平台做了几个月没结果，不知道是继续、调整还是停掉。
3. 新品牌、新账号、新产品要选择内容渠道或传播渠道。
4. 用户把平台选择和品牌定位、产品属性、内容供给、转化承接混在一起。

### 语言信号

- “小红书/抖音/公众号我该做哪个？”
- “几个平台都想做，但人手不够”
- “做了 3 个月没效果要不要停？”
- “channel fit / platform selection / stop rule”

### 与相邻 skill 的区分

- 与 `platform-playbook-currentness-audit` 的区别: 本 skill 选择渠道和设停止线；平台 skill 核验某个平台玩法、规则和广告产品是否当前有效。
- 与 `content-library-minimum-structure-builder` 的区别: 本 skill 看去哪里发布；内容库 skill 看有没有可持续内容供给。
- 与 `private-domain-fit-boundary-audit` 的区别: 本 skill 选择传播渠道；私域 skill 检查是否适合反复触达和如何守边界。

## E — 可执行步骤 (Execution)

1. **写渠道假设**
   - 完成标准: 对每个候选渠道写清目标用户、使用场景、内容形式、转化路径和主要风险。

2. **检查适配度**
   - 完成标准: 用品牌调性、产品属性、用户属性、内容供给、预算、人效、承接能力给渠道做证据评分。
   - 判停条件: 平台具体规则、广告权限、行业合规或算法机制未核验时，不给操作细节。

3. **选 1 个主渠道 + 1 个备选**
   - 完成标准: 明确本周期只押一个主渠道，备选渠道只做低成本观察。

4. **设置 3-6 个月停止线**
   - 完成标准: 写清周期、预算、人效、内容产量、核心指标、护栏指标和停止条件。

5. **运行中复盘归因**
   - 完成标准: 每月判断问题在定位、内容、渠道、平台规则、承接、产品体验还是预算不足。

6. **决定保留/调整/停止**
   - 完成标准: 输出一个决策：加码、改内容、换承接、换渠道、暂停或退出，并说明证据。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户要求具体平台算法、投放后台、广告政策、达人合作规则，应先转 `platform-playbook-currentness-audit` 并当前核验。
- 用户完全没有内容供给，应先转 `content-library-minimum-structure-builder`。
- 用户想通过过度打扰、误导宣传或未经授权数据追踪提高转化。

### 作者在资料中的失败模式提示

- 渠道没有效果要停，否则会消耗多余人效。
- 不同平台的用户群体、流量特点和营销形式不同，不能同一套内容全平台复制。

### 作者的盲点 / 时代局限

- PPT 中列举的平台特征和机会品类会随平台政策、用户结构、广告产品和内容生态变化；实际使用必须核验当前事实。
- 3-6 个月是经验窗口，不同业务周期、客单价和转化链路需要调整。

### 容易混淆的邻近方法论

- 渠道停止不是否定品牌，可能只是平台-内容-用户不匹配。
- 全域营销不是成熟标志，小团队没有预算、人效和承接时全域会稀释质量。
