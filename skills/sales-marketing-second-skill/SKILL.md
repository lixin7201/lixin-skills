# 销售市场第二技能

## R — 原文 (Reading)

> 上面写的是畅销书作家，而不是最好的作家。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸穷爸爸》第7章

## I — 方法论骨架 (Interpretation)

作者用“畅销书不是最佳书”提醒: 好作品和市场结果之间隔着第二技能。
这个第二技能包括理解需求、表达价值、讲清问题、建立信任、设计分发和获得反馈。
它适用于写作、咨询、技术、课程、产品和内部提案，不只适用于卖货。
边界是不得用虚假承诺、压力销售或关系消耗来换短期成交。

## A1 — 书中的应用 (Past Application)

### 案例 1: 畅销书作家的反问
- **问题**: 有人强调自己写得比畅销书作者更好，却没有市场结果。
- **方法论的使用**: 作者指出榜单衡量的是销售，不是文学水平。
- **结论**: 专业能力需要销售和市场能力才能被看见。
- **结果**: 写作者应补分发、定位、标题、渠道和成交能力。
### 案例 2: 施乐销售训练
- **问题**: 作者意识到害怕被拒绝会限制收入和创业。
- **方法论的使用**: 他进入销售训练环境，练习表达、拒绝承受和成交。
- **结论**: 销售是可训练技能，不是天生性格。
- **结果**: 销售能力支撑了后续创业、教学和书籍传播。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有内容或产品但没人买、没人看、没人转化。
2. 用户要把专业能力转成提案、课程、文章、咨询或产品。
3. 用户害怕销售、推广、报价、被拒绝。

### 语言信号 (用户的话里出现这些就应激活)

- "卖不出去"
- "不会推广"
- "写作怎么变现"
- "没人买"
- "怎么做提案"
- "我怕销售"

### 与相邻 skill 的区分

- 与 `work-to-learn-skill-stack` 的区别: 本 skill 已锁定销售/市场短板，直接做分发和成交设计。
- 与 `business-education-due-diligence` 的区别: 本 skill 训练自己的销售能力；后者审计外部销售/商业训练系统。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **定义购买者**
   - 操作: 写出谁会付费、为什么现在需要、替代方案是什么。
   - 完成标准: 受众不是泛泛的人。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **翻译价值**
   - 操作: 把专业特性改写成用户问题、结果、证据和风险降低。
   - 完成标准: 表达从自我介绍变成对方收益。
 3. **设计分发**
   - 操作: 选择 1-2 个渠道、一个测试话题、一个行动按钮。
   - 完成标准: 有可执行的发布或提案动作。
 4. **收反馈**
   - 操作: 记录曝光、咨询、回复、成交、拒绝理由并复盘。
   - 完成标准: 销售失败变成下一轮素材。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要求夸大收益、隐瞒风险、制造焦虑或操纵成交。
- 产品本身没有真实价值或还没有最小验证时；先做问题验证。

### 作者在书中警告的失败模式

- 只追求作品质量，逃避标题、渠道、报价和成交。
- 把销售理解为骚扰别人，或者反过来用压力销售透支信任。

### 作者的盲点 / 时代局限

- 作者强调销售，容易被误读成结果至上；这里必须以真实价值和长期信任为前提。
- 市场反馈受时机、渠道和品牌积累影响，不能用一次发布判定能力。

### 容易混淆的邻近方法论

- 与 `work-to-learn-skill-stack` 的区别: 本 skill 已锁定销售/市场短板，直接做分发和成交设计。
- 与 `business-education-due-diligence` 的区别: 本 skill 训练自己的销售能力；后者审计外部销售/商业训练系统。
