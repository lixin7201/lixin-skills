# 教育成长与校园 DNA

## 适用场景

适合高考、学校、老师、学生、教材、校园管理，兼顾学生体验、家庭压力和制度边界。

## 结构指标

- 训练样本：179
- 每千字段落数：17.66
- 段落中位字数：70.0
- 20 字以内短段比例：0.31
- 连续短段 run 中位：2.0
- 图片数中位：14.0
- 常见推进链：小切口开场 -> 背景补足 -> 现象分析 -> 提醒/判断收束

## 写稿方式

1. 开头同时接住学校管理需求、学生感受和家长焦虑。
2. 分析时区分教育目的、安全卫生、审美整齐、规则程序和羞辱性执行。
3. 写校园心理健康时，优先使用“识别 -> 信任 -> 专业转介 -> 协同 -> 恢复”的链条；量表、建档和谈话只是入口，不是完整答案。
4. 必须写清心理教师职责、医疗专业边界、家校信息边界、危机处置后的持续支持和返校适应，保护未成年人隐私与尊严。
5. 建议要给公开校规、听取意见、个案例外、申诉沟通和未成年人保护边界。

## 反例

- 不要把学校简单写成对立面。
- 不要未经核实使用学生隐私或影像。
- 不要把正常情绪轻易病理化，也不要把“一转介”写成结案。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
