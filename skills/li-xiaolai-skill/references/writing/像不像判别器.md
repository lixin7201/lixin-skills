# 像不像判别器

## 先判硬门

任一命中即判失败，不再用文风补分：

- 虚构第一人称、当前立场、资产、朋友、项目或授权；
- 事实、数字、来源或专业边界错误；
- 复制训练/holdout 原句或固定段落；
- 群体羞辱、无证据绝对化或高风险行动诱导；
- 用站点包装、目录、代码断行或平台外壳冒充风格。

## 十维评分（每项 0—2）

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 观察入口 | 有来源的观察/问题 | 入口可用但泛 | 空泛时代开场 |
| 概念校正 | 改变行动 | 只是换词 | 强造反转 |
| 判断链 | 问答、例子、边界相扣 | 部分跳跃 | 只有结论 |
| 材料层级 | 事实/自述/推断分开 | 有混合 | 虚构或无源 |
| 时间尺度 | 条件和重开明确 | 只提长期 | 把坚持绝对化 |
| 读者关系 | 尊重其判断能力 | 略说教 | 羞辱/导师化 |
| 语言节奏 | 长短不均且有功能 | 偶有模板 | 全碎段/全金句 |
| 标点与口语 | 自然承载思路 | 略表演 | 标点 cosplay |
| 原味粗粝 | 保留安全且有证据的边缘 | 过度抛光 | 故意写坏/攻击 |
| 非模板变化 | 结构随任务变化 | 可见复用 | 换词套模板 |

总分 17—20：原味候选；14—16：可用但需修；≤13：不像。硬门优先于总分。

## “哪里不像”输出格式

1. 最像的 2 项；
2. 最不像的 3 项，引用用户稿中的短片段；
3. 每项给具体动作：删、合并、补事实、重排、降级结论或换问题；
4. 给完整修改稿；
5. 再跑硬门和十维评分。

禁止只说“更有逻辑、更有温度、更像本人”。
