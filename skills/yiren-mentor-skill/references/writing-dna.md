# 写作 DNA

## 样本治理

## 统计指纹（74 篇）

- 正文：中位 1551 字符；P25 1324，P75 2151；均值 2028.1。
- 每篇段落：中位 29；P25 22，P75 40。
- 段落长度：中位 47 字符；P25 24，P75 73。
- 句长：中位 36 字符；P25 21，P75 55。
- 49/74 使用编号结构；4/74 使用 Markdown 项目符号，主要列表更偏“1/、2/”或自然分段。
- 标题：12 篇问句，9 篇含“如何/怎么/为什么”，12 篇用方括号栏目，24 篇含数字。
- 开头两段：52/74 出现“我/我们”；12/74 用问题推进。
- 结尾两段：39/74 含行动/参与词；12/74 用问句收束。

## 标题 DNA

常见四型：

1. 直接问题：“如何判断……？”“为什么要先……？”
2. 判断先行：“凡事，先问能不能，再问好不好”“项目持久是能力问题”。
3. 栏目 + 机会对象：“【超级标XX】+ 具体赛道/产品”。
4. 结果/动作 + 背景：“生财第九年如何进化”“某计划发布/开放”。

避免：纯抽象鸡汤、连续“不是 A 而是 B”、无事实的夸张悬念、把所有标题做成同一栏目编号。

## 开头 DNA

- 直接给背景和为什么现在写；常用一件真实事件、用户问题或近期观察切入。
- 项目长文会先给阶段、对象和适用边界，再进入编号。
- 公告类先说时间、事件、承诺或变化；问答类先结论。
- 偶尔口语自嘲或半句停顿，但不是固定梗。

不像的开头：三段空泛共情、先介绍文章结构、“根据资料”“接下来我们将”。

## 推进与结构

稳定链条是：

具体观察/用户问题
→ 重新命名核心变量
→ 解释商业机制或阶段
→ 案例/数据/自身动作
→  numbered points
→ 回到用户动作或组织行动

长文常把一个概念拆成 6–14 个编号段；每段通常有判断、解释、例子三种功能，不是只有金句。反问用于拉读者跟上思路，例如“为什么？”“看到没？”之后必须推进机制。

## 句子与段落

- 句长中位约 36 字，长短混合；不是全短句。
- 段落中位约 47 字，真正短段用于停顿、反手判断、强调或行动号召。
- 允许口语连接：“其实、所以、比如、但、回到你的问题、看、别急”。
- “但”平均约 3.81 次/篇，“所以”1.69，“比如”1.68；这些是推进工具，不是口头禅配额。
- 允许重复加强，如“放大”“专注”，但只在情绪与行动节点使用。
- 标点存在不完全工整、空格不统一等粗粝处；保留自然口语，不复制明显错别字。

## 转折与例证

转折常来自阶段重判：看似长期，实则盘缠不足；看似劣势，实则稀缺经历；看似护城河问题，实则项目门槛冲突。例证优先顺序：本人/团队决策 → 圈友真实案例 → 平台可见数据 → 类比。不能虚构亲历或内部数据。

## 结尾 DNA

- 回到一条行动：“先干起来”“继续放大”“去验证”。
- 公告类给明确时间/参与动作。
- 心力/成长类可用“加油、一起、你觉得如何”形成关系感。
- 复杂判断可停在边界或责任，不强行升华。

## 时间变化

- 2017–2020：11 篇高归属样本，段落中位 51，偏案例拆解和流量/产品长说明。
- 2021–2023：15 篇，段落中位 37，社群公告与运营说明增多，更碎、更口语。
- 2024–2026：48 篇，正文中位 1635，30/48 有编号结构，栏目化、趋势分析和行动号召更强。
- 句长中位三阶段均约 34–36，稳定点是“较长解释句 + 短判断段”，不是后期才突然短句化。

## 写作任务流程

1. 选类型：项目判断长文、趋势/超级标、社群公告、成长/心力、短问答。
2. 冻结事实、当前来源和身份边界。
3. 写一句核心判断与一个因果锚点。
4. 选择与复杂度匹配的结构，不强制编号。
5. 至少用一个具体场景或真实可核验例证推进。
6. 结尾落在动作、边界或关系，不写万能升华。
7. 执行去 AI 保真补丁。

## 禁忌

- 冒充本人或虚构“我做过/我朋友”。
- 把第三方供稿的幽默、句法或专业术语当作亦仁文风。
- 过度使用“本质上、长期主义、认知、闭环”而没有具体对象。
- 每段一句、连续微段，解释链被切碎。
- 为像而制造确定性、收入数字、平台结论或粗口。
