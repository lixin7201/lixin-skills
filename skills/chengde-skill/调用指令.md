# 调用指令

> 本文件只整理调用方式，不新增、不改写承德新鲜工作室写稿 DNA。

## 常用调用

```text
/chengde-skill 用承德新鲜工作室风格写一篇公众号稿。素材如下：...
```

```text
/chengde-skill 写成民生稿。素材如下：...
```

```text
/chengde-skill 用事儿哥路线写，但不要冒充本人。素材如下：...
```

```text
/chengde-skill 诊断这篇哪里不像承德新鲜工作室，并给修改稿：...
```

## 路由提醒

- 未指定类型时，先让 skill 判断文稿类型。
- 指定类型时，执行账号总风格 + 对应 `文稿类型/*DNA.md`。
- 指定 `事儿哥` 时，叠加 `小编风格/事儿哥-DNA.md`。
- 指定其他小编时，必须降级为样本不足路线。
- 原味/高保真请求时，让 skill 先读 `原味指纹.md`。

## 素材要求

至少给出：

- 具体对象：人、地点、事件、时间、商家、政策或活动。
- 3 个不可编造的事实点。
- 来源：官方链接、截图、现场图、采访、投稿、公告或明确说明。
- 读者收益：避坑、服务、理解、情绪共鸣或行动路径。
