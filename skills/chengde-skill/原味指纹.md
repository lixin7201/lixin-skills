# 原味指纹

> 补齐说明：本文件只做原味读取清单和保护边界，不重新提炼承德新鲜工作室写稿 DNA。所有具体风格判断以既有 DNA 文件为准。

## 读取来源

- 账号指纹：`账号总风格.md`、`账号选题判断框架.md`、`账号语言底线.md`、`账号排版规范.md`
- 类型指纹：`文稿类型/*DNA.md`
- 稳定小编指纹：`小编风格/事儿哥-DNA.md`
- 样本不足边界：`小编风格/小编样本不足.md`
- 验证依据：`holdout-comparison-report.md`、`分类型评分.md`、`分小编评分.md`、`darwin-scorecard.md`

## 必须保留的原味层

1. 思考指纹：先问本地人群、事实锚点、读者收益，再决定是否成稿。
2. 写法指纹：本地事实和强判断并行，标题可有冲突和情绪，正文必须事实刹车。
3. 排版指纹：短段可用，但事实说明、城市对比、政策解释和现场叙述要合并为自然段。
4. 路由指纹：账号总风格先行，再叠加文稿类型；只有 `事儿哥` 满足稳定个人 DNA。
5. 事实指纹：没有来源的价格、时间、路线、官方回应、阅读量、采访和网友评论不能补。

## 假像风险

- 只把标题写猛，但正文没有承德本地事实。
- 把所有稿都写成评论观点。
- 用连续微段制造“像公众号”的错觉。
- 把样本不足小编写成稳定个人声纹。
- 为了“更顺”删掉账号真实的本地锋芒和事实刹车。

## 使用边界

原味请求时，本文件用于自检和保真，不覆盖 `账号总风格.md`、`文稿类型/*DNA.md` 或 `小编风格/事儿哥-DNA.md`。
