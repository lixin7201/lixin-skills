## I — 方法论骨架 (Interpretation)

战略模型不是一组可以同时套用的模板，而是一组选问题的工具。3C 适合看顾客、竞争者和自身；PEST 适合看宏观环境；SWOT 适合把内外部信息合成优劣势；五力适合判断行业竞争压力；BCG/GE 适合产品或业务组合；安索夫适合增长路径；价值链适合拆业务活动和附加价值。

真正的风险不是“不知道模型名”，而是模型格子里没有证据。每个模型都必须有对应的事实门：数据来源、时间、样本、口径、竞品证据、客户证据、成本证据和不确定性。

第十三批补进三条硬规则：PEST 必须核验当前政策、经济、社会和技术变量；SWOT 必须先明确目标、区分内外部因素，并按影响程度排序；五力的“压力强/弱”只是结果标签，必须追到供应集中度、买方集中度、进入壁垒、替代价值、行业利润等结构原因。

第十四批补进组合矩阵规则：BCG/GE 不能只照模板分明星、金牛、问题、瘦狗或九宫格。市场增长率、相对份额、行业吸引力、经营实力、权重、标准线、业务历史轨迹和风险变量都要有来源；标准线来自模板或经验时，只能作为假设，不能直接决定裁撤或投资。

这个 skill 的输出不是完整战略方案，而是“当前问题应该用哪个模型、需要哪些证据、证据不足时先做什么取证”。等模型和证据门清楚后，再进入战略屋对齐或具体执行。

## A1 — 资料中的应用 (Past Application)

### 示例 1: 竞争战略选择

- **问题**: 企业要在竞争环境中选择成本领先、差异化或集中化。
- **方法论的使用**: PPT 建议先分析企业和竞争对手的经营环境，再思考战略方向，并分析各战略风险。
- **结论**: 战略方向不能只凭偏好选择，需要竞争环境和风险证据。
- **结果**: 输出应是战略选项和风险控制点，而不是简单说“做差异化”。

### 示例 2: 行业竞争压力

- **问题**: 用户想判断一个行业是否值得进入或投入。
- **方法论的使用**: 五力模型要求检查现有竞争者、供应商、购买者、潜在进入者、替代品。
- **结论**: 行业吸引力来自多方力量，而非只看市场规模。
- **结果**: 取证要覆盖进入壁垒、供应商议价、买方议价、替代品和竞争强度。

### 示例 3: 组合保留或退出

- **问题**: 多个业务、产品或市场不知道该发展、保持还是退出。
- **方法论的使用**: 市场吸引力和企业实力矩阵要求评估市场增长、规模、盈利、竞争结构、企业份额、质量、渠道和效率等。
- **结论**: 资源倾斜、维持调整、停止转移应由市场吸引力和企业实力共同决定。
- **结果**: 不同产品进入发展、保持或退出的证据门。

### 示例 4: BCG/GE 标准线校准

- **问题**: 团队把业务放进 BCG 或 GE 矩阵后，想直接裁撤“瘦狗”或加投“明星”。
- **方法论的使用**: 先检查市场增长率、相对市场份额、行业吸引力、经营实力、权重、标准线、业务规模和历史轨迹是否有当前证据。
- **结论**: 矩阵位置只是资源配置假设，标准线和变量缺证时不能输出投资/退出结论。
- **结果**: 先形成取证清单和动态复核点，再进入资源配置讨论。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 想做战略分析，但不知道该选 3C、PEST、SWOT、五力、BCG、安索夫、价值链还是 GE。
2. 已经填了一堆战略模型，但担心没有数据、用户、竞争或成本证据。
3. 要评估行业进入、产品组合、增长路径、竞争优势或退出选择。
4. 想把战略讨论从“观点争论”转成“模型选择 + 证据缺口 + 取证动作”。
5. 团队拿静态 BCG/GE/SWOT 矩阵做资源配置、裁撤或进入决策，但标准线、权重和变量来源不清。

### 语言信号

- “这个战略问题该用 SWOT 还是五力？”
- “帮我做 PEST/3C/BCG/安索夫，但别空填表”
- “我们只有战略框架，没有证据”
- “strategic analysis / evidence gate / model router”
- “BCG/GE matrix 标准线怎么定？”
- “SWOT 能不能直接变成策略？”

### 与相邻 skill 的区分

- 与 `strategy-house-alignment-check` 的区别: 本 skill 先选战略分析工具并补证据；战略屋 skill 用于战略目标、战场、制胜方式和保障机制对齐。
- 与 `primary-source-fact-grounding` 的区别: 本 skill 告诉你哪些战略证据需要补；原始材料接地 skill 深挖某个证据来源是否可靠。
- 与 `seven-s-hard-soft-change-balance-audit` 的区别: 组织承接失败时用 7S；战略问题和模型选择不清时用本 skill。
- 与 `kgi-kpi-causal-tree-validity-check` 的区别: KPI 树处理既定目标的过程指标；本 skill 处理目标或战略选项之前的分析。
- 与 `problem-analysis-tool-router` 的区别: 对“现实问题该用什么工具”的泛路由先用 problem router；一旦明确为战略模型选择和战略证据门，使用本 skill。

## E — 可执行步骤 (Execution)

1. **界定战略问题类型**
   - 完成标准: 将问题归为顾客/竞争/自身、宏观环境、行业压力、增长路径、产品组合、价值链、市场吸引力、资源配置或综合取舍之一。
   - 判停条件: 如果只是执行计划或 KPI 拆解，不进入战略模型路由。

2. **选择一个主模型**
   - 完成标准: 只选一个最窄模型，并说明为什么暂不使用其他模型。
   - 示例: 宏观政策变化用 PEST；行业进入压力用五力；产品组合用 BCG/GE；增长路径用安索夫；内部活动降本增值用价值链。

3. **列模型专属证据门**
   - 完成标准: 对模型每个格子列出需要的事实、数据来源、时间范围、样本、口径和不确定性。
   - PEST: 必须标明当前政策/经济/社会/技术来源和时间戳。
   - SWOT: 必须有目标、内外部归类、竞争比较、影响排序和行动承接。
   - 五力: 必须把压力标签追到结构原因，而不是只写“强/弱”。
   - BCG/GE: 必须写明市场增长、相对份额、行业吸引力、经营实力、权重、标准线、业务规模、历史轨迹和风险变量。

4. **判定证据状态**
   - 完成标准: 将每个格子标为已证实、弱证据、假设、未知。
   - 判停条件: 关键格子是未知或弱证据时，只输出取证计划，不给战略结论。

5. **校准标准线和时间动态**
   - 完成标准: 对矩阵类模型说明标准线来自行业均值、历史均值、竞品比较、管理假设还是未知；标出必须复核的时间点。
   - 判停条件: 标准线来自模板默认值或未注明来源时，不做资源投放、裁撤或进入/退出建议。

6. **输出下一步**
   - 完成标准: 给出一个取证任务、一个暂定判断、一个必须复核的风险点，以及下一步是否转 `strategy-house-alignment-check`。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 战略目标、主战场和能力已清楚，只需要检查落地一致性，应转 `strategy-house-alignment-check`。
- 用户只想写品牌定位、利益点和可信理由，应转 `brand-house-positioning-benefit-rtb-audit`。
- 用户只需要拆销售、转化或运营 KPI，应转 `kgi-kpi-causal-tree-validity-check`。
- 用户给的是当前市场、政策、平台规则或竞品状态，实际使用时必须浏览或核验最新来源，不能凭旧资料下结论。
- 用户只是说“不知道该用哪个思维模型/管理工具”且尚未确定为战略问题，应先转 `problem-analysis-tool-router`。
- 用户要求直接给行业进入、投资、裁撤、融资或财务结论，但证据缺失，只能输出取证计划。

### 资料中的失败模式提示

- PPT 的战略模型多为单页速览，若逐个安装会变成模型堆砌。
- 波特基本战略页特别提示“任何战略都存在风险”，模型选择必须伴随风险控制。
- SWOT 常见错误是目标未共识就开填，或把 SWOT 当成策略本身。
- BCG/GE 常见错误是使用模板标准线、忽略历史轨迹、变量权重和风险。

### 作者的盲点 / 资料局限

- 资料没有提供真实行业案例和原始数据样本；所有战略结论都必须回到当前事实。
- PEST、五力、SWOT 等模型高度依赖时效信息，不能把 2026 年以前的资料当作当前市场事实。
- 《100个思维工具详解》的 BCG/GE/SWOT 案例多为工具说明与二手案例，只能作为结构样例，不是当前行业证据。

### 容易混淆的邻近方法论

- SWOT 不是万能入口；它适合汇总内外部证据，不适合在没有证据时凭感觉填格子。
- BCG/GE 不等于“喜欢哪个业务就投哪个”；必须有市场增长、份额、盈利、能力等证据。
- PEST 不提供指标选择和评估标准；必须按具体行业和时间重新取证。
- 五力不是原因分析终点；“买方议价强”之后还要追到买方集中度、转换成本、替代方案和利润结构。
