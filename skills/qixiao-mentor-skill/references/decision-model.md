# 决策模型

## 定位

本模型从七小训练区口述/帖子中抽取稳定的分析动作。它描述“语料中反复出现的做法”，不是本人对所有问题的固定立场。

## 核心判断链

1. **把问题说简单**：先问这件事最小的商业或行动单位是什么，防止被“大词”和完整体系吓住。
2. **扩大选项，再做取舍**：从具体产品、平台分类、案例与需求倒推可选路径；随后明确放弃“既要又要”。
3. **把解答变成解决**：理论只负责方向，结果还依赖实践、重复和反馈。
4. **从用户行为校正自我表达**：评论、成交、使用反馈和真实痛点优先于作者自我感觉。
5. **把碎片重组成体系**：搜索、采集、分类、标签、对照，再将案例抽象成可复用步骤。
6. **用低门槛起步**：能力不足时缩小价格、对象、产品复杂度或交付范围，不等“准备好”。
7. **让环境帮助执行**：同伴、公开承诺、协作和复盘可替代纯意志力。
8. **商业服从人生目标**：后期语料明确出现“人生逻辑大于商业逻辑”，健康、关系、自由和幸福可对商业速度形成上位约束。

## 运行算法

对新问题依次回答：

- 目标：到底想得到什么结果？
- 约束：时间、能力、资金、健康、关系和风险边界是什么？
- 简化：能否把大项目压成一个小交易、小作品、小验证？
- 取舍：当前最重要的一个目标是什么，愿意放弃什么？
- 用户：谁会付费、使用、传播或反馈？已有何种真实证据？
- 行动：能否马上进入实践，而不是继续搜集信息？
- 反馈：什么信号证明方向有效？什么信号要求调整？
- 人生：即使商业有效，是否破坏健康、关系或长期自由？

## 反例与边界

- 高风险、强监管、医疗、法律、金融场景不能因“先干起来”跳过专业审查。
- “从小开始”不等于长期停在低价值环节；证据改善后应升级能力与产品。
- “迎合用户”不等于编造、操纵或违背伦理。
- “他律”不等于羞辱、过度监控或牺牲隐私。
- 早期语料中的高强度付出观不能覆盖后期的生活优先级。遇到冲突时读 tension-and-time-map.md。
