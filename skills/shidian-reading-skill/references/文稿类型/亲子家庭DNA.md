# 亲子家庭 DNA

- **适用场景**：育儿焦虑、教育选择、代际沟通、父母边界、陪伴和孩子的心理安全。
- **标题 DNA**：反常识引语加“令父母反思”；孩子/老人某种特征加结果；以教育现象提问“现在怎么样了”。人群加命运判断在样本中最突出。
- **开头 DNA**：从假期、考试、热搜、家长朋友圈或一段具体亲子互动切入，再把两种对立意见摆在桌面上。统计上“判断或铺垫”最多，说明此类不必每次先上名言。
- **推进链**：现实场景/新闻 → 家长两难 → 孩子的真实感受或代价 → 教育/心理机制 → 反例或替代做法 → 3—5 条家庭行动 → 降低焦虑的结论。
- **材料偏好**：父母和孩子的对话、教育新闻、纪录片、研究数据、身边家庭、正反案例。细节必须呈现孩子的主观体验，而非只写家长判断。
- **段落节奏**：句长中位 27 字；叙事比成长类略长，重大数据或孩子原话前后留白。行动建议通常分点，单点内部仍用小故事支撑。
- **情绪温度**：7/10。允许先制造关切，但最终应把父母从羞耻/恐慌带回理解、尊重和可行动空间。
- **结尾 DNA**：强调陪伴、倾听、界限、身教或接纳中的一项，不求完美；常以评论话题邀请父母分享。
- **事实核查**：教育政策、升学比例、精神健康与自杀数据、调查样本、专家身份、学校事件进展都属高风险事实。涉及未成年人时去标识、避免责怪受害者，不能把相关性写成父母职业导致孩子患病。
- **像 / 不像警告**：像的是同时看见父母压力和孩子感受；不像以“别人家孩子”恐吓、把职业教育写成注定失败、用单个悲剧推出普遍因果。
- **深读样本与置信度**：`7a40e1fa6ece7e22`《“请不要带孩子去旅行”，令无数父母反思的好文》、`3fd7f5097dbced5a`《北大教授公布自杀学生父母职业分布，让我想起那组40年前中国孩子偷拍照》、`7a28eb21ca615cbc`《第一批被中考分流的孩子，现在怎么样了？》、`ef02804e9e5dad7a`《父母子女间的因果，谁也躲不过》。**置信度：高（结构）/中（事实）**；结构一致，但数据和因果表述需要比原样本更严格的核查。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
