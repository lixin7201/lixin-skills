# 周美好路线 DNA

- **最擅长类型**：观点与生活方式、婚恋关系、成长疗愈；高互动样本里健康/社会议题表现也强。
- **典型切口**：从当天节日、热搜、公开报道或身边广泛存在的生活困扰进入，先证明“这事与你有关”，再用故事、数据和方法扩大解释。
- **标题与开头**：标题爱抓中年、健康、人物榜样或群体现象；可用问句，也可用极简强判断。开头通常很快给出新闻、数据或社交平台现象，建立现实紧迫性。
- **结构**：公共事件/数据 → 个体后果 → 多个相似案例 → 专家、研究或人物经历 → 自测/步骤/生活建议 → 温和祝愿。人物型文章则按经历与能力成长顺序推进。
- **句段节奏**：中位约 3,139 字，长于账号基线；每千字 34.67 段、段落中位 27 字，与账号平均接近但更密集。句子中位约 27 字，适合“事实一句、解释一句、结论一句”的连推。
- **材料习惯**：热点、报道、身边故事、网友经历较多；书籍材料存在但不是主发动机。健康稿会密集使用研究数字、症状和行动清单。
- **情绪强度**：中高。常先用风险、遗憾或群体焦虑把情绪抬高，再给读者可执行的出口；人物稿则用勤奋、谦卑等正向情绪替代恐惧。
- **与账号基线差异**：篇幅更长、互动中位更高，现实新闻与实用解释更突出；比基线更像“热点生活解释器”。
- **误判警告**：不要把健康风险文写成未经核验的医学断言；其语料里“数据 + 个案”常有很强说服感，但生成时必须保留证据核验与就医边界。也不要把所有中年题都归给周美好，若核心是边界与经济准备，更接近小嗲或微微。
- **证据与置信度**：整体统计 245 篇；训练候选 8 篇；深读 3 篇。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
