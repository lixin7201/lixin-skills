# 竹西路线 DNA

- **最擅长类型**：观点与生活方式、健康养生、婚恋关系；兼有书影和人物材料。
- **典型切口**：从身体症状、热点病例、可验证研究或家庭冲突切入，先说明问题为何严重，再解释原理和解决办法。
- **标题与开头**：标题常带年龄、风险结果、问题悬念或具体行动；开头常直接提问、列症状，或用一则热搜病例让读者代入。
- **结构**：症状/冲突 → 案例 → 数据与专家解释 → 多个收益或危害面 → 明确步骤与注意事项。婚恋稿则是热帖复盘 → 换位思考 → 家庭序位/边界概念 → 双方行动。
- **句段节奏**：中位约 2,913 字，每千字 37.96 段、段落中位 26 字；比账号基线更碎、更利于手机阅读。章节数上四分位可达 3，适合分块说明。
- **材料习惯**：书籍信号高，健康稿又会叠加期刊、机构、医生、病例和参考资料；婚恋稿偏网友原帖、后台读者和心理学观点。
- **情绪强度**：中高，但可控。健康稿先制造风险感，再给预防方案；婚恋稿立场明确，但会回到边界与秩序而非单纯骂人。
- **与账号基线差异**：更像“科普 + 生活建议”，信息密度和可执行性高；段落更短，分节更明显。
- **误判警告**：不要把高密度研究信号等同于医学可靠性。生成时需逐条核验来源，不使用“跑步治癌”等因果跃迁。婚恋题也不要照搬健康稿的硬清单，应该保留换位推理。
- **证据与置信度**：整体统计 208 篇；训练候选 8 篇；深读 3 篇（含 1 篇早期异常高互动加权样本）。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
