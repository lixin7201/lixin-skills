# 人际处世 DNA

- **适用场景**：识人、交友、关系断舍离、独处、边界、说话做事的分寸。
- **标题 DNA**：某类人加 3 个特征/3 句话，再给“别深交”等明确结论；也可从“没什么朋友的人”做反向正名。
- **开头 DNA**：日常社交观察、提问或一句古今名言，随后很快宣布判断标准。引用/金句开路仍最常见。
- **推进链**：常见误解/风险 → 3 个识别信号或性格特征 → 每点配一个故事 → 解释关系成本 → 给出筛选/边界原则 → 祝愿遇到良人。
- **材料偏好**：身边故事最强（类型信号 90），其次书籍 46；古人故事、寓言、饭局和职场细节常被用来做“见微知著”。
- **段落节奏**：句长中位 26 字；三段式最稳，每段都按“小场景—行为—人品/边界判断”结束。
- **情绪温度**：5/10。带警醒但不猎巫；对“虚伪、精明、人品差”的判断要留证据，不做全人格宣判。
- **结尾 DNA**：回到“关系宁缺毋滥、真心贵、先照顾好自己”，多为祝愿共勉。
- **事实核查**：历史人物、寓言来源、名言、网络高赞故事均需核查；对真人的人品判断应只描述已知行为。不要把一次饭局表现写成终身定性。
- **像 / 不像警告**：像的是给读者可观察行为，而不是玄学读心；不像是“有这三点的人都不能交”式绝对化。训练中《你熬夜只会刷朋友圈，看古人熬夜做什么？》主脊柱其实是历史生活方式，不应因“人与社会”宽泛标签继续留在本路由。
- **深读样本与置信度**：`e9475d814cfccf2b`《没什么朋友的女人，大多是这3种性格，你是吗》、`b95125c059267ba9`《你熬夜只会刷朋友圈，看古人熬夜做什么？》、`bb2d41442edbac0d`《越是虚伪的人，越喜欢把这三句话挂在嘴边，最好别深交》、`b348a1ff4d1499ec`《人品差的人，饭局上有这3个特征，不值得深交》。**置信度：中**；典型三点识人稿稳定，但存在明显跨类样本，调用前必须重判主脊柱。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
