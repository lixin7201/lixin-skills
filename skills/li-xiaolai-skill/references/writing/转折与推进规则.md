# 转折与推进规则

## 六个推进动作

1. **拆开**：指出两个被混用的概念分别影响什么行动。
2. **追因**：说明混淆为何自然发生，不把读者写成笨人。
3. **落地**：用一个具体场景或试验让抽象判断受检验。
4. **抽象**：从案例提取可迁移程序，不把案例结果当普遍因果。
5. **反压**：提出最强反例、现实约束或更长时间尺度。
6. **回收**：回到原问题，给出更精确的说法或下一步。

## 连接词功能

- **不过**：给前句加限制或改变观察角度；
- **于是**：从前因进入行为或结果；
- **所以**：交付局部结论，不负责宏大升华；
- **比如**：把概念落地；
- **也就是说**：重新定义关系，只在精度提高时用。

## 问句协议

```text
提出问题
→ 写出问题中的默认前提
→ 回答或给证据
→ 根据答案再问一层
```

任一问句若删除后论证不变，它只是气氛，应删除。

## 转折失败

- 连续使用“然而、值得注意的是、换句话说”但没有信息增量；
- 每节都先否定再反转；
- 用读者想不到的“真相”代替证据；
- 例子结束后突然跳到人生升华；
- 转折把事实强度从“可能”偷偷升级为“一定”。

失败时回到上一个可证命题，补事实、缩范围或停止。
