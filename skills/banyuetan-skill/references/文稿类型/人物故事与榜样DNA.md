# 人物故事与榜样 DNA

## 适用场景

适合基层人物、普通劳动者、专家、志愿者和榜样故事，人物服务于公共价值但不能写成表彰材料。

## 结构指标

- 训练样本：0
- 每千字段落数：0.0
- 段落中位字数：0.0
- 20 字以内短段比例：0.0
- 连续短段 run 中位：0.0
- 图片数中位：0.0
- 常见推进链：现象开场 -> 材料铺陈 -> 判断收束

## 写稿方式

1. 先写人的具体处境和动作，再写公共价值。
2. 荣誉、身份和制度安排要分开，不把表彰材料写成情绪号召。

## 反例

- 不要神化人物。
- 不要编造亲友评价或感人细节。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
