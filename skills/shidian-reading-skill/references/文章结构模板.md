# 十点读书文章结构模板

模板是路线图，不是槽位表。每篇只选一种主结构，并允许 20%–30% 的自然偏离。

## A. 故事—机制—行动（默认）

1. 生活瞬间或主事件：让冲突立即可见。
2. 主故事展开：人物为什么这样选，付出什么代价。
3. 第一层判断：命名关系机制。
4. 第二材料校准：提供反例、相邻案例、书影或可靠知识。
5. 读者映射：指出日常里如何识别同类问题。
6. 最小行动：给边界、选择或习惯，不做万能承诺。

## B. 书影人物—现实映照

1. 从人物最难的选择进入，不从作品简介开始。
2. 用必要情节完成一条人物弧，避免复述全剧情。
3. 提炼作品中的关系或成长命题。
4. 引入现实生活的相似处境或反例。
5. 回到读者，把作品从“看懂”变成“用得上”。

## C. 热点—事实—边界

1. 交代已核验的核心事实与时间。
2. 区分已知、争议和未知，不靠情绪替代证据。
3. 展开一条最值得讨论的人性或公共机制。
4. 引入第二事实/规则/专业来源校准。
5. 落到个人能采取的动作与不能越过的伦理边界。

## D. 清单—场景—递进

1. 用具体困扰说明为什么需要这份清单。
2. 每一项都包含“小场景/解释/动作”，禁止只有口号。
3. 各项之间形成递进或不同维度，不同义改写。
4. 结尾指出最先做的一项，而非重复全部清单。

## E. 人物生平—关键选择

1. 用最能代表命题的高光或低谷开场。
2. 只选 2–4 个决定人生方向的节点。
3. 每个节点写选择与代价，不做年表。
4. 允许人物矛盾，避免神化或道德审判。
5. 把人物经验转译成有边界的普通人启示。

## 成稿自检

- 主材料是否真正展开，而不是名字列表？
- 每一节是否推动了新的认识？
- 第二材料是否校准而非重复？
- 标题的每个强承诺是否被正文兑现？
- 删掉结尾祝愿后，核心判断是否依然成立？
