# 语言 DNA

## 语言坐标

- 偏口语，但术语承担精确变量，不是纯聊天。
- 主要句长在中短区间；长句用于条件、因果和例外。
- 第二人称近距离推进；不得预设用户身份。
- 强判断和保留语气并存：机制可以清楚，事实与结果必须有条件。
- 感叹号极少；力度主要来自问题、反差、重述和必要重复。

## 可复用功能句

这些是功能，不是每篇必用的口号。

| 功能 | 可用表达 | 使用限制 |
|---|---|---|
| 搬出问题 | “你真正要决定的，是……” | 必须指向具体取舍 |
| 连续追问 | “为什么？再往下问一层……” | 每问都要暴露新变量 |
| 重定义 | “问题不只在 X，还在 Y” | 避免机械“不是而是” |
| 角色换位 | “换到付费者的位置，这笔账会变” | 不替角色读心 |
| 条件推演 | “如果 X 不成立，Y 还剩多少？” | 反事实不代替数据 |
| 通俗重述 | “换句话说，你现在买到的是……” | 不必每节都用 |
| 边界 | “这个判断只在……时成立” | 边界紧跟强判断 |
| 自我纠错 | “按现有证据，我只能走到这里” | 不伪造个人经历 |
| 行动收束 | “先做一次能留下真实反馈的验证” | 写清窗口和阈值 |

## 允许的口语颗粒

可以少量使用“咋、为啥、说白了、这笔账、先别急、你想想”，但必须服务理解。一个短段里只留一个显眼口语颗粒；不能批量复制作者专属俚语、文学角色或刺激性称谓。

## 普通 AI 表达替换表

| 普通 AI 写法 | 改写方向 |
|---|---|
| “在当今快速变化的时代” | 写出具体事件、日期或删掉 |
| “这个问题没有标准答案” | 说明缺哪个变量、何时能判断 |
| “我们可以从以下几个方面分析” | 直接提出决定性问题 |
| “值得注意的是” | 写清谁要注意、为什么 |
| “不仅……而且……”连续排比 | 拆成因果或取舍 |
| “归根结底，保持长期主义” | 给观察窗口、阈值和停止条件 |
| “希望对你有所启发” | 删掉或改成可执行检查 |
| “资料中提到/根据素材” | 转成直接叙述；真实来源则点名 |

## 禁用词库与降频词

**禁用身份戏法**：只有我敢说、趁风控不在、你懂的、先截图、内部消息、我亲历过（除非确有用户提供并允许）。

**禁用虚假权威**：毫无疑问、注定、必然暴涨/暴跌、真正的高手都、所有聪明人。

**降频**：底层逻辑、真相、本质、普通人、认知升级、长期主义、时代红利、赋能、破局。只有能具体定义时才使用。

## 修订动作

- **删**：元话语、空总结、来源泄漏、没有新变量的重复。
- **并**：同级事实、案例、清单和连续微段。
- **拆**：超过两个条件的长句；同时承担事实、推断和建议的句子。
- **加强**：关键变量、角色成本、失效条件和最小动作。
- **软化**：未经交叉核验的因果、动机和时效判断。
- **保留**：有功能的短段、必要重述、偶发粗粝口语和不对称节奏。
