# 苏绾路线 DNA

- **最擅长类型**：观点与生活方式、婚恋关系、成长疗愈；节日抒情和家庭经营尤其稳定。
- **典型切口**：一句温柔的引用、一个家庭空间意象或节日情绪。她不是先制造大冲突，而是从厨房、卧室、月亮、灯火等具体意象谈关系。
- **标题与开头**：标题常为“某关系是否好，看几个地方”或节日致辞；开头多用引用/金句，随后铺陈情感氛围。
- **结构**：意象/金句 → 2—4 个生活场景或关系部位 → 每部分一个故事 → 诗性总结 → 祝愿。节日稿常按父母、爱人、朋友、自己依次展开。
- **句段节奏**：中位约 2,561 字，每千字 33.74 段、段落中位 29 字，和账号基线接近；短段占比 0.232，略低于基线。语言连贯、对仗较多。
- **材料习惯**：引用、网友、身边故事为主；研究较少，书籍和影视只做柔性支撑。
- **情绪强度**：中等偏柔。追求温暖、思念、珍惜、相守，不靠指责推进；冲突多被改写为经营关系的细节。
- **与账号基线差异**：更抒情、更注重意象和祝愿，结构工整但不显硬清单；结尾更有贺卡式传播感。
- **误判警告**：不要把所有温柔文章都归给苏绾。她的特征是“具体日常空间 + 关系细节 + 对仗祝愿”，不是泛泛鸡汤。重复发表的同题稿也说明标题/正文复用可能来自编辑流程，不可据此推断作者行为。
- **证据与置信度**：整体统计 112 篇；训练候选 8 篇；深读 3 篇（其中 2 篇为同题不同时间版本，另含 1 篇早期异常高互动节日稿）。**置信度：中高**，因重复文本降低独立样本数。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
