# 角度家族与人物提问镜头

## 使用原则

角度不是标题句式，而是“用哪组事实回答哪个问题，最终给读者什么新判断”。先从六个家族各取一个成立候选，再用人物镜头做压力测试。若角度仅换了形容词、语序或情绪强度，合并为同一个候选。

## 六个角度家族

### 1. `change-and-consequence`：变化与后果

- 问题：这件事与昨天相比究竟改变了什么？谁最先感受到？
- 适合：新规、项目进度、商业动作、公共服务、城市变化。
- 角度成立条件：有明确的“之前/之后”与影响对象。
- 避免：把计划写成落地，把普通更新夸成时代转折。

### 2. `hidden-cost`：隐性代价与取舍

- 问题：表面利好背后由谁付出时间、钱、机会或风险？
- 适合：消费、教育、住房、产业、工程、平台规则。
- 角度成立条件：成本可被事实、账本、流程或具体处境说明。
- 避免：为了“反转”强行唱反调。

### 3. `counter-consensus`：反常识但可证伪

- 问题：大家第一反应可能错在哪里？什么证据支持另一个判断？
- 适合：热搜、流行观点、城市比较、技术趋势、营销叙事。
- 角度成立条件：有清楚的主流说法、替代判断和可推翻证据。
- 避免：用冒犯、阴谋论或无证据否定制造新意。

### 4. `local-human`：本地具体的人

- 问题：哪类宜宾人会在什么场景中真实遇到它？
- 适合：宏观政策、产业数据、公共设施、招聘、社区生活。
- 角度成立条件：能落到具体对象、场景和行动，而不是随机加“宜宾人”。
- 避免：伪造亲历、采访、群体态度或本地锚点。

### 5. `decision-service`：帮读者做决定

- 问题：读完后，读者能少踩什么坑、完成什么动作、做什么取舍？
- 适合：通知、攻略、活动、招聘、办事、消费和工具实测。
- 角度成立条件：条件、入口、时间、成本与限制足够完整。
- 避免：把普通信息清单伪装成深度观点。

### 6. `system-mechanism`：机制与二阶影响

- 问题：是什么激励、流程或约束让这件事发生？下一步会影响什么？
- 适合：产业、企业、治理、平台、教育就业、城市运行。
- 角度成立条件：至少有两个相互作用的主体和可解释的机制。
- 避免：用宏大词汇替代事实，或把相关性写成因果。

## 角度去同质检查

两个候选若以下五项有四项相同，视为同一角度，只保留证据更强者：主角/受影响对象、核心问题、非显然判断、读者收益、主要证据路径。

## 14 个人物镜头路由

人物镜头用于提问和反驳，不用于模仿口吻。一次最多选 3 位，且必须来自不同认知用途。

| 人物镜头 | 精确 Skill | 适合挑战的问题 | 不要强用 |
|---|---|---|---|
| Paul Graham | `paul-graham-perspective` | 个体行动、创业选择、早期信号、反直觉经验 | 通知和纯信息服务 |
| 张一鸣 | `zhang-yiming-perspective` | 系统效率、组织、长期变量、产业演化 | 只有情绪没有机制的故事 |
| Andrej Karpathy | `andrej-karpathy-perspective` | AI 工具真实能力、技术边界、实测路径 | 未亲测就下技术结论 |
| Ilya Sutskever | `ilya-sutskever-perspective` | AI 能力跃迁、研究风险、长周期不确定性 | 普通本地资讯 |
| MrBeast | `mrbeast-perspective` | 第一秒注意力、兑现承诺、传播包装 | 用夸张替代内容价值 |
| Donald Trump | `trump-perspective` | 谈判、权力、传播行为和对手反应 | 常规民生稿与无冲突素材 |
| Steve Jobs | `steve-jobs-perspective` | 产品体验、空间感受、删繁就简、核心承诺 | 政策事实不足时谈体验 |
| Elon Musk | `elon-musk-perspective` | 第一性原理、工程约束、成本和规模化 | 无工程或成本事实的宏大叙事 |
| Charlie Munger | `munger-perspective` | 激励、利益、二阶影响、误判和代价 | 为尖锐而尖锐 |
| Richard Feynman | `feynman-perspective` | 机制解释、可验证问题、把术语讲明白 | 冒充专业结论或医疗建议 |
| Naval Ravikant | `naval-perspective` | 杠杆、长期选择、个人自由和复利 | 无个人选择关系的公共通知 |
| Nassim Taleb | `taleb-perspective` | 脆弱性、尾部风险、反脆弱与可逆性 | 把小概率风险渲染成必然灾难 |
| 张雪峰 | `zhangxuefeng-perspective` | 教育、就业、家庭约束和结果导向 | 与升学就业无关的泛热点 |
| 孙宇晨 | `sun-yuchen-perspective` | 注意力、叙事、营销博弈和话题扩散 | 操纵、碰瓷、虚假承诺或高风险金融诱导 |

## 推荐组合

- 本地政策/民生变化：Charlie Munger + Richard Feynman + 张雪峰（仅教育就业时）。
- 城市项目/公共空间：Steve Jobs + Charlie Munger + Nassim Taleb。
- AI/科技：Andrej Karpathy + Ilya Sutskever + Richard Feynman。
- 活动/消费/传播：MrBeast + Steve Jobs + Charlie Munger。
- 人物/创业：Paul Graham + 张一鸣 + Naval Ravikant。

组合只是候选镜头，不要求凑满三人；普通通知往往 `none` 更好。
