# 工作即学习场技能叠加

## R — 原文 (Reading)

> 在找工作时要看能从中学到什么，而不是只看能挣多少钱。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸穷爸爸》第7章

## I — 方法论骨架 (Interpretation)

这个方法把工作从单纯收入来源，改成能力、信息、人脉和未来象限迁移的训练场。
它不是让人忽视工资，而是把短期现金和长期能力资产同时放上桌。
一份工作或项目如果只消耗时间，却没有训练销售、沟通、系统、财务、管理或分发能力，就要警惕。
对写作和创业尤其重要: 专业能力需要被市场化能力放大。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者选择销售训练而非安稳路线
- **问题**: 作者意识到自己怕销售，单靠专业和学历无法进入想要的商业世界。
- **方法论的使用**: 他选择能训练销售和沟通的工作，把短期不舒服当成学习成本。
- **结论**: 工作选择要看补哪块未来短板。
- **结果**: 销售能力后来成为作者创业、写作和教育产品的重要底层能力。
### 案例 2: 网络营销被作者视为商业训练环境
- **问题**: 普通人缺少低成本学习销售、领导和商业系统的场景。
- **方法论的使用**: 作者把某些网络营销系统视为训练场，但强调要看教育系统。
- **结论**: 机会的教育价值必须被审计，不能只看回报承诺。
- **结果**: 该观点进入商业教育尽调，而不是直接加入建议。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户纠结一份工作或项目短期钱少但可能学东西。
2. 用户想为创业、写作、管理、销售或投资补能力。
3. 用户感觉当前工作只耗时间，想评估是否还值得留。

### 语言信号 (用户的话里出现这些就应激活)

- "这份工作能学到什么"
- "短期钱少值得吗"
- "我该补什么技能"
- "项目值不值得做"
- "职业转型怎么选训练场"

### 与相邻 skill 的区分

- 与 `sales-marketing-second-skill` 的区别: 本 skill 选训练场和技能组合；后者专门补销售、市场、分发能力。
- 与 `cashflow-quadrant-income-map` 的区别: 本 skill 看能力资产；后者看收入来源。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **定义目标能力**
   - 操作: 写出未来 1-3 年最需要的能力，而不是只写职位目标。
   - 完成标准: 目标能力具体可练。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **拆机会收益**
   - 操作: 比较现金、能力、信息、人脉、作品、系统经验和风险成本。
   - 完成标准: 机会得分不只按薪资。
 3. **识别缺口**
   - 操作: 找出当前机会能补的关键短板和补不了的地方。
   - 完成标准: 知道为何选择或拒绝。
 4. **设学习合同**
   - 操作: 如果接受，写清 30-90 天要产出的作品、案例、技能证据和退出条件。
   - 完成标准: 机会转化为可复盘学习任务。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户面临现金流危机，只能先保基本收入时；先处理安全垫。
- 用户要求你替他决定具体 offer 而不提供目标和约束。

### 作者在书中警告的失败模式

- 把低工资合理化为学习，但没有明确技能证据。
- 为了舒适和头衔长期待在不会训练未来能力的位置。

### 作者的盲点 / 时代局限

- 作者强调学习机会，可能低估家庭现金流、医保、签证和年龄阶段约束。
- 不是每个低薪或高压环境都有教育价值，必须设退出条件。

### 容易混淆的邻近方法论

- 与 `sales-marketing-second-skill` 的区别: 本 skill 选训练场和技能组合；后者专门补销售、市场、分发能力。
- 与 `cashflow-quadrant-income-map` 的区别: 本 skill 看能力资产；后者看收入来源。
