# 社会民生评论 DNA

## 适用场景

适合社会热点、公共争议、网络情绪和生活秩序类评论，先立问题，再做边界判断。

## 结构指标

- 训练样本：75
- 每千字段落数：15.62
- 段落中位字数：77.0
- 20 字以内短段比例：0.3
- 连续短段 run 中位：2.0
- 图片数中位：13.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 先界定公共边界：正常喜爱和失序追捧、理性讨论和网络攻击、个人选择和公共风险要分开。
2. 材料组织要从一件热议现象进入，再拆平台机制、规则边界、受影响人群和协同治理。
3. 标题可锋利，但正文要避免站队式情绪，把争议拉回秩序、权益、安全、信任或常识。
4. 写体育饭圈化时，先保留正常支持和批评讨论，再划出拉踩攻击、造谣侵权、隐私骚扰、组织性控评和商业营销的红线。
5. 同类稿要把平台流量机制、圈层对立、赛事组织、媒体叙事和公众表达保障分开写，结尾把注意力拉回比赛、训练、规则精神和健康参与。

## 反例

- 不要把网暴、饭圈、流量争议写成单纯年轻人情绪。
- 不要直接指认平台或群体，除非素材给了事实。
- 不要用“压低热情”替代治理失序行为；要同时保护正常喜爱和正常讨论。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
