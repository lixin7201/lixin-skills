# 误解地图预演

## R — 原文 (Reading)

> 通过日常对话、小范围内的讨论，收集不同意见，思考它们的有理之处、无理之处，而后逐一设计对应策略。
>
> — 李笑来，第9节与第30节

---

## I — 方法论骨架 (Interpretation)

表达者不能用“我已经说过”证明听众会按原意理解。正式发布前，应让具有代表性的小样本在看完材料后用自己的话复述，并把偏差当成设计数据。

误解地图区分遗漏、概念替换、范围扩大、情绪触发、合理异议和恶意曲解。前四类可通过定义、反例、顺序或证据修复；合理异议要修改主张；恶意或高风险场景需要边界和升级。

验收标准不是所有人赞同，而是目标受众能准确说出“是什么、不是什么、适用于谁、何时停止”。

## A1 — 书中的应用 (Past Application)

### 案例：“多背”被学生误解为背作文

- **问题**：作者建议学生多背英语原文，学生却准备背应试作文。
- **方法论的使用**：该错误复述暴露了“多背”的相邻误用，作者据此强调同时讲清正面定义和不是什么。
- **结论**：正面说明不足以阻止听众用旧类别补全新方法，必须显式排除最可能的误用。
- **结果**：书中以该案例说明错误行动可能与原目标相反；没有量化后续修订效果。
- **证据位置**：candidates/cases.md c25，第30节

## E — 可执行步骤 (Execution)

1. **选取代表性小样本**
   - 动作：按知识水平、利益关系、使用场景和反对程度选择5—12名样本，不只找同温层。
   - 完成标准：样本覆盖至少三类关键差异，并记录选择理由。

2. **收集无提示复述**
   - 动作：让样本回答“这是什么、不是什么、谁能用、什么时候不能用、下一步做什么”，表达者不先纠正。
   - 完成标准：每名样本都有原始复述记录，能够定位到具体句段或缺失信息。

3. **分类误解并找机制**
   - 动作：分为遗漏、概念替换、范围漂移、情绪触发、合理异议和恶意曲解，统计影响与频率。
   - 完成标准：每个高影响误解有机制假设和至少一个原始样本。

4. **回写正反定义与边界**
   - 动作：增加正例、反例、非适用项、关键风险和必要证据，再进行一轮新样本复述。
   - 完成标准：高影响误解不再重复，或被明确列为不可通过文案消除的剩余风险。

### 整体验收与停止

- **完成标准**：形成误解地图、修订记录和第二轮复述证据，关键行动边界能被目标样本准确说出。
- **停止条件**：主张本身不真实、关键风险无法披露，或样本显示政策/产品设计而非表达有根本问题时，停止修文案并回到决策层。
- **复盘方式**：发布后把真实提问和误用加入地图，比较预演命中率；连续出现的新高影响误解触发版本修订。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 主张尚未通过事实与授权审计时，不用误解预演掩盖内容问题。
- 不以“听众误解”为由否定合理异议或伤害反馈。

### 作者在书中警告的失败模式

- 只解释是什么而不排除不是什么，或把演后反馈变成争辩，失去误解数据。

### 作者的盲点 / 时代局限

- 原书主要是个人演讲经验；不同文化、语言、无障碍需求和大规模在线受众的样本设计需额外验证。

### 容易混淆的邻近方法论

- 与 `accurate-restatement-feedback-loop` 的区别：本 Skill在发布前用样本构建群体误解地图；后者处理一次真实互动中的问题确认和反馈闭环。
- 与 `speaker-claim-consistency-audit` 的区别：本 Skill检验受众理解；后者先检验讲者主张是否真实、有证据且归属清楚。
