# 原子输出与周期重组

## R — 原文 (Reading)

> “笔记流”只关注两件事：1.提取关键概念。2.概念与概念之间的连接。
>
> — 姜胡说，第四章

---

## I — 方法论骨架 (Interpretation)

这个方法处理的核心不是“知道更多”，而是把一个模糊问题变成可观察、可验证的行动结构。

每条只写一个可引用结论并标注关系，按周期围绕真实问题重组，重复和冲突处触发重新理解。

它的独特性在于：将每日输出、可运行原子和周期重构结合，目标是让知识自然长成产品，而非普通摘抄。

使用时先确认输入和边界，再运行最小步骤；没有证据的地方要标为假设。

输出必须包含下一步、完成标准和停止条件，不能停在口号或概念解释。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **原子化**
   - 完成标准: 每条只表达一个可独立引用的结论，并注明来源或场景

2. **建立连接**
   - 完成标准: 至少标出支持、反驳、例证或应用中的一种关系
   - 判停条件: 若关键输入无法取得或风险超过授权范围，停止推进并转为补证/求助。

3. **周期重组**
   - 完成标准: 围绕一个真实问题重新编排，不沿用采集顺序

4. **发布与回流**
   - 完成标准: 形成可用产物，把反馈和冲突写回原子卡片

### 整体验收与停止

- **完成标准**: 四步均有可检查产物；事实、假设与建议分开；用户能直接执行下一步。
- **停止条件**: 输入不足、越过专业/安全/资金授权边界、用户拒绝关键验证，或继续行动将不可逆时，停止并明确缺口。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 一次性摘抄归档、要求保持原文顺序的证据材料，或尚无任何输出素材。
- 只有主题词相似、但没有 A2 所列任务与触发信号时，不要激活。

### 作者在书中警告的失败模式

- 用高亮、抄写和重复阅读制造已经掌握知识的错觉。 熟悉感会被误判为理解；没有输出和测试时，认知漏洞不会暴露。

### 作者的盲点 / 时代局限

- 过度原子化会割裂语境；法律、医疗、历史等材料应保留完整来源链。

### 容易混淆的邻近方法论

- `personal-method-ipo` 与 `value-trust-repeat-flywheel`：先比较目标产物、输入证据和停止条件，再决定调用哪个。
