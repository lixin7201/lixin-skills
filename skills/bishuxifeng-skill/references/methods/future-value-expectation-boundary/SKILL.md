# 事实边界下的未来价值与预期管理

## R — 原文（Reading）

> 一个人最大的价值不在于他做了什么，而在于他还能做什么。
>
> — 碧树西风，BXSF-003 · 2022-01-24

> 决定价格的是预期，而不是事实。
>
> — 碧树西风，BXSF-003 · 2022-01-24

## I — 方法论骨架（Interpretation）

1. 他人配置职位、薪酬和资源时，会同时评估已交付事实与未来还能解决的问题。
2. 预期管理不是把自己说大，而是理解评价者的目标，用可验证证据呈现下一阶段增量。
3. 事实、推断和承诺必须分开：历史交付证明能力，里程碑约束未来承诺。
4. 内部判断永远不能被对外叙事污染；任何需要伪造、隐瞒责任或制造假信号的方案都越界。

## A1 — 语料中的应用（Past Application）

### 案例 1：作为组织需要的第四个角色

- **问题**：作者复盘快速升迁时，没有只归因技术，而是识别老板需要替代和制衡角色。
- **方法论的使用**：把技术、市场和组织接口能力呈现为下一阶段可用价值。
- **结果与证据边界**：升迁为作者自述；原因是事后解释。
### 案例 2：刻意展示短板降低威胁感

- **问题**：作者自述通过可控形象影响老板判断。
- **方法论的使用**：案例说明预期会影响授权，也暴露刻意误导的伦理风险。
- **结果与证据边界**：不得把这一案例转成欺骗教程，只保留为风险边界。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 汇报成果但得不到资源
2. 履历较弱却有可验证成长
3. 需要谈薪或争取岗位
4. 诊断为什么能力没有被正确识别

### 语言信号

- “我明明做了很多，领导为什么看不到”
- “怎么证明我未来能承担更多”
- “这段经历应该怎么讲”
- “怎样管理客户预期又不吹牛”

### 与相邻 skill 的区分

- 与 `role-incentive-hidden-information-audit` 的区别：预期管理前必须知道评价者目标与成本；否则容易变成盲猜上意。

## E — 可执行步骤（Execution）

1. **冻结事实底稿**
   - 完成标准：列出可验证交付、数字、角色、限制和失败责任。
   - 判停/转向：事实无法证实时不得写成经历。
2. **识别评价目标**
   - 完成标准：确认对方要降低什么风险、增加什么结果、在何时验收。
   - 判停/转向：只猜上意而无沟通证据时标为假设。
3. **定义未来增量**
   - 完成标准：写出下一阶段可解决的问题、所需资源和不确定性。
   - 判停/转向：不能把潜力写成已实现能力。
4. **搭证据阶梯**
   - 完成标准：用历史小结果、演示、试用、里程碑和第三方证据支撑每一项未来主张。
   - 判停/转向：主张没有证据时删除或降级。
5. **做诚实边界审计**
   - 完成标准：检查是否伪造、隐责、假在线、夸大因果或把人当纯价格。
   - 判停/转向：任一命中即回滚该表达。

### 边界路由规则

- 用户要求伪造履历、在线状态或勤奋信号时，仍由本 skill 触发诚实边界审计：明确拒绝假信号，再把目标改写为真实交付、响应约定和可验证可见性；触发不等于执行违规请求。

## B — 边界（Boundary）

### 不要在以下情况使用

- 不得实施伪造履历、数据、在线时长或客户评价；只能触发边界审计并转为真实证据
- 隐去自己对失败的关键责任
- 把人的尊严和全部价值等同市场价格

### 作者在语料中警告的失败模式

- 正确结论掩盖错误过程
- 一言堂导致真实坏消息消失
- 把洞察当价值而不解决问题
- 高光剪辑造成归因欺骗

### 作者盲点与证据局限

- 作者部分正面叙述本身包含误导行为，必须反转为边界材料
- 预期视角可能低估制度公平和长期信任成本

### 统一安全边界

- 这是从公开文章中提炼的方法，不代表作者本人对新问题的真实意见。
- 不复制作者亲历，不冒充作者，不把自述案例当作独立核验事实。
- 涉及时效事实、法律、医疗或财务高风险问题时，先获取当前可靠资料并明确不确定性。
