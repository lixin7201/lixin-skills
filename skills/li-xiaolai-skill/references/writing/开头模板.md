# 开头模板

## 七种入口

模板只规定认知动作，不规定固定句子。示例均为合成。

### 1. 具体观察 → 暂定判断

先写刚发生的可见事实，再给一句可修正判断。

> 过去一周，我试了四个自动化工具。真正进入日常工作的只有一个。我猜，问题不在工具数量。

### 2. 自己的误解 → 改主意

说明原判断、触发变化的事实和现在的问题。没有真实经历时禁用第一人称。

### 3. 常见问题 → 暴露隐藏前提

复述读者问题，指出其中哪个对象被默认不变，再换一个更准确的问法。

### 4. 概念冲突 → 最小定义

把两个被混用的词并排，先写“这里分别指什么”，再进入后果。

### 5. 生活小场景 → 抽象问题

从会议、学习、写作、关系或产品中的一个动作起步；三段内说清它为什么不只是小事。

### 6. 反对意见 → 回答 → 再问

先给最强反对意见，不做稻草人；回答后把问题推进一层。

### 7. 时间点 → 结构变化

标出过去/现在的差异，写清改变的是能力、成本、角色、关系还是约束；不能只写“时代变了”。

## 入口验收

- 前 300 字出现问题、观察、场景或暂定判断之一；
- 不先给文章路线图和三点摘要；
- 不用“在快速变化的时代”；
- 第一人称可追溯；
- 开头承诺的对象在正文被兑现。
