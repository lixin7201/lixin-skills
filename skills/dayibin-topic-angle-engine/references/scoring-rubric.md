# 角度与标题联合筛选

## KNOCKOUT：不可用好标题分数抵消的事实门

- K1 evidence：标题或主判断编造数字、身份、因果、事件状态、采访或结果。未知且能调查的问题可保留为种子，不算事实通过。
- K2 reader：随机加本地称呼、原文无关系却包装成本地事件。全国问题与本地读者的真实共同处境可以成立，不要求硬造地点。
- K3 delta：核心问题、主要材料和读者收益相同，只改标题。新后果、新证据或阶段推进不算简单重复。
- K4 rhetoric：关键承诺无法兑现；问号暗示无证据指控；藏关键条件使普通读者误判；只有“出事了/全城炸了”才吸引而素材不支持。
- K5 counterargument：对解释或争议公平说明替代解释；反例足以推翻既定结论时改为待验证问题。服务/通知/记忆不强造反方。
- K6 risk：隐私伤害、冒充真人、制造无根据恐慌或保证性承诺。放宽标题力度不放宽事实身份。
- K7 payoff：不知点开后能获得什么，也没有可执行的取证/体验/参与办法。短服务帖不用凑三个正文段落。

## 双判断，不混成100分

分别评估“角度价值”和“标题吸引力”：强/中/弱，各用具体理由。它们是编辑判断，不是CTR预测。

角度价值：具体读者关系、相对常规写法的增量、收益/参与机会、可执行性。
标题吸引力：看点识别速度、具体好奇缺口/情绪/收益、语言自然度、平台适配。
标题兑现：通过/待证据/不通过。事实门独立于前两项。

联合排序：
1. 虚构或误导先淘汰；
2. 角度和标题都强者优先；一强一弱先修弱项，不直接靠平均分胜出；
3. 都成立时按本次用户目标（想点击/讨论/实用）做成对比较，用差异理由推荐；
4. 值得调查但资料少者与今天能写者分别注明，不靠证据多压过所有新方向。

不输出无依据的“90分爆款/必火/点击率翻倍”。需要结构化score时total:null，保留分项文字判断。

## 两个状态

idea_value: strong / medium / weak
status: READY / HOLD_FOR_EVIDENCE / NO_GO

READY表示材料支持当前标题与展开，不表示已发布或无需最后核验。
HOLD_FOR_EVIDENCE表示仍值得展示的策划标题，附最小补采和什么发现会令方向不成立。
NO_GO表示该前提/承诺不可取，不推荐刺激包装。

## 标题力度与边界示例

用户默认bold；clear按需。悬念、情绪词、强反差、半透露结果可以使用，不能机械禁“竟然/原来/没想到/最”。评价含义而非扫词。

- 已有真实账单：可用“午饭没吃多贵，账单怎么这么吓人？”；只有主题没有账单时不能这样暗示已发现高支出。
- 假设讨论：可用“AI把周报写漂亮了，工作没做完怎么办？”作为明确假设策划；不能写“宜宾打工人靠AI骗过老板”。
- 关闭通知只封一条步道：不能写“整个公园突然关闭”，也不能把“只是这条步道”藏在正文末尾。
- 有具体意外发现才能“没想到”；仅换一个问句不能制造不存在的发现。
- 正常广告不能借抢救/失联/事故悬念伪装成公共紧急消息。

清晰并不等于把全文答案讲完。留下值得阅读的答案，同时说清事件、对象及必要条件。
