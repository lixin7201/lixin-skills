# 讨论—争论目标分流

## R — 原文 (Reading)

> 我们不花时间与他人争论，我们只为了弄清楚事实而讨论。
>
> — 李笑来，前言、第13—15章

---

## I — 方法论骨架 (Interpretation)

对话的表面主题相同，实际目标可能完全不同：查明事实、做出决定、争夺身份胜负、修复关系或履行责任。目标不明时，证据和情绪会在不同赛道上互相错过。

先明确共同目标和仲裁方式。能共同查明事实时，转成可证伪问题与证据；只剩争胜时退出；关系修复时先处理影响和协议；涉及安全、权利、合规时，即使对方不合作也要留痕升级。

“不争论”只是否定无效胜负循环，不能取消必要异议和公共责任。

## A1 — 书中的应用 (Past Application)

### 案例：用不删评论与群规替代临场争论

- **问题**：作者面对公开评论和社群内争吵，不希望每次都靠个人情绪裁决。
- **方法论的使用**：他把“讨论为了弄明白”写入群规，对无仲裁争吵设置预先后果，并保留评论作为证据。
- **结论**：互动目标和停止条件应前置成协议，而非在争执中临时决定。
- **结果**：作者自述外界评价对情绪影响下降；群规的公平性和长期效果无独立数据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 群聊或会议围绕错误数据反复拉扯，需要判断是否仍有共同求真目标。
2. 伴侣、合伙人或同事对话混合事实、身份和关系伤害。
3. 争议涉及安全、权利、合规或举报，不能简单退出。

## E — 可执行步骤 (Execution)

1. **识别实际互动目标**
   - 动作：分别询问各方想得到事实、决定、认同、道歉还是责任处理，并用行为而非口号验证。
   - 完成标准：至少识别一个共同目标，或明确目标不兼容。

2. **选择仲裁与证据规则**
   - 动作：对事实确定来源和可证伪标准，对决定确定权限，对关系确定影响与修复，对责任确定留痕渠道。
   - 完成标准：参与者知道什么能结束分歧；无仲裁时不继续无限争辩。

3. **路由继续、重构、退出或升级**
   - 动作：求真则缩成证据问题，关系则转修复协议，争胜则退出，安全/权利/合规则留痕升级。
   - 完成标准：动作、负责人、时间和停止条件明确。

4. **记录剩余分歧**
   - 动作：区分已确认事实、价值分歧、未知证据和未解决责任，不强行制造共识。
   - 完成标准：各方可准确复述仍不同意什么以及下一节点。

### 整体验收与停止

- **完成标准**：互动目标、仲裁规则、路由动作和剩余分歧均被记录，没有把退出与免责混为一谈。
- **停止条件**：只剩身份争胜、重复人身攻击或仲裁规则被拒绝时停止普通讨论；安全/合规事项转正式升级。
- **复盘方式**：复盘对话何时改变目标、哪些信号未及时识别；把高频场景写成前置协议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 不用来压制安全异议、申诉、举报、劳动权利和必要审查。
- 不要求受害者为维持“理性讨论”继续承受辱骂或危险。

### 作者在书中警告的失败模式

- 把讨论变成迫使对方认同的争论，或在没有共同协议和回执时继续推送复杂信息。

### 作者的盲点 / 时代局限

- 书中的强“不争论”规则可能低估权力不对等与制度救济；现实工作场景必须保留正式异议和升级机制。

### 容易混淆的邻近方法论

- 与 `accurate-restatement-feedback-loop` 的区别：本 Skill先决定互动目标和路由；后者在可沟通目标下准确确认具体问题。
- 与 `problem-ownership-routing` 的区别：本 Skill处理对话目标；后者处理问题的责任、权限和升级节点。
