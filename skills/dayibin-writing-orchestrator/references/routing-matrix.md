# 大宜宾公众号稿型与组合路由

## 证据边界

本矩阵综合三层现有证据：

1. `51-大宜宾公众号正文分型规则（精准版）.md` 的 6 个历史核心分型；
2. `52-大宜宾公众号1000篇全量数据分析（2026-04-05）.md` 的高表现结构与低表现原因；
3. 当前 `wechat-writing-skill` 的 7 条生产类型及 4 条编辑线。

历史数据证明的稳定规律是“本地强对象 + 明确变化 + 用户生活关系”，不是某位名人或外部作者一定带来高阅读。下面的产业、冲突、活动、招聘和专业覆盖是生产路由细化，不冒充 1000 篇数据中的独立统计类目。发布位置会显著影响阅读，不能把头条位收益误算成写法收益。

## 选择规则

- 默认优先保住大宜宾账号适配；只有用户明确需要机制深度、专业报道或另一种成稿气质时，才把外部写稿 Skill 设为唯一写稿人。
- 每次最多展示 3 套组合，且每套只有 1 位人物顾问和 1 位写稿人。
- `none` 是合法人物选择。通知、求助、活动信息不应为显得高级而硬套名人。
- 表中的候选是方向库，不要求每次全部展示。

## 稿型路由

### 1. 城市发展 / 城建交通

识别：道路、桥梁、轨道、片区、老城更新、拆迁改造、公共空间、学校医院配套、经济公报中的城市变化。

- 默认：`munger-perspective` → `wechat-writing-skill` / 大艳。侧重利益、激励、二阶影响和市民可感知变化。
- 产业系统：`zhang-yiming-perspective` → `liurun-skill`。侧重产业、人才、效率、价值链和长期机制。
- 公共韧性：`taleb-perspective` → `banyuetan-skill`。侧重治理、脆弱点、尾部风险和公共利益。
- 工程成本备选：`elon-musk-perspective` → `wechat-writing-skill` / 大艳。仅当材料有成本、工期、方案或工程约束。

事实门：位置、时间、范围、项目状态、影响对象；严格区分规划中、建设中、试运行、已落地。

### 2. 产业经济 / 企业商业

识别：产业链、企业落地、投资、产能、就业、园区、消费品牌、城市竞争、经济数据。

- 本地翻译：`zhang-yiming-perspective` → `wechat-writing-skill` / 大艳。侧重这项产业变化先影响哪些宜宾人。
- 机制分析：`munger-perspective` → `liurun-skill`。侧重钱、成本、效率、激励和长期信任。
- 新闻报道：`zhang-yiming-perspective` → `36kr-skill`。侧重企业动作、数据证据、竞争格局和下一步变量。
- 尖锐评论备选：`munger-perspective` → `banfo-skill`。仅当事实充分且核心是消费陷阱或商业机制。

事实门：主体、金额、时间、来源、项目状态、产能/就业口径；不把签约写成投产。

### 3. 民生通知 / 公共服务

识别：限行、封闭、停演、政策调整、办事提醒、招考、补贴、公共服务变化。

- 默认：`none` → `wechat-writing-skill` / 小美。最快、最清楚、行动入口最明确。
- 普通人处境：`none` → `wechat-writing-skill` / 甘甘。仅当材料有人群困难、共情和互助价值。
- 治理解读：`munger-perspective` → `banyuetan-skill`。仅当政策机制与公共利益本身值得解释。

事实门：生效时间、对象、范围、用户动作、官方入口和限制条件。第一屏先给结果。

### 4. 民生求助 / 维权 / 冲突

识别：寻人、救助、消费纠纷、网友求助、曝光线索、公共争议、现场冲突。

- 求助互助：`none` → `wechat-writing-skill` / 甘甘。侧重当事人保护和读者能怎么帮。
- 事实推进：`munger-perspective` → `wechat-writing-skill` / 大艳。侧重各方利益、已确认事实和待回应问题。
- 公共治理：`taleb-perspective` → `banyuetan-skill`。侧重系统风险、规则和公共边界。
- 社会情绪备选：`munger-perspective` → `caozhi-skill`。仅当事实充分且重点是消费/文化/社会情绪，不用于定责。

事实门：来源、当事人诉求、隐私授权、回应状态。禁止法律结论、责任定性和二次伤害。

### 5. 打卡攻略 / 周边玩法 / 本地美食

识别：景点、江边、花海、古镇、周末路线、街区、美食、老店、体验清单。

- 实用入口：`mrbeast-perspective` → `wechat-writing-skill` / 小美。侧重点击理由、路线、收藏和行动。
- 城市体验：`steve-jobs-perspective` → `wechat-writing-skill` / 加菲。侧重空间体验、旧貌新颜和城市记忆。
- 美食专稿：`mrbeast-perspective` → `chengdu-meishi-skill`。由该 Skill 再按探店、街区、老店、测评、单品或节令选择唯一署名线。

事实门：开放状态、位置、路线、价格、停车、营业时间、现场体验；没有亲测或可靠素材不写完整攻略。

### 6. 情怀回忆 / 城市记忆

识别：老街、老厂、学校、旧地、老照片、城市符号、消失与重逢。

- 默认：`none` → `wechat-writing-skill` / 加菲。侧重地点、旧记忆、现实变化和克制共鸣。
- 设计体验：`steve-jobs-perspective` → `wechat-writing-skill` / 加菲。侧重一个空间为何被记住、变化是否保留核心体验。
- 文化解释：`feynman-perspective` → `caozhi-skill`。侧重把地域文化、怀旧 IP 或城市符号讲清楚，不空喊情怀。

事实门：历史年份、旧称、人物关系、图片内容和变化状态；不能把网络资料改成亲历。

### 7. 人物故事 / 创业成长

识别：普通人、创业者、学校人物、行业人物、返乡者、困境与转折。

- 本地人物：`paul-graham-perspective` → `wechat-writing-skill` / 甘甘。侧重选择、行动、困难及其与宜宾的关系。
- 深度人物：`paul-graham-perspective` → `renwu-skill`。需要场景、时间线、原话、关系和转折；这时 `renwu-skill` 是唯一写稿人。
- 商业创业者：`zhang-yiming-perspective` → `36kr-skill`。侧重产品、组织、行业和商业变量。
- 教育成长备选：`zhangxuefeng-perspective` → `banyuetan-skill`。侧重教育选择、就业结果和普通家庭约束。

事实门：身份、经历、原话、行动、当下处境；缺采访和原话不得写成专访。

### 8. 本地荣誉 / 家乡被看见

识别：外部认证、央视/全国平台、获奖、入选、城市/产品/人物出圈。

- 传播提气：`mrbeast-perspective` → `wechat-writing-skill` / 小美。侧重外部认证、点击理由和可信自豪感。
- 历史含金量：`none` → `wechat-writing-skill` / 加菲。侧重旧脉络、城市记忆和今天的意义。
- 公共文化：`feynman-perspective` → `banyuetan-skill`。侧重把认证含金量和文化价值解释清楚。

事实门：认证机构、奖项级别、时间、对象、评选口径；禁止“第一、唯一、顶级”等无依据表述。

### 9. 活动商业 / 城市资讯

识别：本地活动、商家入驻、品牌发布、展会、节庆、商业预告、城市短资讯。

- 到场转化：`mrbeast-perspective` → `wechat-writing-skill` / 小美。侧重最强看点、适合谁、何时何地和行动入口。
- 产品体验：`steve-jobs-perspective` → `liurun-skill`。侧重产品价值、用户体验和商业机制，适合有足够材料的深稿。
- 注意力机制：`sun-yuchen-perspective` → `caozhi-skill`。只分析营销、叙事和注意力，不采用操纵、碰瓷或虚假承诺。

事实门：时间、地点、对象、费用、名额、优惠规则、限制条件和真实入口。

### 10. 招聘 / 红娘 / 便民服务

识别：岗位、人才引进、招聘会、相亲、公益服务、办事入口。

- 信息服务：`none` → `wechat-writing-skill` / 小美。侧重条件、时间、方式、入口和收藏转发。
- 普通人机会：`zhangxuefeng-perspective` → `wechat-writing-skill` / 甘甘。侧重岗位匹配、就业结果和现实约束。
- 就业公共议题：`zhangxuefeng-perspective` → `banyuetan-skill`。仅当材料足以讨论教育、就业或阶层流动。

事实门：岗位、工资、资格、材料、入口、费用、名额；禁止承诺录用、脱单或收益。

### 11. 观点观察 / 公共议题

识别：城市态度、区域价值、网友建议、社会情绪、教育住房消费、公共政策争议。

- 本地现实：`munger-perspective` → `wechat-writing-skill` / 大艳。侧重事实、利益、激励和普通人影响。
- 公共治理：`taleb-perspective` → `banyuetan-skill`。侧重规则、风险、治理和边界。
- 商业机制：`munger-perspective` → `liurun-skill` 或 `banfo-skill`。前者解释机制，后者做尖锐评论；二选一。
- 消费/情绪：`munger-perspective` → `caozhi-skill`。侧重消费文化、地域迷因或社会情绪。
- 家庭现实备选：`zhangxuefeng-perspective` → `datudou-skill`。侧重住房、教育、家庭账本和普通人后果。

事实门：分清事实、观点、网友意见和推断；禁止替所有宜宾人表态。

## 专业覆盖规则

专业题材优先使用以下组合，不强塞进普通地方号写法：

- AI 工具实测：`andrej-karpathy-perspective` → `kazike-skill`。
- AI 企业/产业：`ilya-sutskever-perspective` 或 `zhang-yiming-perspective` → `36kr-skill`。
- 科学、健康、灾害：`feynman-perspective` → `kepu-zhongguo-skill`；高风险事实必须权威核验。
- 教育就业：`zhangxuefeng-perspective` → `banyuetan-skill` 或 `datudou-skill`，按公共治理与家庭账本二选一。
- 党建活动、获奖、领导调研：`none` → `dangjian-skill`。
- 房产、教育、家庭成本：`munger-perspective` 或 `zhangxuefeng-perspective` → `datudou-skill`。

`trump-perspective` 只在用户明确要求谈判、权力或传播行为预判时作为反方分析，不作为本地公众号常规选题默认项。`naval-perspective` 和 `li-xiaolai-skill` 更适合个人认知/财富/选择文章，默认不用于无个人经历的本地公共稿。
