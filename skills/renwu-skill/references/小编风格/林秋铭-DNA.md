# 林秋铭 DNA

## 样本边界

- 完整互动样本：41
- 置信度：stable
- 主要类型：文娱影视人物(12)、女性家庭与亲密关系(9)、社会公共事件(9)
- 个人前 80% 训练/holdout：见 `data/文章元数据总表.csv`

`stable` 可作为个人小编线叠加；`early` 只能作为轻量增强，不能覆盖账号总风格和文稿类型 DNA。

## 写稿倾向

- 选题入口：更常进入 `文娱影视人物`，适合演员、导演、歌手、综艺人物和作品关系，写人如何被角色、行业和观众重新定义。
- 段落节奏：段落更完整，叙述链更长；段落中位约 84.0 个中文字符。
- 结构习惯：常从可见场景或人物状态进入，再回到较长时间线中的变化。
- 材料习惯：优先让人物行动、关系和选择自己说明问题，少用抽象评语。
- 语言温度：保持克制和体察，不把对象写成观点工具。

## 使用方式

1. 先读账号总风格和对应类型 DNA。
2. 用户明确指定“按 林秋铭 线”时，再叠加本文件。
3. 如果素材类型与 `林秋铭` 的强项冲突，以类型 DNA 为主，本文件只调节节奏和观察角度。
4. 不冒充 林秋铭 本人，不写“我是/本记者认为”。

## 像不像自检

- 是否先有具体人和具体场景，再有判断？
- 是否把人物放回关系和时间里，而不是只写标签？
- 是否保留了复杂性，没有把材料改成鸡汤、控诉或商业稿？
