# 错误转学习复盘

## R — 原文 (Reading)

> “犯错”是动词，不是名词。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸致富需要做的6件事》第2件事

## I — 方法论骨架 (Interpretation)

作者反复强调错误是学习动作，不是身份判决。
这个方法不是鼓励鲁莽，而是把错误转成事实、机制、规则和下一次小实验。
它特别适合创业、写作、销售、投资学习和职业转型，因为这些领域无法只靠读书学会。
复盘必须区分可控错误、不可控波动、违反边界和伦理责任。

## A1 — 书中的应用 (Past Application)

### 案例 1: 犯错并从错误获得新知
- **问题**: 很多人犯错后否认、抱怨或把自己定义为失败者。
- **方法论的使用**: 作者把犯错视为动作，要求承认、学习并修改行为。
- **结论**: 错误只有被提炼成规则才变成资产。
- **结果**: 失败不再只是情绪事件，而是训练材料。
### 案例 2: 怀基基第一笔房产纠错
- **问题**: 作者早期交易出现负现金流和判断错误。
- **方法论的使用**: 他从交易失败中学习现金流、融资和尽调。
- **结论**: 小额错误能换来昂贵但可承受的经验。
- **结果**: 后续投资更重视现金流和控制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户犯错、亏损、项目失败、被拒绝后陷入羞耻或抱怨。
2. 用户要复盘一次学习、创业、写作、销售或投资尝试。
3. 用户害怕行动，只想继续准备以避免犯错。

### 语言信号 (用户的话里出现这些就应激活)

- "我失败了"
- "犯错了怎么办"
- "怎么复盘"
- "亏了"
- "被拒绝"
- "不敢行动"

### 与相邻 skill 的区分

- 与 `control-prior-leverage-check` 的区别: 本 skill 事后复盘和学习；后者事前控制杠杆风险。
- 与 `work-to-learn-skill-stack` 的区别: 本 skill 处理一次错误；后者选择长期训练场。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **降身份化**
   - 操作: 把“我是失败者”改写成“我做了一个产生某结果的动作”。
   - 完成标准: 情绪和事实分开。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **还原事实**
   - 操作: 记录目标、假设、行动、结果、代价、可控/不可控因素。
   - 完成标准: 复盘基于事实。
 3. **提炼规则**
   - 操作: 找出一个下次可检查的规则、边界或信号。
   - 完成标准: 产出可复用句子。
 4. **设计小实验**
   - 操作: 下一步只做可逆、低成本、能验证新规则的动作。
   - 完成标准: 错误变成下一次实验。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户试图用复盘掩盖违法、欺骗或伤害他人的责任。
- 用户处在严重心理危机中；应优先安全和专业支持。

### 作者在书中警告的失败模式

- 把错误当身份羞耻，逃避再次行动。
- 把错误浪漫化，不设边界，重复同一种代价。

### 作者的盲点 / 时代局限

- 作者强调从失败学习，可能低估某些错误的不可逆代价。
- 高杠杆、法律、健康和关系错误不适合用大代价试错。

### 容易混淆的邻近方法论

- 与 `control-prior-leverage-check` 的区别: 本 skill 事后复盘和学习；后者事前控制杠杆风险。
- 与 `work-to-learn-skill-stack` 的区别: 本 skill 处理一次错误；后者选择长期训练场。
