# 赛点机会资源集中

## R — 原文 (Reading)

> "小机会随便错过，大机会死命抓住。"
>
> — 粥左罗，第一章 第二节 赛点思维

## I — 方法论骨架 (Interpretation)

机会不是平均分布的，资源也不该平均分配。  
这个方法先判断一个机会是否会改变长期走势：进入新赛道、获得关键客户、形成代表作、连接高价值网络、改变竞争变量。  
如果只是普通收益，就低成本处理；如果是赛点，就允许短期提高投入强度，同时压低其他普通任务。  
关键不是"冲动 All in"，而是把机会不对称性、资源上限和退出条件写出来。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者进入新媒体行业
- **问题**: 作者处在普通职业起点，需要寻找能放大个人努力的机会。
- **方法论的使用**: 把新媒体视为行业杠杆和人生大机会，集中投入内容、业务和能力建设。
- **结论**: 新媒体不是普通工作任务，而是可改变成长曲线的赛点。
- **结果**: 作者将个人成长经验沉淀为课程、写作和公司经营资产。

### 案例 2: 一年打磨课程代表作
- **问题**: 知识付费课程可能成为长期品牌资产。
- **方法论的使用**: 作者在 2017 年基本集中做课、写课、录课、讲课。
- **结论**: 大机会需要超常准备，而不是平均兼顾所有机会。
- **结果**: 课程成为个人品牌和商业增长的重要资产。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 普通工作和一个可能带来关键客户/作品/赛道入口的项目冲突。
2. 觉得某个机会很大，但不确定是否值得牺牲短期稳定安排。
3. 内容、课程、产品或创业窗口期短，需要决定是否集中资源。
4. 正在平均分配时间，担心错过真正改变曲线的机会。

### 语言信号

- "这是不是一个大机会?"
- "要不要临时 All in / sprint?"
- "普通任务和关键项目撞了"
- "我怕错过窗口期"

### 与相邻 skill 的区分

- `growth-option-standard-screen` 先筛出候选；本 skill 只处理已具备证据的关键机会。
- `explore-exploit-mode-switch` 判断探索/利用模式；本 skill 判断是否对单个赛点提高资源密度。
- `variable-competition-design` 用于设计获胜变量；本 skill 决定是否把资源押到该变量或机会。

## E — 可执行步骤 (Execution)

1. **判定赛点属性**
   - 检查机会是否改变: 赛道、客户质量、作品资产、关系网络、收入结构或学习曲线。
   - 完成标准: 至少 2 个长期指标有明确证据，不只是兴奋感。

2. **设计资源集中期**
   - 明确冲刺周期、投入上限、被压低的普通任务和不可牺牲的底线。
   - 判停条件: 若机会收益只靠他人承诺、平台红利或无法验证的收入预期，先降级为小实验。
   - 完成标准: 有 1 个主目标、3 个以内关键动作和每日/每周验收。

3. **设复核和退出**
   - 记录领先指标、实际反馈、机会成本和身体/现金流压力。
   - 完成标准: 到复核日必须选择继续、降级、转向或停止。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 还没有备选和证据，只是被"限时机会"刺激时，先回到筛选。
- 涉及杠杆投资、借债、裸辞或高风险承诺时，必须先做财务/法律/安全边界。
- 所谓大机会要求牺牲健康、照护责任、诚信或合法合规时，停止。

### 作者在书中警告的失败模式

- 把所有机会平均对待，结果关键机会没有获得足够资源。

### 作者的盲点 / 时代局限

- 书中机会样本强依赖新媒体窗口期，不能把平台红利误读成可复制个人能力。
- 成长和变现绑定较强，不能把收入跃迁作为所有人的唯一成长标准。

### 容易混淆的邻近方法论

- 与长期坚持不同: 赛点是短期资源密度调整，不是无期限硬扛。
- 与投资决策不同: 本 skill 处理学习/工作/创业行动资源，不提供金融建议。
