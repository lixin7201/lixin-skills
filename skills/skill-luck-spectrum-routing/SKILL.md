# 技巧—运气连续谱路由

## R — 原文 (Reading)

> 技巧起着百分之百的作用
>
> — 李笑来，第6章｜6.2 大多数主动的人竟然不知道边界

---

## I — 方法论骨架 (Interpretation)

不同活动里，技巧与运气的权重不同。把所有结果都归功努力会导致过度自信，把所有结果都归因运气又会放弃可训练空间。

先定义结果指标和时间窗口，再用可重复性、反馈速度、对手影响、外部冲击和样本方差定位。技巧端优先刻意训练和快速反馈；运气端优先缩小单次押注、扩大样本、分散暴露并保留失败空间。

连续谱不是给人贴标签，而是决定资源配置和对单次结果的解释方式。

## A1 — 书中的应用 (Past Application)

### 案例：奥沙利文改变同代选手的冠军概率

- **问题**：作者用奥沙利文的长期统治说明，个人努力之外，同一时期是否出现极端强手也会改变其他选手的可达结果。
- **方法论的使用**：作者把该经历用于检查外部趋势识别、目标可达性校准，而不是只展示结果。
- **结论**：案例能说明方法如何进入真实行动，但不能从一个成功样本推出普遍因果。
- **结果**：同时代竞争者的冠军空间被显著压缩，迫使他们调整目标或退出竞争。
- **证据位置**：`candidates/cases.md` c06，第5章（PDF p50—51）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一次成功或失败难以区分能力和运气
2. 选择训练还是扩大样本与分散
3. 高波动领域需要决定押注大小

### 语言信号

- “这主要靠努力还是运气”
- “一次成功能证明能力吗”
- “我该练技术还是多试几次”
- “skill luck spectrum”

### 与相邻 skill 的区分

- 与 `decision-node-error-multiplier-audit` 的区别：本 Skill 判断结果机制中技巧和运气的权重；后者审计动作节点数量。
- 与 `correctness-nonconsensus-evidence-matrix` 的区别：本 Skill 路由训练与押注；证据矩阵评估主张正确性和共识度。

## E — 可执行步骤 (Execution)

1. **定义结果与窗口**
   - 动作：写出要解释的结果、观察周期、可控投入和外部因素。
   - 完成标准：指标可观察且不以一次输赢概括长期能力。

2. **定位连续谱**
   - 动作：检查重复表现、反馈速度、对手与环境冲击、样本方差和可训练动作。
   - 完成标准：给出技巧/混合/运气主导及证据，不强求虚假百分比。

3. **选择资源策略**
   - 动作：技巧端设计训练反馈；混合区兼顾训练与风险预算；运气端缩押注、扩样本、分散并留退出。
   - 完成标准：训练、样本、押注和失败空间均有明确安排。

4. **用多轮结果更新**
   - 动作：按预定窗口比较过程质量与结果分布，更新连续谱位置。
   - 完成标准：至少一次更新不由单次极端结果驱动。

### 整体验收与停止

- **完成标准**：有机制证据支持的谱系定位，以及匹配的训练、样本、押注和复盘方案。
- **停止条件**：最大损失不可承受、样本无法合法获得，或安全健康风险出现时停止押注。
- **复盘方式**：按多轮样本复盘可控动作是否改善、方差是否下降，并区分过程正确与结果幸运。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 不要用运气解释逃避训练和责任
- 不以幸存者的结果反推所有人可复制

### 作者在书中警告的失败模式

- 在运气主导处重仓一次结果，或在技巧主导处只靠增加次数不改善能力。

### 作者的盲点 / 时代局限

- 技巧与运气常相互作用且随时间变化；书中例子不能给出普适比例，需用领域数据校准。

### 容易混淆的邻近方法论

- 与 `decision-node-error-multiplier-audit` 的区别：本 Skill 判断结果机制中技巧和运气的权重；后者审计动作节点数量。
- 与 `correctness-nonconsensus-evidence-matrix` 的区别：本 Skill 路由训练与押注；证据矩阵评估主张正确性和共识度。
