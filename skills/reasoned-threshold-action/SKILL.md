# 有理有据阈值行动

## R - 原文依据

> 想先看到结果再行动的人往往无法看到结果。

来源：周岭《认知觉醒：开启自我改变的原动力》，第七章第三节：行动力。本 Skill 依据已抽取文字版、候选卡片和 Stage 1.5 验证记录生成，不凭记忆使用。

## I - 解释

- 行动前完全看见结果是不现实的，关键是区分盲目坚持和有证据的承诺。
- 阈值能防止两种错误：还没做够就放弃，以及已经无效还硬撑。
- 它把“我再试试”改造成“在什么证据前坚持到哪里”。

## A1 - 案例与反例

正例：
- 作者提到有些人练习或改变还没到足量，就因为看不见结果而停止。
- 连续行动160天一类案例说明，成长常需要跨过前期无反馈区，但不能没有复盘。

反例：
- 三天没效果就换方法，永远停在起步期。
- 完全没有依据却迷信坚持，把沉没成本误认为毅力。

## A2 - 迁移与边界

适合调用的触发条件：
- 方法来源可信、逻辑合理，但短期结果不明显。
- 你频繁换课、换工具、换项目，却没有一个执行到足量。
- 团队因早期数据平淡想放弃一个仍需验证的方向。
- 写作、健身、学习等任务需要跨过初期无反馈阶段。

不适用或需要降级的边界：
- 不是盲目坚持；没有证据、代价过高或风险不可逆时不能用。
- 创业验证的阈值必须结合真实用户或市场信号。
- 个人成长方法若引发健康问题，应优先停止。

## E - 执行协议

触发后按以下步骤执行：

1. **确认依据**：写明这个方法为什么值得试：来源、逻辑、案例或小样本证据。
2. **设行动阈值**：定义最小周期和最小次数，如14天、10篇、30次访谈。
3. **设观察指标**：选择过程指标和结果指标，不只盯最终结果。
4. **执行不评判**：阈值内只按计划行动和记录，不每天重判方向。
5. **到点决策**：达到阈值后基于证据继续、调整或停止。

完成标准：
- 阈值前写清依据、周期、次数、指标和停止条件。
- 阈值内完成至少80%的承诺动作。
- 到点有证据支持继续、调整或停止，而不是凭情绪。

停止条件：
- 方法没有基本依据、只靠鸡血或权威崇拜时，不进入坚持。
- 出现明显身体、财务、法律或关系伤害时，提前停止。
- 如果行动阈值太大导致无法启动，缩小到一轮小实验。

复盘方式：
- 复盘依据是否仍成立，指标是否真实反映目标。
- 记录放弃冲动出现的时间点和原因。
- 把有效方法固化为下一轮技能训练，失效方法写入停止台账。

## B - 行为化提示

当用户的请求符合触发条件时，先把问题改写为“当前触发是什么、我要获得什么证据、下一步动作是什么”。输出时不要只给励志总结，必须给出可执行步骤、完成标准、停止条件和复盘方式。若请求触及医疗、法律、财务安全、人身安全、严重心理危机或组织权力伤害，先提示边界并转向专业支持、现实求助或低风险准备动作。
