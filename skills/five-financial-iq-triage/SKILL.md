# 五种财商问题分诊

## R — 原文 (Reading)

> 5种基本的财商：赚更多的钱，守住你的钱，预算你的钱，撬起金钱的杠杆，改善你的财务信息。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸提高你的财商》第2章

## I — 方法论骨架 (Interpretation)

这个方法把“缺钱”拆成五类问题: 创造收入、保护收入、预算配置、杠杆控制、信息质量。
同一个症状可能来自不同财商缺口，例如月光可能是预算问题，也可能是收入问题或债务结构问题。
分诊的价值是防止拿错药: 该增收时不要只节流，该补信息时不要盲目加杠杆。
它适合做个人、家庭、项目和创业现金流的第一轮诊断。

## A1 — 书中的应用 (Past Application)

### 案例 1: 钱多不能解决坏模式
- **问题**: 很多人收入提高后仍陷入财务压力。
- **方法论的使用**: 作者把问题拆成五种财商，要求先找能力缺口。
- **结论**: 不是所有问题都叫缺钱。
- **结果**: 行动从笼统焦虑变成具体训练清单。
### 案例 2: 错误信息导致错误决策
- **问题**: 人们把建议、新闻、销售话术和事实混在一起。
- **方法论的使用**: 第五财商要求改善财务信息，区分事实、观点和利益结构。
- **结论**: 信息质量会决定风险大小。
- **结果**: 顾问、媒体和课程建议都需要来源审计。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户财务问题很乱，不知道先解决收入、预算、债务还是信息。
2. 用户做项目、创业或家庭财务复盘，需要分类问题。
3. 用户把“缺钱”当总解释，需要拆成可训练能力。

### 语言信号 (用户的话里出现这些就应激活)

- "我财务哪里出问题"
- "赚不到钱"
- "守不住钱"
- "预算混乱"
- "财商怎么提高"
- "信息太乱"

### 与相邻 skill 的区分

- 与 `surplus-budget-pay-yourself-first` 的区别: 本 skill 是分诊；预算问题确认后才进入后者。
- 与 `control-prior-leverage-check` 的区别: 本 skill 判断杠杆是否是问题之一；后者专门检查杠杆控制权。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **描述症状**
   - 操作: 记录当前最痛的财务症状和三个事实数字。
   - 完成标准: 不是泛泛说焦虑。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **五类分诊**
   - 操作: 逐项判断收入、保护、预算、杠杆、信息哪个最弱。
   - 完成标准: 至少选出主因和次因。
 3. **匹配处方**
   - 操作: 为主因选择一个行动: 增收实验、成本保护、预算重排、降杠杆、信息核验。
   - 完成标准: 行动对应缺口。
 4. **复盘指标**
   - 操作: 设定 30 天观察指标，例如结余率、债务下降、信息来源数、报价次数。
   - 完成标准: 能判断是否改善。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只想讨论宏观经济、货币政策或作者观点。
- 用户已明确是某个债务或预算执行问题时，可直接调用更窄 skill。

### 作者在书中警告的失败模式

- 把所有财务问题都归因于收入低。
- 在信息不清、预算失控时加杠杆或买复杂产品。

### 作者的盲点 / 时代局限

- 五种财商是作者框架，不是学术诊断量表。
- 涉及税务、法律、保险、投资产品时需要专业与实时资料。

### 容易混淆的邻近方法论

- 与 `surplus-budget-pay-yourself-first` 的区别: 本 skill 是分诊；预算问题确认后才进入后者。
- 与 `control-prior-leverage-check` 的区别: 本 skill 判断杠杆是否是问题之一；后者专门检查杠杆控制权。
