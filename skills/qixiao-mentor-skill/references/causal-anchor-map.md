# 因果锚点地图

| 场景 | 优先命名的因果 | 常见误诊 | 可验证信号 |
|---|---|---|---|
| 项目太复杂、迟迟不做 | 把大词当成高门槛完整形态，没有缩到最小交易 | 继续补更多课程和理论 | 是否能写出一个最小产品、一个对象、一个成交动作 |
| 找不到项目 | 被“热门项目”概念框住，没有从需求和产品形态反推 | 认为市场没有机会 | 平台分类、真实购买、用户问题中能否找到重复需求 |
| 选项很多却都不合适 | 既要喜欢、擅长、高利润、低风险、快回报 | 继续寻找完美赛道 | 是否明确放弃至少一个目标 |
| 学了很多仍没结果 | 把“解答”误当成“解决”，实践重复与反馈不足 | 归因于还没学够 | 行动次数、真实用户接触、复盘记录是否增加 |
| 不敢开始或收费 | 参照物错、服务范围过大、把吸引等同于必须成交 | 归因于性格不自信 | 能否缩小对象、价格、交付范围并筛选用户 |
| 内容/产品无人接受 | 自我表达与用户关心错位 | 认为用户不懂好东西 | 评论、点击、成交、留存、访谈中是否出现同一需求 |
| 看见异常机会 | 异常行为背后存在具体任务或痛点 | 只模仿表面内容 | 能否解释“谁、为什么、在什么约束下需要它” |
| 难以坚持 | 预期过高、参照物不匹配、缺少他律与阶段反馈 | 归因于意志力差 | 同工龄比较、同伴机制、小成果奖励是否建立 |
| 过度工作仍焦虑 | 商业指标压过健康、关系和自由目标 | 用更高营收解决焦虑 | 停止营收动作后是否仍能维持生活目标与自我评价 |

## 案例归纳五步

1. 记录具体异常：搜索量、评论、购买、求助、失败或重复问题。
2. 还原约束：谁在什么场景下必须完成什么任务。
3. 抽象需求：不要停在具体商品或内容形式。
4. 变换载体：资料、社群、咨询、课程、工具、服务等只是需求载体。
5. 做最小验证：先验证真实需求与交付，再扩张。

## 置信度

- 两个以上独立训练事件支持：中等。
- 仅一个训练事件或个人经历支持：低，必须标注。
- 没有训练事件、仅靠通用常识补充：归入“系统建议”，不得称为七小式结论。
