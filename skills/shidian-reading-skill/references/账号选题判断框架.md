# 十点读书选题判断框架

## 一句话门槛

选题必须同时回答：**谁正在为什么事难受；哪一组人物或材料能让这份难受被看见；读完后他能换一个什么判断或动作。**

## 六项筛选

每项 0–2 分，低于 8 分先补材料，不直接写长文。

1. **人群清晰**：能否说出具体处境，而不只是“所有人”。
2. **痛点可见**：是否有一个可观察的冲突、选择或代价。
3. **材料承载**：是否有可核验、可展开的主材料，而非只够写标题。
4. **机制增量**：能否解释一层读者原本没看见的关系机制。
5. **行动落点**：能否落到边界、选择、习惯或下一步，而非空泛鼓励。
6. **伦理与事实**：是否避免消费悲剧、伪医学、羞辱与未经证实的归因。

## 选题角度生成

从材料中分别提出四个问题，再选最有张力的一条：

- **处境**：普通人在哪个瞬间会认出自己？
- **关系**：谁在付出，谁在逃避，边界在哪里？
- **代价**：继续这样下去，会失去什么？
- **转向**：真正可改变的最小动作是什么？

同一材料至少生成两个不重叠角度。若两个角度只是换标题、案例顺序和“三个道理”，判为同构，重做。

## 题材路由

- 有明确书、剧、电影及人物弧：`书影解读`。
- 有新闻时效与公共争议：`热点社会观察`。
- 关系冲突核心在伴侣：`婚恋关系`；核心在父母子女：`亲子家庭`。
- 主体是完整生平与选择：`人物故事`。
- 主要回答身体风险：`健康养生`，启用高风险核验门。
- 主要回答收入、存款、职业选择：`金钱职场`。
- 其余按 `人际处世 / 成长疗愈 / 观点与生活方式 / 节气生活美学` 中最能决定结构的一类。

## 杀停条件

- 只有一个流行观点，没有可用材料。
- 标题承诺大于正文证据。
- 关键事实无法核验，且删除后文章不成立。
- 必须虚构第一人称经历才能打动人。
- 只能靠复制训练语料的标题、情节或句子来“像”。
