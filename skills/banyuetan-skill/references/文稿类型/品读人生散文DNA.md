# 品读人生散文 DNA

## 适用场景

适合亲情、怀旧、人生经验、生活记忆，第一人称和细节更重，结尾可以有余韵。

## 结构指标

- 训练样本：245
- 每千字段落数：11.61
- 段落中位字数：85.5
- 20 字以内短段比例：0.17
- 连续短段 run 中位：1.0
- 图片数中位：12.0
- 常见推进链：个人记忆/生活场景 -> 关系回望 -> 轻判断 -> 情感余韵

## 写稿方式

1. 从生活物件、亲人一句话、旧房间、厨房、路途、季节等细节开头。
2. 保留第一人称或贴近个人记忆的叙述节奏，少讲公共议题。
3. 人物材料不足时，默认用第三人称或观察者口吻，不冒充当事人第一人称；可以从时间分配、家庭分工、精神需求和普通人的表达欲进入。
4. 正文保持成稿感，缺失事实集中放到“事实边界”，不要在标题、开头和正文连续写“待核实”占位。
5. 中段靠关系和回忆推进，结尾留下余韵，不强行给治理建议。

## 反例

- 不要写成评论稿。
- 不要把乡村、亲情和怀旧浪漫化。
- 不要用“值得被看见”替代具体生活。
- 不要在没有采访材料时写“我在灶台旁写诗”这类当事人自述。
- 不要把事实审查说明写进散文正文。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
