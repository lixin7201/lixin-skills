# 不良债务滚动清理

## R — 原文 (Reading)

> 每偿清一项债务，就把偿清该项债务的全部金额加到下一个偿还金额最少的债务上。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸致富需要做的6件事》第5件事

## I — 方法论骨架 (Interpretation)

这个方法处理已经形成的不良债务，重点是止血、排序、集中火力和滚动释放现金流。
它借用书中的债务滚雪球逻辑: 先锁定一个目标，清掉后把释放出的月供滚入下一项。
它更像行为执行程序，不是最优金融数学证明；若利率差异极大，要同时看利率和违约风险。
适合从混乱债务中恢复掌控感，但必须避免继续新增消费债。

## A1 — 书中的应用 (Past Application)

### 案例 1: 先搞清楚不良债务坑有多深
- **问题**: 很多人知道债务存在，却不愿把明细完整列出来。
- **方法论的使用**: 作者要求先列出所有不良债务、最低还款和余额。
- **结论**: 债务清理从面对真实数字开始。
- **结果**: 清理计划才能从焦虑变成排序问题。
### 案例 2: 还清一项后滚入下一项
- **问题**: 多笔债务同时还会让人感觉没有进展。
- **方法论的使用**: 先清最小债务，释放的金额继续加入下一项。
- **结论**: 现金流释放要继续滚动，不能被新消费吃掉。
- **结果**: 书中称坚持者几年内会感到财务轻松。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户有多笔不良债务，不知道先还哪一笔。
2. 用户想停止信用卡、消费贷、分期继续扩张。
3. 用户需要一个可坚持的还债节奏和复盘表。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **冻结新增**
   - 操作: 停止新增消费债、分期和借新还旧，保留必要支付工具。
   - 完成标准: 债务池不再扩大。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **列全清单**
   - 操作: 列余额、利率、最低还款、逾期风险、担保/抵押和心理压力。
   - 完成标准: 每笔债务都有事实字段。
 3. **排序执行**
   - 操作: 默认先清余额最小且无担保的高压债；利率极高或逾期风险高的提前处理。
   - 完成标准: 排序理由明确。
 4. **滚动复盘**
   - 操作: 清掉一笔后，把原月供和额外还款加入下一笔，不释放给消费。
   - 完成标准: 每月更新余额和自由现金流。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户问是否应该新增贷款或融资；先用债务筛选。
- 用户已逾期、被起诉或涉及破产；需要专业法律/债务咨询。

### 作者在书中警告的失败模式

- 只做债务合并，消费习惯不变，债务换壳后继续膨胀。
- 还清一笔后把释放现金流拿去升级消费。

### 作者的盲点 / 时代局限

- 书中滚雪球更重视行为动能；若利率极端悬殊，需结合利息成本优化。
- 不同地区催收、征信和破产规则不同，不能替代专业建议。

### 容易混淆的邻近方法论

- 与 `good-bad-debt-screen` 的区别: 本 skill 处理已存在的不良债务；后者判断新债或债务性质。
- 与 `surplus-budget-pay-yourself-first` 的区别: 本 skill 先止血清债；后者在现金流稳定后建立盈余和资产投入。
