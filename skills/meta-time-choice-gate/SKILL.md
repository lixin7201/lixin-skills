# 元时间选择节点守门

## R - 原文依据

> 我们在每个选择节点上，都有一个暂停几秒的机会。

来源：周岭《认知觉醒：开启自我改变的原动力》，第二章第二节：元认知；第一章第一节：三重大脑。本 Skill 依据已抽取文字版、候选卡片和 Stage 1.5 验证记录生成，不凭记忆使用。

## I - 解释

- 元认知不是抽象哲学，而是在本能反应发生前识别“我正在选择”。
- 很多失败不是大计划失败，而是无数微小选择节点失守。
- 守门的核心是提前设计替代动作，让显意识有时间接管本能。

## A1 - 案例与反例

正例：
- 作者提醒自己早起后不立刻摸手机，而是利用一小段停顿进入计划动作。
- 工作开头先做最小启动动作，能减少拖延带来的情绪解释。

反例：
- 把刷手机解释成“休息”，但没有明确停止点，结果破坏了原计划。
- 情绪上头时立刻发消息、辞职或下单，把短暂冲动固化成长期后果。

## A2 - 迁移与边界

适合调用的触发条件：
- 开工、学习、写作前，总会先点开短视频、微信或网页。
- 想回复、反驳、购买、放弃之前，身体已经要行动了。
- 知道正确动作是什么，但启动前的几秒总被旧习惯接管。
- 一天结束后发现损失来自很多小岔路，而不是一个大错误。

不适用或需要降级的边界：
- 它适合微选择，不适合复杂战略决策的全套分析。
- 不能把所有自发行为都当敌人，否则会形成过度控制。
- 当冲动来自严重情绪或关系伤害时，需要结合情绪重构和外部支持。

与相邻 Skill 的关系：
- `written-clarity-action-planner` (composes-with)：清晰计划能减少选择节点数量。
- `focus-rest-energy-cycle` (supports)：能量不足会让选择节点更易失守。
- `mental-bandwidth-scarcity-triage` (fallback-to)：情绪峰值和稀缺压力下先降负荷。

## E - 执行协议

触发后按以下步骤执行：

1. **命名节点**：写下最常失守的具体瞬间，如“打开电脑后的第一分钟”。
2. **插入停顿**：在节点前设置3-10秒暂停，可以是深呼吸、站起或看一张提示卡。
3. **预设替代动作**：为节点绑定一个小动作，如打开文档、写标题、倒计时5分钟。
4. **降低入口阻力**：提前关闭干扰入口，把替代动作放在视觉中心。
5. **记录一次选择**：只记录是否在节点上醒来，不记录情绪好坏。

完成标准：
- 已识别一个具体选择节点。
- 节点前有可执行停顿动作，节点后有替代动作。
- 连续三次在节点上至少醒来一次，即视为本轮有效。

停止条件：
- 紧急安全、医疗或求助场景不做停顿仪式，直接处理。
- 如果节点失守后进入自责，立刻停止复盘，改为下一次提示设计。
- 若节点背后是长期过劳或睡眠不足，优先修复能量。

复盘方式：
- 每日记录一个“我本来会自动做什么，但今天看见了它”的瞬间。
- 每周只优化一个节点，避免把所有行为都纳入管控。
- 检查替代动作是否小到不需要意志力。

## B - 行为化提示

当用户的请求符合触发条件时，先把问题改写为“当前触发是什么、我要获得什么证据、下一步动作是什么”。输出时不要只给励志总结，必须给出可执行步骤、完成标准、停止条件和复盘方式。若请求触及医疗、法律、财务安全、人身安全、严重心理危机或组织权力伤害，先提示边界并转向专业支持、现实求助或低风险准备动作。
