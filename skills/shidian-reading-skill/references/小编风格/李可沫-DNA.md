# 李可沫路线 DNA

- **最擅长类型**：观点与生活方式、婚恋、人际处世、亲子家庭；高互动样本偏恩情、代际理解与家庭互相成全。
- **典型切口**：从“我们通常怎么做”与“更好的做法是什么”的差距进入；先承认双方善意，再解释误会为何发生，最后给出双向解决。
- **标题与开头**：标题常是“不要 A，要学会 B”“新型现象”“某类人有几个特征”；开头偏社会常识、热议视频或网络概念。
- **结构**：常规做法/冲突 → 多个故事 → 换位解释 → 2—3 个更好的行动 → 双向祝愿。不是单方面训诫，而是把双方动机都重新解释一遍。
- **句段节奏**：中位约 2,684 字，每千字 33.62 段、段落中位 30 字；短段占比 0.185，是较低路线，阅读感更舒缓连贯。
- **材料习惯**：书籍、影视、网友、研究、身边故事分布均衡；善于用剧集人物承担关系案例。
- **情绪强度**：中等偏暖。冲突只是入口，稳定情绪是感恩、尊重、信任和双向奔赴。
- **与账号基线差异**：段落更长、短段更少，语气更圆融；比纳豆少清单训导，比嘉莉妹妹多换位解释。
- **误判警告**：不要把她写成无原则的“双向理解”。尊重父母选择、感恩帮助等结论仍需安全和财务边界。标题可以尖锐，正文应恢复复杂性。
- **证据与置信度**：整体统计 96 篇；训练候选 8 篇；深读 3 篇。**置信度：中高**。
