# 热点社会观察 DNA

- **适用场景**：刚发生的公共事件、社会趋势、热门人物或影视热点，需要从“发生了什么”过渡到“这与普通人有什么关系”。
- **标题 DNA**：人物/事件 + 强数字 + 情绪反转；时间节点 + 重大进展 + 情绪句；收入/生活数据提问 + “看完你就不焦虑”。数字承诺和热点事实加情绪最突出。
- **开头 DNA**：先给最新结果、权威来源或热搜画面，再补公众反应。样本统计虽识别为引用开路居多，但生产上必须把可核验的事件事实放在最前。
- **推进链**：最新事实 → 时间线/关键细节 → 受影响的具体人 → 网络争议或普遍处境 → 价值反转 → 宏观意义/普通人动作 → 评论话题。
- **材料偏好**：官方通报、当事人发言、新闻现场、公开数据、网友评论、人物背景。热点可叠加影视/人物故事，但事实层必须先于价值层。
- **段落节奏**：句长中位 27 字，但全量样本短段比例 0.317、每千字约 36 段，较账号平均更碎；时间线和关键数字单独成段，快速推进。
- **情绪温度**：8—9/10。允许震惊、悲痛、振奋，但必须与证据同速；事实不确定时情绪自动降档。
- **结尾 DNA**：从个案落到公共常识、个人行动或纪念祝愿；可以邀请读者谈感受，但不把悲剧当互动诱饵。
- **事实核查**：日期、数字、票房、体重、判决、事件进展、官方表态、政策与统计必须做发布前复核并标注截止时间。涉及死亡、犯罪、国际事件时至少双源核验；禁止把推测写成定论。
- **像 / 不像警告**：像的是“快事实、慢结论”；不像标题先把情绪拉满，正文靠旧闻、二手截图和未经证实的细节填充。国家、群体、当事人价值判断不能替代证据。
- **深读样本与置信度**：`8623c80c08ae4f27`《贾玲“整容式”近照曝光：暴瘦100斤，颜值逆天，我却笑不出来》、`4bed4bf142916945`《被困1028天，孟晚舟一条朋友圈看哭所有人：中国，我回家了！》、`576a3abd31418a36`《月薪6000在中国什么水平？看完你就不焦虑了》、`27fb4e6c73bbdeee`《那一晚，他意外身亡！全网刷屏：“这么多人爱过你，一路走好……”》。**置信度：中高（结构）/中（时效事实）**；叙事结构鲜明，但事实随时间变化，不能直接复用旧稿判断。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
