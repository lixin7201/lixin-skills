# 好/坏负面情绪行动分流

## R — 原文 (Reading)

> "负面情绪也有'良性'与'恶性'之分。"
>
> — 高杉尚孝，总论

## I — 方法论骨架 (Interpretation)

目标不是立刻变开心，而是让负面情绪不要导向坏行动。  
作者区分坏负面情绪和好负面情绪: 不安、愤怒、情绪低落、罪恶感容易导向逃避、攻击、封闭、自我否定；担心、不快、悲伤、自责则更容易导向准备、协商、分享和反省。  
这个方法先识别当前情绪会把你推向什么动作，再把它换成更有行动功能的负面情绪。  
情绪不必消失，但必须接一个改善现实的行动。

## A1 — 书中的应用 (Past Application)

### 案例 1: 松井销售目标未达
- **问题**: 松井因目标未达陷入不安，影响吃饭和睡眠。
- **方法论的使用**: 作者把不安转成担心，再连接请教和改变拜访方法。
- **结论**: 好的负面情绪能保留行动能力。
- **结果**: 松井能继续工作和调整方法。

### 案例 2: 园部错失晋升
- **问题**: 园部未获晋升后情绪低落，想辞职。
- **方法论的使用**: 作者把情绪低落转为悲伤，并指出机会仍在。
- **结论**: 悲伤可以连接休养、学习和能力改进。
- **结果**: 园部从终局化解释中退出。

### 案例 3: 小林创业失败
- **问题**: 小林公司倒闭后给自己贴上终局标签，想逃离熟人圈。
- **方法论的使用**: 改为承认悲伤并分享经验，不把失败等同整个人。
- **结论**: 失败后的好负面情绪可以连接分享和反省。
- **结果**: 从逃离现实转向面对现实。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 被客户、老板、读者或同事批评后想攻击、删除、逃避。
2. 目标未达、晋升失败、创业失败后自我否定。
3. 负面情绪很强，但用户仍需要决定一个下一步。
4. 用户不想被"积极一点"敷衍，希望保留真实情绪又能行动。

### 语言信号

- "我又气又想删项目"
- "被批评后崩了"
- "我是不是彻底失败了"
- "good negative emotion / emotion to action"

## E — 可执行步骤 (Execution)

1. **命名情绪和坏行动倾向**
   - 写出当前情绪: 不安、愤怒、情绪低落、罪恶感、羞耻、恐惧。
   - 完成标准: 同时写出它正在推你做的坏行动: 逃避、攻击、封闭、自我否定、冲动辞职/删除。

2. **转换为好负面情绪**
   - 不安 -> 担心；愤怒 -> 不快；情绪低落 -> 悲伤；罪恶感 -> 自责。
   - 判停条件: 若有自伤风险、持续失眠、无法工作生活、严重身体症状或霸凌/违法压力，停止自助并求助。
   - 完成标准: 新情绪不要求开心，但能支持一个改善动作。

3. **绑定正面行动**
   - 担心 -> 准备；不快 -> 协商；悲伤 -> 休养/分享；自责 -> 反省/补救。
   - 完成标准: 选一个 24 小时内可做的行动，并设置不做什么的禁止动作。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 自伤念头、严重焦虑/抑郁、持续功能损害、明显身体症状或临床风险。
- 压力来自霸凌、歧视、过劳、违法命令、骚扰或安全威胁。
- 需要立即法律、医疗、心理治疗、劳动保护或第三方介入。

### 作者在书中警告的失败模式

- 坏负面情绪导向逃避、攻击、自我封闭或自我否定。
- 强行积极思考往往难以持久。

### 作者的盲点 / 时代局限

- 案例多为虚构训练对话，真实情绪困境可能不能一次改写解决。
- 组织不能把此方法当成员工适应不合理压力的工具。

### 容易混淆的邻近方法论

- 情绪分流不是情绪压制；负面情绪可以保留。
- 行动分流不是追责复盘；它先保证用户不被情绪推向坏行动。
