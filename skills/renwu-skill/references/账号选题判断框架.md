# 账号选题判断框架

## 可写

- 一个普通人或公众人物身上有可见的时代变化。
- 一个公共议题最终落在人的生活、身体、家庭或工作里。
- 一个流行现象背后有真实的人和关系，不只是热点。
- 一个多年后才出现回声的旧故事。
- 一个能让读者理解他人处境的职业、身份、年龄或地域样本。

## 不优先写

- 只有观点，没有人。
- 只有情绪，没有事实。
- 只有热点，没有可进入的生活切面。
- 只有人物履历，没有当下处境和关系变化。

## 角度生成

先问四个问题：

1. 这个人正在失去、争取、逃离或重新理解什么？
2. 这个变化是谁造成的：时代、行业、亲密关系、制度、疾病、观众，还是自己？
3. 最能说明这件事的一个场景是什么？
4. 结尾能不能停在一个新状态，而不是一句道理？
