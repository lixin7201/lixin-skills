# 多元模型格栅交叉决策审计

## R — 原文 (Reading)

> “你必须把经验悬挂在头脑中的一个由许多思维模型组成的框架上……这些模型必须来自各个不同的学科。”
>
> — 查理·芒格，第一讲；提取文本第 2762–2770 行

## I — 方法论骨架 (Interpretation)

复杂问题很少只服从一个学科。先把事实和假设分开，再从少数真正相关的领域各取一个有解释力的模型，例如概率、工程可靠性、激励、心理、竞争和现金流。每个模型都要产生可检验的预测，而不是只贡献一个名词。模型结论冲突时，回到证据、时间尺度和失效条件，不用投票解决。最后检查是否因为职业、工具或既有成功而把现实扭成自己熟悉的“钉子”。

## A1 — 书中的应用 (Past Application)

### 案例：从心理学补齐经济与商业判断

- **问题**：只靠经济学和会计不能解释人为何在明显不利的激励、权威或群体压力下行动。
- **方法论的使用**：芒格把数学、工程、生物、心理和经济模型放在同一格栅中，并用西奥迪尼的研究补齐心理学缺口。
- **结论**：商业判断既要看理性收益，也要看潜意识偏差和系统反馈。
- **结果**：形成书中多模型与双轨分析的共同骨架；但它是启发式格栅，不是封闭学科目录。

## A2 — 触发场景 (Future Trigger)

1. 重要方案只用一个指标或一个部门视角得出结论。
2. 多部门对同一问题结论冲突，需要找出模型与时间尺度差异。
3. 用户怀疑自己因专业背景或工具偏好遗漏关键变量。

语言信号：“别只看 ROI”“换几个模型交叉看”“我是不是把什么都当钉子”“multi-model check”。

与相邻 Skill 的区分：本 Skill 负责调用多个模型；`circle-of-competence-boundary-test` 判断是否有资格下结论；`inversion-ruin-path-preflight` 专查致命失败；`lollapalooza-bias-stack-audit` 专查心理偏差的交互放大。

## E — 可执行步骤 (Execution)

1. **定界决策**：写清决策、期限、不可逆后果、已知事实和待证假设。
   - 完成标准：形成一页问题卡；事实与假设分别列示。
2. **选择 3–6 个相关模型**：每个模型必须来自不同机制，并写出“它预测什么”。
   - 完成标准：每个模型至少产生一个可证伪预测；删除只换术语、不改变判断的模型。
3. **交叉与冲突审计**：比较模型一致点、冲突点、缺失证据和最敏感变量。
   - 判停条件：若关键模型超出能力圈、数据不可得或存在高风险专业边界，停止给结论并转为补证/求助。
4. **形成有条件结论**：列主结论、反转条件、下一次验证动作。
   - 完成标准：结论至少由两个独立模型支持，且写明一个能推翻它的证据。
5. **复盘**：决策后记录哪个模型真正预测了结果、哪个只是事后解释；更新模型使用记录，不因一次成功永久抬高权重。

## B — 边界 (Boundary)

- 不用于晚饭、格式选择等低损失日常事项，也不替代医疗、法律、财务等专业审查。
- 失败模式：模型越多越显得聪明，却没有可检验预测；或始终选择支持既有结论的模型。
- 盲点：书中的学科清单是经验性建议，不是完整、经验证的标准分类。
- 如果真正问题是致命风险、能力边界或心理偏差叠加，应分别调用相邻 Skill，而非用“多模型”包办。
