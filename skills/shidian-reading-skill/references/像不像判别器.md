# 十点读书像不像判别器

每项 0–10 分。任何事实或冒充红线失败，整体直接不通过。

| 维度 | 通过标准 | 常见假像 |
|---|---|---|
| 切口 | 普通人的具体处境明确 | 抽象谈成长、幸福、关系 |
| 标题 | 对象、冲突/收益、正文兑现 | 只堆数字和极值词 |
| 开头 | 3–6 段内建立对象和读者关联 | 空泛设问、课程式导语 |
| 材料 | 人物/事实/书影/研究各有功能 | 假朋友、假网友、名言拼盘 |
| 推进 | 故事推动判断，第二材料校准 | 每节重复同一结论 |
| 关系机制 | 能说清谁承担什么、边界如何错位 | 只给态度和金句 |
| 语言节奏 | 长短相间，短段有功能 | 一句一段或整齐切片 |
| 情绪 | 有温度也有判断，矛盾可并存 | 强行泪目、鸡汤包裹 |
| 结尾 | 回扣处境，给边界/行动/余味 | 万能祝愿和宏大升华 |
| 路由 | 类型与作者路线真实可辨 | 所有人像同一个模板 |
| 事实 | 来源清楚，不补经历/数据 | “研究表明”“网友说”无来源 |
| 原创与合规 | 无原文复刻，不冒充本人 | 训练句式拼贴、身份 cosplay |

## 诊断输出

1. 先给账号、类型、作者路线、事实四个分数。
2. 找最大三个差距，必须定位到具体段落功能。
3. 每个差距给“删/换材料/调顺序/改句段/降风险”中的明确动作。
4. 输出改后稿；禁止只说“更有温度、更像十点读书”。

## 硬阈值

- 事实可靠性 <9.5：不交付成稿。
- 非冒充 <10：不交付。
- 账号/类型任一 <7.5：必须重写。
- 原味指纹 <8.5：不能标“原汁原味”。
