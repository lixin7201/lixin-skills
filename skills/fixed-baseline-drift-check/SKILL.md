# 固定基线渐进恶化审计

## R — 原文 (Reading)

> “当一个人逐步逐步走向灭亡时，如果他每一步都很小……人们经常无法认识到通往终点的趋势。”
>
> — 查理·芒格，第三讲；提取文本第 3950–3964 行

## I — 方法论骨架 (Interpretation)

相邻比较会让连续的小变化显得可接受，直到累计结果跨过危险线。审计必须同时保留固定合格基线、当前绝对值、累计变化和按当前速度外推的终点。阈值要在恶化发生前确定，并区分正常噪声、基线需要更新与系统性漂移。目的不是拒绝一切变化，而是避免“每次只差一点”替代对最终状态的判断。

## A1 — 书中的应用 (Past Application)

### 案例：房地产经纪的对比锚点

- **问题**：客户若先看几套糟糕房源，会把随后仍不理想的房子判断为不错。
- **方法论的使用**：芒格用它说明当前判断会被刚见过的参照物扭曲。
- **结论**：重要标准不能只依赖相邻对象，必须保留独立基线。
- **结果**：同一机制可解释连续小纰漏和渐进恶化，但不能把营销案例当普遍定律。

## A2 — 触发场景 (Future Trigger)

1. 内容、产品、服务或健康指标每期只下降一点，团队仍说“差不多”。
2. 目标或验收线被不断向当前表现移动。
3. 用户只看环比，没有固定合格样本、累计变化或终点外推。

语言信号：“是不是温水煮青蛙”“每次只退步一点有问题吗”“拿最初版本再比一次”“baseline drift”。

与相邻 Skill 的区分：本 Skill识别时间上的累计漂移；`incentive-caused-bias-audit` 解释指标为何被逐步放松。它不同于跨周期趋势判断，不要求把短期漂移外推成永久趋势。

## E — 可执行步骤 (Execution)

1. **冻结基线**：选一个经验证合格的版本、标准或时期，记录其适用条件。
   - 完成标准：基线可重现，且不是为了支持当前结论临时挑选。
2. **四栏比较**：当前值、上期值、固定基线、累计变化同时展示。
   - 完成标准：质量、成本、风险或行为至少有一个绝对指标。
3. **外推终点**：若当前小步连续 N 次，描述最终状态和跨线时间。
   - 判停条件：若基线对应的目标、环境或用户已根本改变，先版本化新基线，不机械沿用。
4. **设置阈值动作**：预先规定警戒、暂停、修复和恢复标准。
   - 完成标准：跨阈值后有负责人和动作，不只发提醒。
5. **复盘**：按周期记录误报、漏报、基线变更理由和累计趋势；不得删除旧基线来美化历史。

## B — 边界 (Boundary)

- 不把任何小变化都判为恶化；需区分随机波动、学习成本和有意转型。
- 失败模式：基线随表现下调；只看环比；外推时忽略结构变化。
- 盲点：“渐进灭亡”是强烈修辞，不是每个小误差都会线性累积。
- 需要统计控制、医疗监测或安全报警时，应使用专业标准和工具。
