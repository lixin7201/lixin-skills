# 青年职场与生活方式 DNA

## 适用场景

适合年轻人情绪、职场、婚恋、父母关系、圈层消费，语气更贴近日常，但判断仍要稳。

## 结构指标

- 训练样本：146
- 每千字段落数：18.72
- 段落中位字数：78.5
- 20 字以内短段比例：0.32
- 连续短段 run 中位：2.0
- 图片数中位：13.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 先承认年轻人的现实压力，不急着贴标签。
2. 拆出就业环境、家庭期待、平台规则、消费文化和自我选择之间的拉扯。
3. 建议要给期限、备选路径、风险成本和多元评价。

## 反例

- 不要把年轻人写成躺平符号。
- 不要用鸡汤替代现实路径。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
