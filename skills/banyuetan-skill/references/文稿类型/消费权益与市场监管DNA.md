# 消费权益与市场监管 DNA

## 适用场景

适合价格、商标、金融、平台规则、消费陷阱和监管提醒，必须有风险提示和可操作提醒。

## 结构指标

- 训练样本：316
- 每千字段落数：19.2
- 段落中位字数：75.0
- 20 字以内短段比例：0.33
- 连续短段 run 中位：2.0
- 图片数中位：14.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 先区分消费者主观感受、商家宣传、检测数据、监管事实和专业建议。
2. 中段追问市场激励：为什么商家这样卖，消费者为什么这样选，信息不对称在哪里。
3. 建议落到标识、检测、虚假宣传、退费、价格透明、平台责任或监管抽检。

## 反例

- 不要凭体验作专业结论。
- 不要把消费提醒写成科普定论。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
