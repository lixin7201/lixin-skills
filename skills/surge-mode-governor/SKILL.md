# 狂飙模式治理器

## R — 原文 (Reading)

> “不能一直处于危机战备状态。”
>
> — 沃尔特·艾萨克森，序章“火之缪斯”

## I — 方法论骨架 (Interpretation)

狂飙是一种临时组织模式：把资源集中到一个真实关键窗口，用极短周期暴露协调阻力并完成单一里程碑。它不是文化身份，也不是常态加班。启用前必须证明窗口真实、瓶颈明确、集中资源比正常推进更有效；运行中保护安全、质量、法律和人员底线；到期必须退出并复盘。若冲刺只完成物理动作却破坏系统结果，仍判失败。

## A1 — 书中的应用 (Past Application)

### 案例 1：Model 3 产能冲刺

- **问题**：现金和市场承诺形成真实期限，现有两条生产线无法达到周产量目标。
- **方法论的使用**：资源集中到当前瓶颈，快速拆机器人、改工序并搭建临时人工产线。
- **结论**：真实窗口中，短期集中能突破常规建设周期。
- **结果**：达到每周 5,000 辆；同时产生工伤、过劳和质量捷径风险。

### 案例 2：萨克拉门托服务器搬迁

- **问题**：推特希望尽快停止每年上亿美元的数据中心支出。
- **方法论的使用**：小团队在数天内搬走 700 多个机柜，远超原搬迁速度。
- **结论**：物理搬迁计划确有大量缓冲，但系统依赖并未被理解。
- **结果**：7 万次硬编码引用遭破坏，后续系统不稳定；速度成功、业务失败。

## A2 — 触发场景 (Future Trigger)

1. 公司只有短暂现金、监管、市场或交付窗口，错过后损失显著。
2. 大型发布、迁移、救援或集成任务需要跨团队短期集中。
3. 领导者提出全员通宵、战时状态或极端期限，需要判断是否合理。
4. 团队已经连续多次冲刺，需要决定是否停止危机模式。

### 语言信号

- “这两周要不要全员进入战时状态？”
- “必须十天搞定，怎么组织？”
- “要不要开 war room / crunch mode？”
- “所有项目都很急，怎么选唯一冲刺目标？”

### 与相邻 Skill 的区分

- 与 `moving-bottleneck-red-light-loop` 的区别：必须先用后者找准瓶颈，本 Skill 才决定是否集中组织资源。
- 与 `bounded-rapid-failure-protocol` 的区别：本 Skill 管理团队运行模式；后者管理一个高不确定试验。
- 与普通项目计划的区别：只有真实时间窗口和跨团队临时资源重排才需要狂飙。

## E — 可执行步骤 (Execution)

1. **验证是否是真危机**
   - 写明外部窗口、错过代价、最晚日期和证据。
   - 完成标准：紧迫性来自现金、合同、监管、用户或技术窗口，而非领导者焦虑。
   - 判停条件：若没有外部窗口，回到正常优先级和能力建设。

2. **选定唯一里程碑与主瓶颈**
   - 用 `moving-bottleneck-red-light-loop` 确认当前限制。
   - 完成标准：只有一个可验收里程碑，其余项目明确降级或暂停。

3. **写入四类护栏**
   - 不可牺牲项：安全、法律、隐私、数据完整性、最低质量。
   - 资源边界：参与人员、最长工时、替补、预算。
   - 决策边界：谁可拍板，谁可因风险叫停。
   - 时间边界：开始、结束和每日检查点。
   - 完成标准：护栏公开且叫停者不会因提出风险受罚。

4. **建立短反馈节奏**
   - 每个检查点只看里程碑、瓶颈、风险和需要取消的任务。
   - 完成标准：资源围绕瓶颈调整，不用会议数量制造忙碌。

5. **按系统结果验收**
   - 不只验收物理动作或代码完成，还检查用户、依赖、质量和稳定性。
   - 停止条件：护栏被突破、关键依赖未知、人员无法安全继续或边际产出连续下降。

6. **强制退出与恢复**
   - 到期自动结束；如需延长，重新做第1—3步，不得默认续期。
   - 安排补休、事故复盘、技术债清单和常态负责人。
   - 完成标准：人员与项目回到可持续运行，临时决策权撤销。

## 复盘方式

- 分开记录“速度结果”和“系统结果”，避免像服务器搬迁一样只庆祝前者。
- 计算冲刺额外产出、人员代价、质量债与后续返工。
- 30 天内再次要求狂飙时，必须解释上次为何没有建立持久能力。
- 若所有季度都在狂飙，判定为管理系统失效，而非团队不够硬核。

## B — 边界 (Boundary)

- 不用于长期战略含糊、需求未验证或单位经济不成立的问题。
- 不允许用羞辱、威胁解雇或隐瞒风险维持速度。
- 第46章工伤率、第60章太阳能屋顶和第92章服务器事故证明，速度不能替代系统结果。
- 医疗、公共安全、关键基础设施和不可逆迁移必须保留专业审查与回滚。
- 人员恢复是完成标准的一部分，不是可选福利。
