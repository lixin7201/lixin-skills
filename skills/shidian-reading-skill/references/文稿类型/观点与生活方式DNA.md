# 观点与生活方式 DNA

- **适用场景**：需要解释一个流行概念、人生判断或生活选择；主题可以跨爱情、修养、离别、欲望、日常伦理。它是最大的兜底类，但不是“其余都塞进来”。
- **标题 DNA**：一个核心概念加极值判断、命运判断或警示，如“最高级的……”“最硬的……”“千万别破坏……”。也可用带强悬念的生活事件标题，但正文若以完整故事为主，应转人物/叙事路线。
- **开头 DNA**：提问代入或引用/金句开路最稳；8 篇统计中引用/金句开路 5 篇。开头 8—12 段内应完成“概念是什么、为什么与你有关、本文要解释什么”。
- **推进链**：概念定义/生活困惑 → 负面样本说明代价 → 心理/文化解释 → 正面或对照样本 → 校准“不是只有 A，还要 B” → 自测或生活建议。
- **材料偏好**：书籍、影视、身边故事为主；类型样本信号中书籍 59、身边故事 38，远高于研究 2。研究不是主骨架，只能用来支撑关键机制。
- **段落节奏**：句长中位 25 字；每个故事用 5—12 个短段推进，动作细节后单独落一句判断。中心词可重复，但每次重复都要增加一层意思。
- **情绪温度**：6/10。先共情，后给方向；可以感伤、警醒，但不把读者吓入绝境。
- **结尾 DNA**：回收中心词，给出更完整的二层判断，再用祝愿、轻互动或自测收口。统计中祝愿共勉最稳定。
- **事实核查**：心理学概念、激素/基因等科学解释、名人婚恋、影视情节、名言出处、匿名“真实故事”均需核查；无法证实的故事必须标明来源层级，不得当普遍规律。
- **像 / 不像警告**：像在“故事—判断—再故事”中逐层加深；不像把“最高级、底牌、风水、真相”换词循环。第一人称长篇故事虽可能高互动，但若来自明确外部作者，只能作为独立叙事子路由，不能冒充账号编辑部口吻。
- **深读样本与置信度**：`ebc51f1fa2fdd4b9`《异性之间最高级的爱：生理性喜欢》、`b7eef2e7cb61f627`《我爸我妈甜蜜20年，直到一碗面条，引发了亲子鉴定》、`8f0d539b0a3689e2`《千万不要破坏你身上的上等风水》、`7f7e6dec58a69800`《成年人有些再见，是再也不见》。**置信度：中高**；大样本足够，但内部包含概念稿、议论文和外部第一人称故事三种不同骨架。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
