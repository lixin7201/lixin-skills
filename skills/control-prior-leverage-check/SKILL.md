# 控制优先杠杆检查

## R — 原文 (Reading)

> 只有在人们投资他们不能控制的资产时，杠杆作用才是危险的。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸提高你的财商》第6章

## I — 方法论骨架 (Interpretation)

杠杆不是只指借钱，也包括人、工具、广告、品牌、平台、合伙和系统。
作者的关键提醒是: 杠杆会放大结果，风险来自你放大的东西自己无法理解或控制。
这个方法要求先检查控制面: 收入、成本、运营、信息、法律、退出和心理承受力。
适用于创业、投资、写作分发和团队扩张中的放大决策。

## A1 — 书中的应用 (Past Application)

### 案例 1: 投资不能控制的杠杆
- **问题**: 投资者借钱进入自己不懂、不可控、只能听别人建议的资产。
- **方法论的使用**: 作者把控制权放在杠杆前面，要求先懂资产和现金流。
- **结论**: 无控制的杠杆会把小错放大成灾难。
- **结果**: 杠杆前必须做信息、现金流和退出检查。
### 案例 2: 良性债务也像上膛的枪
- **问题**: 即使债务看起来由资产支付，也可能因现金流变化失控。
- **方法论的使用**: 作者用强警告强调债务和杠杆都要敬畏。
- **结论**: 控制权不是一次性判断，而是持续监控。
- **结果**: 本 skill 把停止条件放入执行步骤。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想用资金、人、广告、平台、工具或合伙放大结果。
2. 用户只看到杠杆收益，没看控制权和退出。
3. 用户准备扩大创业、内容、投资或团队规模。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要加杠杆"
- "投广告放大"
- "融资扩张"
- "合伙风险"
- "控制权够不够"
- "外包会不会失控"

### 与相邻 skill 的区分

- 与 `good-bad-debt-screen` 的区别: 债务只是杠杆之一；本 skill 覆盖人、平台、广告和系统杠杆。
- 与 `five-financial-iq-triage` 的区别: 本 skill 专门处理杠杆控制，不做全局财务分诊。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **定义杠杆**
   - 操作: 说明要放大的资源是什么: 钱、人、工具、渠道、信用、品牌或关系。
   - 完成标准: 杠杆对象明确。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **列控制面**
   - 操作: 检查收入、成本、质量、法律、信息、依赖方、退出和最大损失。
   - 完成标准: 至少覆盖 6 个控制面。
 3. **小额压力测试**
   - 操作: 先用最小规模测试杠杆是否按预期放大，记录负面反馈。
   - 完成标准: 测试成本可承受。
 4. **设停止条件**
   - 操作: 写出亏损、投诉、现金流、时间、依赖风险的停机阈值。
   - 完成标准: 达到阈值时必须降杠杆或退出。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要求预测某个投资杠杆收益或推荐产品。
- 用户已在危机中需要法律、财务或医疗专业支持。

### 作者在书中警告的失败模式

- 只看倍数，不看自己能控制哪些变量。
- 用借来的钱、别人的关系或平台流量放大未经验证的东西。

### 作者的盲点 / 时代局限

- 作者强调控制可降低风险，但现实仍有不可控黑天鹅。
- 控制权检查不能替代合规、合同、财务和安全审查。

### 容易混淆的邻近方法论

- 与 `five-financial-iq-triage` 的区别: 本 skill 专门处理杠杆控制，不做全局财务分诊。
