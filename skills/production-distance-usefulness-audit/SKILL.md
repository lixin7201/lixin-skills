# 有效生产距离—有用性审计

## R — 原文 (Reading)

> 人们收入的差异，主要源自与有效生产之间的距离。换言之，离生产越近的人赚钱越多，或者反过来，离生产越远的人赚钱越少。
>
> — 李笑来，第2、4—6、23章

---

## I — 方法论骨架 (Interpretation)

先把“我很努力”与“我进入了有效生产”分开。有效生产要求有真实受益者、可观察改善和可交付结果；市场付款是一类证据，但不是公共价值的唯一证据。

再画出自己与问题、用户反馈、关键产出和价值分配之间的距离。学习若只增加身份标签，工作若只增加内部流转，产品若没有需求证据，都可能离有效生产很远。

最后按自己、家人、客户、社群和社会逐层检查有用性，不用宏大口号跳过近处责任，也不把暂时不能变现误判为无价值。

## A1 — 书中的应用 (Past Application)

### 案例：自学绘图和代码缩短真实交付

- **问题**：作者制作书和课程时需要插图、排版和程序处理，外部协作会增加等待。
- **方法论的使用**：他围绕实际出版交付学习绘图与代码，把学习内容直接绑定生产任务和受益者。
- **结论**：值得优先学习的能力会缩短从自己到真实产出的距离，并在作品中接受检验。
- **结果**：书中称部分插图制作从等待协作缩短到几分钟完成。
- **证据位置**：candidates/cases.md c24，第23章

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 选择证书、课程或技能时，需要判断它是否改善真实交付。
2. 团队事务很多，却说不清最终用户、关键结果或价值反馈在哪里。
3. 创业或写作点子主要靠自我感觉，需要验证谁会受益、怎样受益。
4. 公共服务、照护或基础研究暂时没有价格信号，需要改用覆盖、风险下降或能力增量验证价值。

### 语言信号

- “这个证书值得学吗”
- “我们很忙但离用户价值有多远”
- “这个点子真的有用吗”
- “is this work close to real production”

### 与相邻 skill 的区分

- 与 `personal-method-ipo` 的区别：本 Skill 先判断是否靠近真实生产与受益者；后者处理已经有效的方法怎样产品化和放大。
- 与 `attention-allocation-ledger` 的区别：本 Skill 审计价值链距离；后者核算注意力投入、被动占用和交换所得。

## E — 可执行步骤 (Execution)

1. **定义受益者与结果**
   - 动作：列出直接受益者、要改善的问题、可观察结果和可交付物；公共价值可用服务覆盖、风险下降或能力增量等非价格证据。
   - 完成标准：至少有一个具体受益者、一个可观察变化和一个交付物，不能只写“提升影响力”。
   - 判停条件：如果无法指出任何受益者或验证信号，先停止大额投入，转为需求访谈或小样本测试。

2. **绘制生产距离**
   - 动作：标出自己到问题现场、用户反馈、关键产出、交易/采用和结果复核的节点，并注明自己是否有接触权和影响力。
   - 完成标准：每个节点都有负责人、证据来源和当前距离；至少找出一个最长反馈链或空白节点。

3. **设计缩短距离的最小动作**
   - 动作：选择一个能在短周期接触真实问题、完成样品、服务一次用户或获得采用证据的动作。
   - 完成标准：动作有截止时间、成本上限、验收信号和失败后的退出或改向条件。

4. **按同心圆复核有用性**
   - 动作：检查行动对自己生存与成长、近处责任、客户/同事、社群或社会的影响，记录受益与外部性。
   - 完成标准：明确当前做到哪一层、牺牲了什么、下一层是否有余力，不用宏大目标掩盖近处损害。

### 整体验收与停止

- **完成标准**：已形成受益者—结果—生产距离图、一个有界现实验证和继续/调整/停止结论。
- **停止条件**：没有真实验证渠道、行动超出授权，或会牺牲基本生计、安全、照护与不可逆权益时停止。
- **复盘方式**：每个验证周期对照预测与实际受益，记录距离是否缩短；连续两轮无更近反馈或交付改善时重选路径。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 若评估者拒绝非价格受益指标、坚持只认短期市场价格，应先停止结论并纠正评估口径；不得据此否定公共服务、照护、基础研究和长期能力建设。
- 不应用它羞辱稳定就业者或强迫用户创业；职业阶段、现金流和家庭责任优先。

### 作者在书中警告的失败模式

- 用自我感觉代替真实需求，或不断增加课程与证书却没有作品、用户和岗位反馈。

### 作者的盲点 / 时代局限

- 书中以个人经验和概念推演为主，生产/投机二分和“离生产近收入高”并非普遍因果，应用时必须补制度、资源与非市场价值。

### 容易混淆的邻近方法论

- 与 `personal-method-ipo` 的区别：本 Skill 先判断是否靠近真实生产与受益者；后者处理已经有效的方法怎样产品化和放大。
- 与 `attention-allocation-ledger` 的区别：本 Skill 审计价值链距离；后者核算注意力投入、被动占用和交换所得。
