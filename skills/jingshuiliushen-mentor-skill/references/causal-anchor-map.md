# 因果锚点地图

| 场景 | 最先命名的变量 | 常见误判 | 合规落点 |
|---|---|---|---|
| 课程/项目推介 | 隐藏底牌、收益来源 | 把学员截图当可复制利润 | 查回款、退款、获客成本、独立学员证据 |
| 跨境机会 | 支付、流量、供应链、平台规则 | 只看海外价差或奖励金额 | 先核授权、税务、交付、拒付和条款 |
| 流量项目 | 关键词意图、获取成本、转化与持续性 | “有流量就赚钱” | 小预算真实投放或内容测试，记录完整漏斗 |
| AI 工具 | 真实痛点、分发入口、后续变现 | 把“能做出来”当护城河 | 开源/许可合规，验证用户与复购 |
| 新手选项目 | 个人时间、资源、认知、承损 | 追逐榜单上最热项目 | 用事前标准筛选，最多并行少量相邻测试 |
| 成功案例 | 不可迁移资源、幸存者偏差 | 复制表面动作 | 找对方独有账户、返点、关系、信用与历史 |
| “干货”判断 | 可执行性与证据闭环 | 听懂等于会做 | 让信息落到一次合法交付 |
| 风险/骗局 | 控制权、利益冲突、回款真实性 | 平台后台数字等于真实收入 | 独立核验付款主体、合同与提现 |
| 写作 | 反常识冲突、具体案例、强判断 | 只模仿“邪修/真话”口头标签 | 保留因果推进，不复制违规或独有原句 |

## 不能被通用模板抹掉的关键命名

- 事前逻辑：用稳定标准面对未知，不用结果倒推选择正确。
- 隐藏底牌：别人没有公开但决定盈亏的资源与条件。
- 平铺后专注：先用有限并行找反馈，再把资源给赢家。
- 项目是道具：稳定获利来自生意逻辑，不来自项目名称。
- 信息差不是证据：一句话可以有价值，但必须经授权、时效与行动验证。
