# 恶意谈判战术识别与反制

## R — 原文 (Reading)

> "应对所有谈判战术最基本的是避免在心理上遭到扰乱。"
>
> — 高杉尚孝，第二章

## I — 方法论骨架 (Interpretation)

恶意战术的核心不是条件本身，而是扰乱你的心理，让你在压力下即时承诺。  
这个方法先识别战术类型，再暂停承诺、要求条件书面化、回到事实标准和授权边界。  
对电话奇袭，默认先听清、暂停、准备后回电，并书面确认。  
不要以牙还牙使用同样恶意手段。  
若出现违法、威胁或安全风险，目标不再是谈成，而是退出和求助。

## A1 — 书中的应用 (Past Application)

### 案例 1: 泷泽被电话订货奇袭
- **问题**: 泷泽写报告时接到复杂订货电话，未准备就顺着谈。
- **方法论的使用**: Good Example 先暂停通话，准备后回电，并书面确认协议。
- **结论**: 电话来电方拥有准备优势，接电方不应即时承诺复杂条件。
- **结果**: 谈判回到可核对、可留痕、可授权状态。

### 案例 2: 最后通牒和事后索取
- **问题**: 对方用"今天不签以后没这个价"和达成后追加免费服务制造压力。
- **方法论的使用**: 识别最后通牒和事后索取，暂停承诺，要求条件书面化。
- **结论**: 战术被命名后，心理扰动下降。
- **结果**: 谈判可回到价格、范围、授权和 B 计划。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 对方催促今天必须签、马上答应、错过不再有。
2. 电话或临场突然抛复杂条件，用户没有准备。
3. 条件达成后，对方继续追加免费服务或额外责任。
4. 对方要求含糊，却逼用户承诺。

### 语言信号

- "今天不签以后就没这个价"
- "电话里突然让我答应"
- "谈好后又加条件"
- "last offer / hardball tactic / phone ambush"

### 与相邻 skill 的区分

- `negotiation-real-intent-listening` 假设对方仍可合作；本 skill 处理有意施压和扰乱。
- `constructive-negotiation-preflight` 是准备；本 skill 是现场防御。
- `multi-perspective-emotion-reframe` 处理情绪视角，本 skill 处理谈判战术。

## E — 可执行步骤 (Execution)

1. **命名战术**
   - 判断是否为最后通牒、红白脸、含糊要求、逆向拍卖、事后索取、预算底线、既成事实、电话奇袭。
   - 完成标准: 写出战术名称、对方压力机制和你被要求即时承诺的点。

2. **暂停并留痕**
   - 说"我需要核对条件/授权/资料，稍后书面回复"。
   - 判停条件: 若有威胁、安全、违法、骚扰或欺诈，停止谈判，转专业/组织/法律支持。
   - 完成标准: 不在压力场中做新承诺，所有条件进入文字记录。

3. **回到标准和 B 计划**
   - 检查原目标、底线、授权、替代方案和退出条件。
   - 完成标准: 回复只围绕事实、标准、范围、授权和可接受方案。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 对方只是正常强硬但条件透明、允许核验和书面化。
- 已经涉及人身安全、威胁、敲诈、违法合同或明显欺诈时，不继续谈判。
- 高金额或法律合同争议必须请专业人士参与。

### 作者在书中警告的失败模式

- 面对最后通牒、赞美、威胁、既成事实或比较时，被迫即时让步。
- 电话里边听边答应复杂条件，挂断后发现漏项和误听。

### 作者的盲点 / 时代局限

- 原书恶意战术表达较早，2026 年平台、聊天工具、自动合同和跨境交易中的战术需类比识别。
- 看穿战术不保证能反制强权，必要时退出比继续谈更正确。

### 容易混淆的邻近方法论

- 强硬谈判不等于恶意战术；关键看是否制造不对等、拒绝澄清和迫使即时承诺。
- 冷静不是忍耐，而是把承诺权拿回自己手里。
