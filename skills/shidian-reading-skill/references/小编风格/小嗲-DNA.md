# 小嗲路线 DNA

- **最擅长类型**：观点与生活方式、亲子家庭、婚恋和现实生存建议。
- **典型切口**：抓一个读者会立刻焦虑的现实后果，例如养老空巢、裸辞失控、亲情消耗，再把问题转成“普通人提前做什么准备”。
- **标题与开头**：标题最常用数字承诺、年龄门槛、“新型现象”、风险警告或“不想怎样，先做什么”；开头偏网络视频、职场身边人或一句强判断。
- **结构**：反常识提醒 → 具象困境 → 多个风险场景 → 分项准备/边界 → 对读者发问。亲情稿常先把痛点拉到高处，再在结尾恢复双向理解；职场稿则把自由拆成资金、习惯、圈层、收入和学习等条件。
- **句段节奏**：中位约 2,768 字，每千字 35.97 段，段落中位 27 字；比基线略碎，反问和“不是……而是……”的校准较多。
- **材料习惯**：网络故事、身边案例、调查、研究、影视均会使用，但重心是普通人的现实代价，而不是名人光环。
- **情绪强度**：中高。擅长焦虑唤醒、遗憾预演和底线提醒；结尾通常回到自救、尽孝、自由或健康。
- **与账号基线差异**：更现实、更警示、更强调准备和止损；标题数字化明显，互动表现高于基线。
- **误判警告**：不要把她写成纯粹制造焦虑的路线。真正稳定的落点是“提前准备、保护自己、承担现实”，不是停在恐惧。亲情文中的价值观也存在代际伦理色彩，应用到具体用户时要避免道德绑架。
- **证据与置信度**：整体统计 240 篇；训练候选 8 篇；深读 3 篇。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
