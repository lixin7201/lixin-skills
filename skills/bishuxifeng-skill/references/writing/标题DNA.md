# 标题 DNA

标题的任务不是制造神秘感，而是把抽象机制翻译成读者正在承担的损益。训练集 101 篇中，疑问型 39 篇、直呼读者 24 篇、风险/命运损益 17 篇、数字清单 10 篇。以下是可复用结构，不是固定句模。

| 结构 | 适用场景 | 合成示例 | 禁止用法 |
|---|---|---|---|
| 为什么 X，结果却 Y？ | 努力与结果错位 | 为什么工具越多，团队交付反而越慢？ | 没有反差证据也硬写“却” |
| X 还是 Y，真正要选的是什么？ | A/B 选择依据未明 | 留在大厂还是去创业，真正要选的是什么？ | 假两难、替读者决定价值 |
| 影响你的不是 X，而是 Y | 表面变量需重定义 | 影响转型的不是课程数量，而是反馈周期 | 把未经验证的 Y 写成“真相” |
| 当 X 发生，普通位置的人怎么办？ | 时效事件与个体位置 | 当行业预算收缩，乙方团队先守什么？ | 用“普通人”推定全部读者 |
| X 已经变了，你的位置变了吗？ | 周期/规则变化 | 客户的购买路径已经变了，你的交付位置变了吗？ | 事实没核验就写“已经” |
| 做了 X，为什么仍得不到 Y？ | 忙而无结果 | 做了内容、社群和活动，为什么仍没有订单？ | 只制造焦虑，不给机制 |
| 先别急着 X，先看 Y | 高风险加码 | 先别急着裸辞，先看新业务有没有真实付费 | 把“别急”变成万能拖延 |
| X 的终局，不只一种 | 长周期与多情景 | 远程协作的终局，不只一种 | 以多情景逃避当前判断 |
| 谁在为 X 付钱，谁在承担 Y？ | 角色利益 | 谁在为免费试点付成本，谁拿到了选择权？ | 阴谋式读心 |
| 行业有机会，为什么未必轮到你？ | 生态位兑现 | AI 有机会，为什么未必等于你的岗位有机会？ | 贬低读者或否定行业 |
| 这 N 个问题，决定 X | 清单型复杂判断 | 这 5 个问题，决定副业能不能变成主业 | 数字与正文不一致 |
| X 之后，真正难的是 Y | 事件后机制 | 拿到第一批客户之后，真正难的是可重复交付 | 每篇都用“真正” |
| 你缺的也许不是 X | 谨慎反常识 | 你缺的也许不是勤奋，而是可验证的结果 | 没有“也许”的证据边界 |
| 如果 X 没发生，Y 还成立吗？ | 反事实检验 | 如果补贴取消，这门生意还成立吗？ | 用反事实代替现实数据 |
| X 值不值得做，先算这笔账 | 成本/可逆性 | 转型值不值得做，先算出局成本 | 把所有价值都货币化 |

## 选择规则

1. 先写正文的一句核心重定义，再选标题；标题不得比论证更确定。
2. 当前事实型标题必须核验“今天、已经、将至、触底”等时效词。
3. 同一批稿件避免连续使用“不是 X，而是 Y”“真正的 X”或问号标题。
4. 可以直呼“你”，但不得替读者预设性别、阶层、职业和财富状况。
5. 原味来自损益问题、反差和变量重定义，不来自“秘密、天机、只有我敢说”。

## 标题自检

- 删除标题中的刺激词后，核心问题还成立吗？
- 正文有没有回答标题承诺？
- 哪个事实变化会使标题不再成立？
- 与同主题其他标题相比，是否只是换了名词的同一模板？
