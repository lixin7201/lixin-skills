# 周期—终局—选项倒推

## R — 原文（Reading）

> 这个游戏从开局的时候，你就要知道终局。
>
> — 碧树西风，BXSF-058 · 2023-12-15

> 站在十年后的角度，倒推今天，到底该如何选择。
>
> — 碧树西风，BXSF-066 · 2024-04-10

## I — 方法论骨架（Interpretation）

1. 先把个人、产品、行业、财富和更大环境的周期分层，避免用一个时间尺度回答另一个时间尺度的问题。
2. 终局不是预言，而是对长期结构状态的假设：哪些位置、能力和关系届时仍有价值。
3. 再从这些状态倒推今天应积累什么，并检查当前行动让未来选项增加还是减少。
4. 好的长期选择不要求猜中唯一赢家，而是让环境变化后仍有 E 到 Z 的隐藏选项。

## A1 — 语料中的应用（Past Application）

### 案例 1：大周期反转后的家族路径

- **问题**：作者以家族自述说明短期押中权势，长期可能变成败落来源。
- **方法论的使用**：把单次正确放进更大周期，并提高城市、资产和能力的容错。
- **结果与证据边界**：因果细节未外部核验，只能作为路径依赖例证。
### 案例 2：转甲方前的提前布局

- **问题**：作者在旧岗位尚稳定时，先了解甲方问题、关系与资源。
- **方法论的使用**：从期望位置反推当下要建立的连接和可交付价值。
- **结果与证据边界**：作者称随后完成转岗和升迁，属于单方职业复盘。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 长期职业或行业选择
2. 担心技术/政策改变现有路径
3. 比较两个都会占用多年时间的方案
4. 需要增加未来选择权

### 语言信号

- “十年后这条路还在吗”
- “现在转行会不会太晚”
- “哪个行业能一直吃香”
- “我怎样避免把路走窄”

### 与相邻 skill 的区分

- 与 `repeatable-survival-decision-system` 的区别：长期方向确定后，用兄弟 skill 控制每轮试错与出局风险。
- 与 `explore-exploit-transition-ladder` 的区别：本 skill 决定长期边界；后者把边界转成根据地和探索切换。
- 与 `choice-basis-three-question-audit` 的区别：本 skill 处理时间与选项；三问审计先澄清责任、能力和意愿。
- 与 `ecological-niche-value-chain-audit` 的区别：本 skill 看多层周期；生态位 skill 判断人在价值链中的具体位置。

## E — 可执行步骤（Execution）

1. **拆周期**
   - 完成标准：至少列出个人反馈、技能、产品、行业和宏观五个时间层，并标注各自转折信号。
   - 判停/转向：若用户只问短期行情，停止并改用时效事实工具。
2. **写多个终局**
   - 完成标准：写出至少两个合理长期结构，不把单一预测包装成答案。
   - 判停/转向：无法给出证据或条件时，把该终局标为低置信假设。
3. **反推要求**
   - 完成标准：对每个终局列出仍有价值的位置、能力、现金流、关系和可接管资源。
   - 判停/转向：只写职位名称而没有价值来源时，本步未完成。
4. **求选项交集**
   - 完成标准：找出跨终局仍有价值的积累，并标出可逆动作和专用沉没成本。
   - 判停/转向：优先保留能扩展选项集的动作。
5. **设置更新点**
   - 完成标准：为关键假设绑定数据、日期或事件，到点重估概率。
   - 判停/转向：新证据出现时必须允许改变路线。

### 边界路由规则

- 当事项表面上只持续几个月、用户也声称不改变长期方向，但它可能占用关键窗口或关闭选项时，仍由本 skill 做一次轻量长期影响筛查；若确认选项影响很小，就在第一步后停止，不强跑完整多周期流程。

## B — 边界（Boundary）

### 不要在以下情况使用

- 把宏观判断直接变成短期买卖点
- 要求预测唯一确定未来
- 成本很低的日常选择

### 作者在语料中警告的失败模式

- 把周期当必然反弹公式
- 沿用旧路径却不重算时机
- 把局部规律外推到制度周期之外
- 用二选一删掉隐藏选项

### 作者盲点与证据局限

- 作者 2021–2026 的宏观预测具有强时效性，使用时必须重新获取现实数据
- 终局叙事容易产生事后解释和幸存者偏差

### 统一安全边界

- 这是从公开文章中提炼的方法，不代表作者本人对新问题的真实意见。
- 不复制作者亲历，不冒充作者，不把自述案例当作独立核验事实。
- 涉及时效事实、法律、医疗或财务高风险问题时，先获取当前可靠资料并明确不确定性。
