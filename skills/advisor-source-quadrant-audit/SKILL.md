# 顾问来源象限审计

## R — 原文 (Reading)

> 你的顾问只能和你一样聪明。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸财务自由之路》第5章

## I — 方法论骨架 (Interpretation)

这个方法要求用户不要把判断外包给头衔、熟人或声音大的专家。
先看建议来自哪个象限、对方做过什么、靠什么赚钱、承担什么后果、证据是否可核验。
顾问可以有价值，但只有当用户具备基础语言和追问能力时，顾问价值才会变大。
它适合投资、创业、课程、职业、写作和合作建议的来源审计。

## A1 — 书中的应用 (Past Application)

### 案例 1: 你的顾问只能和你一样聪明
- **问题**: 财务无知的人把复杂决策交给顾问，却听不懂风险和利益结构。
- **方法论的使用**: 作者提醒先提高自己的财务语言，再使用顾问。
- **结论**: 顾问不是替代判断，而是放大已有判断力。
- **结果**: 建议需要被追问、比较和验证。
### 案例 2: 事实与观点的区分
- **问题**: 很多财务决策基于朋友、媒体和销售人员的观点。
- **方法论的使用**: 作者要求区分事实、观点、建议来源和象限差异。
- **结论**: 建议质量取决于来源、证据和利益结构。
- **结果**: 信息进入行动前要先过审计关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户不知道该听哪个导师、顾问、经纪人、朋友或课程。
2. 用户收到投资、创业、职业或写作建议，想判断是否靠谱。
3. 用户把专家头衔当作决策依据，需要拆利益结构。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **拆建议**
   - 操作: 把对方建议改写成可验证主张、行动和风险。
   - 完成标准: 不再是模糊口号。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **审来源**
   - 操作: 看对方收入来源、所在象限、实操记录、利益冲突和是否承担后果。
   - 完成标准: 来源画像明确。
 3. **查证据**
   - 操作: 区分事实、观点、案例、承诺和无法验证部分。
   - 完成标准: 每个关键主张有证据等级。
 4. **决策边界**
   - 操作: 决定采纳、部分采纳、小额验证或拒绝，并写明停止条件。
   - 完成标准: 不把建议直接变行动。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户需要正式法律、税务、医疗或证券投资建议；必须转专业人士。
- 用户只是要总结某位作者观点，没有现实决策。

### 作者在书中警告的失败模式

- 听不懂报告仍照做。
- 把做过、出名、亲近或自信等同于可信。

### 作者的盲点 / 时代局限

- 作者对传统顾问有强烈批判，实际应避免反专家倾向。
- 专业人士仍有必要，重点是可追问和利益透明，而非排斥。

### 容易混淆的邻近方法论

- 与 `business-education-due-diligence` 的区别: 本 skill 审计单个建议或建议者；后者审计一个商业教育系统或组织。
- 与 `five-financial-iq-triage` 的区别: 本 skill 聚焦信息来源；五财商分诊是更宽的问题分类。
