# SMART 前目标价值-权责-资源预检

## R — 原文 (Reading)

> 目标来自于哪里？愿景导向；竞争导向；顾客导向；职责导向；问题导向；成长导向。
>
> — 《工作计划目标管理培训》Slide 21

> BSC同时关注：内部和外部，现在和将来，让目标更均衡、完整。
>
> — 《工作计划目标管理培训》Slide 22

> SMART原则是一个很实际、很方便的实施原则。
>
> — 《工作计划目标管理培训》Slide 23

## I — 方法论骨架 (Interpretation)

SMART 只能让目标写得更清楚，不能证明目标本身值得做。
在把目标改写成具体、可衡量、可达成、相关、有期限之前，先要审计目标的来源、价值、责任和资源。
一个值得承诺的目标，至少要能说清它来自愿景、竞争、顾客、职责、问题或成长中的哪一个真实入口，而不是只来自情绪、压力或模板。
它还要同时照顾内部与外部、现在与未来，避免为了一个容易衡量的短期数字牺牲长期能力或客户价值。
最后，目标必须和执行人的权责、资源、时间窗口和可控因素匹配。
如果这些前提不成立，正确动作不是急着写 SMART，而是把目标改成取证、试点、协商、补资源或记录边界。
这个 Skill 的核心问题是：这个目标能不能被一个有责任感的人合理承诺？

## A1 — 书中的应用 (Past Application)

### 案例 1: 摩托罗拉用品质目标冲刺国家品质奖

- **问题**: 摩托罗拉想获取美国国家品质奖，需要把组织注意力集中到可共同挑战的成果上。
- **方法论的使用**: PPT 把生产合格率 99.997% 作为目标，并让所有员工看到同一个目标。这一目标不是抽象口号，而来自品质竞争与组织成果要求。
- **结论**: 目标在进入 SMART 表述前，先要有真实来源和共同价值；之后再用数字、期限和衡量标准让执行可见。
- **结果**: 资料称摩托罗拉 1988 年节省 2.5 亿美元、收入增加 23%、利润提高 44%，并在 1989 年获得国家品质奖。

### 案例 2: 用六导向和 BSC 避免目标偏斜

- **问题**: 组织设定总目标时，容易只从上级压力、单一指标或短期考核出发。
- **方法论的使用**: PPT 要求追问愿景、竞争、顾客、职责、问题和成长六个来源，并叠加 BSC 的内外部、现在和将来维度。
- **结论**: 目标来源和均衡性是 SMART 前的预检项；否则目标越清晰，错误方向越容易被放大。
- **结果**: 资料没有给出单个企业完整落地过程，因此正式使用时应把这当作预检清单，而不是当成已验证的战略模型。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 老板、客户、团队或自己提出一个看似 SMART 的目标，但执行人怀疑目标是否值得接。
2. 用户正在写年度目标、月度 KPI、学习计划、创业增长目标或内容生产目标，需要先确认方向和承诺边界。
3. 目标有数字、有期限，却缺少客户证据、资源、权限、时间、责任人或可控因素。
4. 团队争论目标写法，但更根本的问题是目标来源、价值和可实现条件都没说清。
5. 用户想把一个强制目标转化为可协商目标、试点目标、取证目标或风险记录。

### 与相邻 skill 的区分

- 与 `okr-smart-kr-quality-guard` 的区别: 该 Skill 检查已决定执行的 OKR/SMART 目标和 KR 质量；本 Skill 检查目标本身是否值得、能否承诺。
- 与 `okr-fit-preflight` 的区别: 该 Skill 判断是否适合导入 OKR；本 Skill 适用于普通工作目标、个人目标、团队 KPI、MBO 和 SMART 目标。
- 与 `strategy-house-alignment-check` 的区别: 该 Skill 做战略层目标-战场-能力对齐；本 Skill 是接到或设定一个具体目标前的轻量预检门。
- 与 `goal-management-side-effect-audit` 的关系: 本 Skill 先看目标是否该承诺；若目标将绑定奖惩、排名或绩效制度，再组合后者审计组织行为副作用。

## E — 可执行步骤 (Execution)

1. **确认目标原句和承诺对象**
   - 操作: 写下目标原句、提出者、执行人、受影响对象、期限、衡量口径和目标背后的要求。
   - 完成标准: 能区分这是个人目标、团队目标、绩效目标、客户承诺、试点目标还是强制命令。
   - 停止条件: 如果用户只是想润色目标表达，转 `okr-smart-kr-quality-guard` 或普通写作协助。

2. **追问目标来源六导向**
   - 操作: 分别检查目标是否来自愿景、竞争、顾客、职责、问题、成长；每个来源写证据或标注缺失。
   - 完成标准: 至少有一个主要来源有真实证据，并说明为什么现在要做。
   - 判停条件: 如果只有"老板说的"、"大家都这么做"或"模板要求"，先改成取证/澄清任务，不进入承诺。

3. **做价值与均衡检查**
   - 操作: 检查目标是否兼顾内部/外部、现在/未来、短期结果/长期能力、局部指标/整体价值。
   - 完成标准: 能明确目标服务的价值、受益者、可能牺牲的长期项和需要保留的护栏。
   - 判停条件: 如果目标只优化一个局部数字且会伤害客户、能力或协作，进入目标修订或副作用审计。

4. **核对权责、资源和可控性**
   - 操作: 列出责任人拥有的权限、预算、时间、数据、人员、工具、依赖方和不可控变量。
   - 完成标准: 目标和执行人的权责资源匹配，或者明确哪些条件需要协商补足。
   - 判停条件: 如果目标明显不可控或资源缺口无法补足，输出风险记录和协商方案，不建议直接承诺。

5. **选择目标处理方式**
   - 操作: 在五种处理方式中选一项：直接承诺、修订目标、改为取证目标、改为小范围试点、拒绝/升级边界。
   - 完成标准: 用户得到一版目标处理结论，包含理由、下一步动作、所需证据和责任边界。

6. **再做 SMART 表述**
   - 操作: 只有前五步通过后，才把目标写成具体、可衡量、可达成、相关、有期限的形式。
   - 完成标准: SMART 版本不掩盖来源、价值、权责、资源和可控性假设。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 目标已经被确认值得做，用户只是要检查 KR、数字口径、期限或 SMART 表述质量。
- 用户需要完整战略规划、商业模式设计、市场进入策略或品牌定位。
- 目标涉及劳动争议、绩效处罚、裁员、合规、安全、财务承诺或法律责任。
- 执行人完全没有选择权，且当前目标只能服从；此时本 Skill 只用于记录风险和提出协商话术。

### 作者在资料中警告的失败模式

- 无目标领域被系统性忽视，重要工作长期没有负责人或完成标准。
- 目标难制定却硬套目标管理，形成模板化指标和表面配合。
- 条件、资源、环境变化后仍按原目标硬推。
- 把 SMART 当成目标价值判断工具，清晰地做错事。

### 来源局限

- 来源是作者未标注的培训 PPT，案例多为教学转述，不是一手组织研究。
- 两份 SMART 辅助 PPT 为 partial 文本层，只能作为来源变体，不能作为主证据。
- PPT 对权力不对等、劳动关系、真实资源谈判和知识工作目标讲得不足。

### 复盘方式

- 目标执行 1-2 个周期后，检查当初写下的来源、价值、资源和可控性假设是否成立。
- 如果目标完成但客户价值、长期能力或协作关系受损，补做 `goal-management-side-effect-audit`。
- 如果目标未完成，先检查资源/权责/环境变化，再进入 PDCA 或复盘，不要直接归因为执行力差。
