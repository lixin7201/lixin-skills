# 品牌屋定位-利益-RTB 证据审计

## R — 原文 (Reading)

> 品牌定位、品牌主张、品牌调性、品牌口号、核心目标人群、情感利益点、RTB、产品系列。
>
> — 《分章节P3-01 战略屋和品牌屋》Slide 13

> 用一个简单句式来陈述品牌定位就是：我(xx品牌)是__，为了什么样的人，提供什么样的好处。
>
> — 《分章节P3-03 品牌相关模型》Slide 12

## I — 方法论骨架 (Interpretation)

品牌屋把“品牌想怎么说”拉回“用户凭什么信”。它要求同时回答四件事：我是谁，我为谁存在，我给 TA 什么利益，我凭什么被相信。

品牌定位不是一句漂亮口号。口号、调性和视觉表达必须站在定位、利益点、RTB 和产品系列之上。没有 RTB 的利益点只是愿望；没有产品承接的定位只是包装。

这个 skill 的目标是拆掉空泛表达，生成一张定位证据表：每个目标人群、利益点、信任理由、产品功能、体验证据和禁用表达都必须对应起来。

## A1 — 书中的应用 (Past Application)

### 案例 1: 品牌屋模型

- **问题**: 企业希望用品牌资产推广多个产品，但容易只剩调性、口号和包装。
- **方法论的使用**: PPT 要求在品牌屋中同时写品牌定位、主张、调性、目标人群、情感利益点、RTB 和产品系列。
- **结论**: 品牌核心价值必须通过论据、支撑和产品提供进入用户心智。
- **结果**: 品牌表达从“我想被怎么看”转成“用户为什么相信我”。

### 案例 2: 单款产品信息屋

- **问题**: 单个产品需要把人群定位、产品定位、核心利益点和功能证据串起来。
- **方法论的使用**: PPT 以汽车产品为例，将新中产、舒适驾乘、空间设计、安全防护、前端科技等利益点连接到全景天窗、液晶仪表、导航、音响、空调和安全等级。
- **结论**: 产品卖点必须能支撑核心利益。
- **结果**: 传播不只列参数，而是让参数服务人群和利益点。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户要写品牌定位、产品定位、课程定位、个人 IP 简介或账号简介。
2. 团队有很多卖点，但不知道哪些能支撑真正的利益点。
3. 品牌口号听起来顺，但目标人群和可信证据不清楚。
4. 新产品想借用现有品牌资产，但担心品牌延展稀释信任。

### 语言信号

- “我的品牌定位怎么写？”
- “这个卖点凭什么可信？”
- “帮我做品牌屋/定位三角形”
- “RTB / reason to believe / brand positioning”

### 与相邻 skill 的区分

- 与 `scrtv-value-proposition-brief` 的区别: 本 skill 先审计定位和证据；SCRTV 用于把已核验的策略和价值写成表达。
- 与 `strategy-house-alignment-check` 的区别: 本 skill 看品牌定位和产品证据；战略屋看目标、战场和能力是否对齐。
- 与 `brand-health-penetration-loyalty-diagnosis` 的区别: 本 skill 做定位前置审计；品牌健康 skill 看市场和用户指标结果。

## E — 可执行步骤 (Execution)

1. **写定位句**
   - 完成标准: 用“我是 __，为 __，在 __ 场景提供 __ 好处”写出一版定位句。

2. **拆利益点**
   - 完成标准: 列出最多 3 个核心利益点，并标注是功能利益、情感利益、身份利益还是效率利益。

3. **补 RTB**
   - 完成标准: 每个利益点至少对应一个产品功能、交付能力、真实案例、用户反馈、认证、数据或体验证据。
   - 判停条件: 某利益点没有任何 RTB 时，删除该利益点或回到用户/产品验证。

4. **检查产品承接**
   - 完成标准: 把产品系列、服务流程、内容资产或交付体验连接到对应利益点。

5. **写禁用表达**
   - 完成标准: 列出 3-5 个不能说或必须加限定条件的宣传句，尤其是夸大效果、虚假承诺和未授权背书。

6. **生成可测试版本**
   - 完成标准: 输出一版定位句、一张利益-RTB 表、一个最小用户验证问题。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只要润色一句口号，不愿提供目标人群、产品和证据。
- 产品体验或交付明显支撑不了定位，应先修产品或交付。
- 涉及医疗、金融、保健、教育结果、投资收益等高风险承诺时，必须先做合规核验。

### 作者在资料中的失败模式提示

- 品牌屋如果只填口号、调性和风格，就会变成包装工具。
- 品类定位、人群、场景、问题和价格必须一起看，不能只抢一个抽象心智词。

### 作者的盲点 / 时代局限

- PPT 对原始调研、样本量、广告合规和用户反馈证据讲得不足；正式使用必须标注证据来源和强度。
- 五感符号、树概念和口号容易诱导过度包装，必须回连产品体验。

### 容易混淆的邻近方法论

- 品牌定位不是销售话术，销售话术要在定位可信后再写。
- 用户画像不是定位，目标人群必须能被真实行为、场景和反馈校正。
