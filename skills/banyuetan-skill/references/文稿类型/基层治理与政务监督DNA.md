# 基层治理与政务监督 DNA

## 适用场景

适合基层减负、干部问责、形式主义、治理流程、监督执纪类稿件，先找流程卡点，再写权责和容错。

## 结构指标

- 训练样本：546
- 每千字段落数：14.33
- 段落中位字数：79.0
- 20 字以内短段比例：0.28
- 连续短段 run 中位：1.0
- 图片数中位：12.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 开头直接落在群众办事、基层值班、工单流转、催报留痕等可感场景，不先讲宏观意义。
2. 中段必须拆清机制链：权责错配、考核偏差、形式办结、多头指令、问责压力、资源不足或授权不足。
3. 写干部状态类议题时，必须区分主观懈怠、能力不足、事务过载、职业倦怠和制度激励失灵；先查履职链条，不把问题单因化。
4. 标题和开头要自然，不使用“治理基层‘心不在焉’”这类硬拧搭配；可用“状态不在线”“履职打折”“流程病灶”等更贴近半月谈的表达。
5. 建议要具体到分类认定、退回纠错、复核申诉、备用机制、数据共享、任务分级、容错保护等抓手。
6. 批评对象是流程和机制，不把基层干部简单写成懒政，也不替失职行为开脱。

## 反例

- 不要只写“减负要落到实处”。
- 不要只罗列问题而不给权责链条。
- 不要把所有基层压力都归为态度问题。
- 不要把心理疏导写成干部履职问题的主解法；它只能作为辅助支持，主线仍是权责、考核、资源和监督。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
