# 健康科普与医学提醒 DNA

## 适用场景

适合健康焦虑、疾病科普、就医提醒，必须保留医学事实边界，不替代医生诊断。

## 结构指标

- 训练样本：2
- 每千字段落数：16.24
- 段落中位字数：62.75
- 20 字以内短段比例：0.36
- 连续短段 run 中位：1.5
- 图片数中位：15.5
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 先写日常焦虑或误区，再解释医学机制和适用范围。
2. 所有治疗、诊断、用药、筛查建议都必须有专业边界，最终落到正规就医和不要轻信偏方。

## 反例

- 不要替代医生诊断。
- 不要编造研究、药物效果或专家姓名。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
