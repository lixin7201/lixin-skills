# 金字塔结构练习教练

## R — 原文 (Reading)

> 本书包括4个部分、6大练习，可以帮助你理清心中的想法，并强化自己架构思想的能力。
>
> — 芭芭拉·明托，《金字塔原理2：实战篇》课程介绍

## I — 方法论骨架 (Interpretation)

这个 skill 把金字塔原理从“懂概念”变成“拿真实材料反复练”。
它不重新讲理论，而是给用户安排一条训练路线：找结构、检查纵向问答、判别横向归纳/演绎、写 SCQ、构建自己的金字塔、严格检查每组思想。
每次训练只抓一个失败环节，不把所有问题一次改完。
输出既要给改写结果，也要标注用户卡在哪里、下一次练什么。
它适合能力训练，不适合用户只要最快拿到一版代写稿。

## A1 — 书中的应用 (Past Application)

### 案例 1: 电话信息练习
- **问题**: 原电话信息把会议冲突、返程、会议室等条件按发生顺序堆叠。
- **方法论的使用**: 练习先让读者找结构，再对照重写稿，把碎片条件改成会议改期建议。
- **结论**: 最小事务信息也能训练结论先行和归类支撑。
- **结果**: 学习者看到“原文”和“重写后”的理解差异。

### 案例 2: 电玩游戏产业备忘录
- **问题**: 老板要求员工用一个下午调研市场、成本、目标玩家和技术平台，资料很多且时间紧。
- **方法论的使用**: 练习要求先确定老板问题，再建立金字塔结构、找出 S-C-Q、组织备忘录。
- **结论**: 临时调研汇报要围绕决策者问题组织，而不是按资料类别堆叠。
- **结果**: 训练从真实业务材料中构建金字塔的迁移能力。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户说自己懂金字塔原理、SCQA、MECE，但写周报、汇报、提案仍然乱。
2. 用户有一段真实草稿，想“边改边学”，而不是只拿最终稿。
3. 团队要训练新人结构化表达，需要题目、反馈和下一步练习。
4. 用户反复改句子但主旨还变，怀疑是结构问题。

### 语言信号

- “我懂金字塔但不会用”
- “拿这篇周报练一下结构化表达”
- “帮我做金字塔原理练习教练”
- “practice / coaching / drill / 找结构”

### 与相邻 skill 的区分

- 与 `conclusion-first-pyramid-report` 的区别: 本 skill 以训练为目标，会诊断失败环节并安排下一题；结论先行以一次性交付清晰汇报为目标。
- 与 `scqa-reader-question-introduction` 的区别: SCQA 只训练开头；本 skill 会把 SCQA 放入完整练习路线。
- 与 `horizontal-grouping-logic-check` 的区别: 横向检查是一个专项检查；本 skill 会根据用户薄弱点选择是否训练横向。
- 与 `pyramid-slide-one-point-check` 的区别: 单页检查偏交付质检；本 skill 偏能力形成。

## E — 可执行步骤 (Execution)

1. **选择真实练习材料**
   - 要求用户提供一段周报、邮件、PPT 页面、报告开头或混乱草稿。
   - 完成标准: 有可改写的真实文本，且用户允许保留原文和重写对照。
   - 判停条件: 没有材料时，只给练习题设计，不冒充已训练。

2. **诊断卡点**
   - 在找结构、纵向问答、横向关系、SCQ、构建金字塔、概括句六类中定位主要失败环节。
   - 完成标准: 只选 1-2 个当前最关键卡点。

3. **做一轮对照练习**
   - 先让用户或 agent 标出原文结构，再给出重写结构，并解释差异。
   - 完成标准: 输出“原文问题、结构图、重写版、为什么更清楚”。

4. **专项修补**
   - 按卡点选择练习：纵向写读者疑问，横向判归纳/演绎，SCQ 写第一个问题，概括句写结果或共性。
   - 完成标准: 用户能说出本轮修补的是哪条金字塔原则。

5. **安排下一题**
   - 给出 1 个同类真实任务或微练习，用于巩固迁移。
   - 完成标准: 下一题明确输入、要求、完成标准和复盘问题。

6. **复盘训练效果**
   - 记录本轮前后差异、仍然卡住的环节、下次优先练什么。
   - 完成标准: 形成训练日志，而不是只得到一篇改稿。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只想快速得到最终版本，不需要训练反馈。
- 没有真实材料，且不愿意做示例练习。
- 文稿事实、数据和结论本身不可靠，结构训练不能替代内容验证。

### 作者在书中警告的失败模式

- 未先理清思绪导致重复修改。
- 只看纵向不看横向，形成半截金字塔。
- 按标题或发生顺序制造虚假层级。
- 只列相似思想，不做分类提炼总结。

### 作者的盲点 / 时代局限

- 实战篇练习材料偏传统报告，迁移到 AI 协作写作、产品页面和短内容表达时需要改造。
- 参考答案是校准工具，不应被当成唯一正确表达。

### 复盘方式

- 每轮训练记录“失败环节、改写动作、完成标准、下一题”，累计形成个人结构化表达错题本。
- 隔 3-7 天拿新材料复练同一环节；能独立诊断并重写才算迁移完成。
