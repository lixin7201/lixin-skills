# 正确性—非共识证据矩阵

## R — 原文 (Reading)

> 这种利用双重维度来思考问题的方式，我们以后还会经常用到，也希望大家能够掌握。
>
> — 李笑来，第4、17、50章

---

## I — 方法论骨架 (Interpretation)

共识度与正确性是两条轴：多数认同可能正确或错误，少数意见也可能正确或错误。非共识本身不产生价值，只有在证据支持且市场尚未吸收时才可能形成机会。

先把主张改写成可证伪假设，列出支持、反方和基准率，再估计如果错了会损失什么。证据不足时用小额、短周期、可逆实验学习，而不是把勇敢或身份叛逆当作结论。

随着证据和共识变化，矩阵位置会移动；应记录何时更新、什么会推翻论文。

## A1 — 书中的应用 (Past Application)

### 案例：用真题数据反驳一万二词汇量共识

- **问题**：当时普遍认为托福至少需要一万二词汇量，作者怀疑该共识与真实语料不符。
- **方法论的使用**：他统计历年真题，构建2142词候选并用持续整理、校验和产品反馈验证。
- **结论**：非共识观点只有绑定数据、重复劳动和可观察结果才值得行动。
- **结果**：书中称相关词汇书长期畅销；销量与学习效果的外部因果证据不足。
- **证据位置**：candidates/cases.md c13，第17、52章

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队几乎一致反对一个新产品或方案，但存在可检验的少数判断。
2. 行业共识来自重复引用，缺少一手数据和反方条件。
3. 用户因为“别人都不懂”而想做高风险押注，需要证据和损失上限。

### 语言信号

- “大家都反对的新产品值得试吗”
- “少数意见是不是优势”
- “共识可能错了怎么验证”
- “contrarian evidence matrix”

### 与相邻 skill 的区分

- 与 `novelty-information-distortion-audit` 的区别：本 Skill评估主张正确性与共识位置；后者先审计热点输入的新鲜度和筛选失真。
- 与 `explore-exploit-mode-switch` 的区别：本 Skill决定是否有理由验证非共识假设；后者决定验证时采用探索还是利用模式。

## E — 可执行步骤 (Execution)

1. **填写二维矩阵**
   - 动作：分别估计主张正确性证据和认同度，禁止用认同度反推正确性。
   - 完成标准：两条轴都有独立证据、置信区间或明确未知。

2. **建立正反证据表**
   - 动作：写出可证伪主张、基准率、一手支持、最强反方、利益关系和会改变判断的条件。
   - 完成标准：至少一个强反方和一个论文破裂条件被认真保留。

3. **计算错误代价与实验预算**
   - 动作：估计错判的资金、时间、信誉、安全和机会成本，优先设计可逆代理实验。
   - 完成标准：实验损失上限、周期、样本和验收指标明确。

4. **更新矩阵位置**
   - 动作：按实验和新证据更新正确性置信度与共识度，作出扩大、保持、改向或停止决定。
   - 完成标准：结论可追溯到证据变化，不以“我早就说过”保卫身份。

### 整体验收与停止

- **完成标准**：二维矩阵、正反证据、错误代价、可逆实验和论文破裂条件齐全。
- **停止条件**：无法把高风险行动缩到可承受损失，或涉及安全/法律/投资且缺少专业与一手证据时停止。
- **复盘方式**：记录预测、实际、共识变化和自己是否因身份执着拒绝更新；每次扩大前重新审查反方。

## B — 边界 (Boundary) ★

### 不要在以下情况使用

- 不把非共识、逆势或别人反对本身当作优势。
- 不提供个性化投资结论；投资需另过标的、估值、流动性、集中度和制度风险防火墙。

### 作者在书中警告的失败模式

- 为了显得独立而坚持缺证据观点，或把一次盈利误当判断正确；共识与正确性被偷换。

### 作者的盲点 / 时代局限

- 原书的知识付费、比特币和平台案例带有2016—2017年条件及幸存者偏差，矩阵必须配合当前证据和风险预算。

### 容易混淆的邻近方法论

- 与 `novelty-information-distortion-audit` 的区别：本 Skill评估主张正确性与共识位置；后者先审计热点输入的新鲜度和筛选失真。
- 与 `explore-exploit-mode-switch` 的区别：本 Skill决定是否有理由验证非共识假设；后者决定验证时采用探索还是利用模式。
