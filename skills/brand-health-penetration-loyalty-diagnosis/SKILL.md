# 品牌健康渗透率-忠诚度诊断

## R — 原文 (Reading)

> 每个维度都可以通过具体的数据和案例研究来进行深入分析。
>
> — 《分章节P3-03 品牌相关模型》Slide 10

> 渗透率能够不断地扩大消费群体，而忠诚度则增加每一消费个体对该品牌产品和服务的消费量。
>
> — 《分章节P3-03 品牌相关模型》Slide 19

## I — 方法论骨架 (Interpretation)

品牌健康不是“看起来高级”，也不是某次投放 ROI 为正。它至少要同时看两个方向：有多少人愿意进入你的消费群体，以及已经消费的人是否愿意持续购买、推荐或增加消费。

PPT 把品牌五力、CBBE、品牌资产、渗透率和忠诚度放在一起，给了一个重要提醒：品牌是产品力、渠道力、营销力、管理力和心智资产共同作用的结果。只看传播会忽略产品体验，只看复购会忽略规模天花板，只看渗透会忽略关系质量。

这个 skill 用于把品牌问题从“投放不行/口号不行”拆成健康诊断：认知、联想、忠诚、专有资产、渗透、个体消费量和负面反馈分别出了什么问题。

## A1 — 书中的应用 (Past Application)

### 案例 1: 品牌五力检验

- **问题**: 企业想判断自己是否具备品牌竞争力。
- **方法论的使用**: PPT 将品牌竞争力拆成营销力、产品力、管理力、品牌力和渠道力，并强调每个维度可用数据和案例深入分析。
- **结论**: 品牌力不是单独的知名度，而是多种能力沉淀后的综合作用力。
- **结果**: 诊断不能停在“多投广告”，还要查产品、渠道、管理和执行。

### 案例 2: 渗透率和忠诚度四象限

- **问题**: 品牌不知道应扩大消费群体还是提高现有消费者忠诚度。
- **方法论的使用**: PPT 用消费群体大小和个体消费量区分理想品牌、问题品牌、发展不均衡品牌 I/II。
- **结论**: 健康品牌既有可观消费群体，又保持现有消费个体较高消费量。
- **结果**: 行动从“泛泛做品牌”变为选择扩渗透、提频次、修体验或重新定位。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 品牌有投放或内容数据，但不知道增长问题出在认知、信任、复购还是体验。
2. 用户问“我们品牌是不是健康”“该扩人群还是提高忠诚度”。
3. 销售短期上涨，但投诉、退款、差评或复购数据在恶化。
4. 团队争论应改定位、加投放、做会员、做新品还是修产品。

### 语言信号

- “品牌健康怎么看？”
- “复购低是品牌问题还是产品问题？”
- “渗透率和忠诚度怎么判断？”
- “brand health / penetration / loyalty / brand equity”

### 与相邻 skill 的区分

- 与 `brand-house-positioning-benefit-rtb-audit` 的区别: 品牌屋审定位和证据；本 skill 用指标诊断品牌结果。
- 与 `platform-playbook-currentness-audit` 的区别: 平台 skill 看打法时效和迁移；本 skill 看品牌长期健康。
- 与 `customer-journey-touchpoint-diagnosis` 的区别: 旅程 skill 定位触点掉点；本 skill 汇总品牌层面的规模、忠诚和心智状态。

## E — 可执行步骤 (Execution)

1. **定义品牌健康问题**
   - 完成标准: 写清当前异常，如知名度低、转化低、复购低、投诉高、增长停滞或投放依赖。

2. **收集至少两类证据**
   - 完成标准: 至少选两类：认知/提及、品牌联想、购买人数、复购/频次、客单价、投诉/退款、口碑评论、渠道表现、产品体验反馈。
   - 判停条件: 如果完全没有用户、销售或反馈数据，不做打分，只列最小取证计划。

3. **画渗透率-忠诚度象限**
   - 完成标准: 判断是理想、问题、低渗透高忠诚、高渗透低忠诚，或证据不足。

4. **追溯五力支撑**
   - 完成标准: 对营销力、产品力、渠道力、管理力、品牌力各写一条证据或缺口。

5. **识别短期/长期冲突**
   - 完成标准: 标出短期转化、ROI、退款、投诉、复购、品牌认知之间是否互相牺牲。

6. **选择一个修复方向**
   - 完成标准: 在扩人群、提频次、修产品、改承接、改定位、停投放中选一个主方向，并设观察指标。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 只有团队主观感受，没有任何真实用户、销售、评论、客服或渠道证据。
- 用户只需要写定位句，应转 `brand-house-positioning-benefit-rtb-audit`。
- 用户要核验平台投放规则、广告产品或算法变化，应转 `platform-playbook-currentness-audit`。

### 作者在资料中的失败模式提示

- 品牌五力各维度必须用数据或案例研究深入分析，不能只主观打分。
- 忠诚度高但消费群体有限，和消费群体大但忠诚度低，是两种不同的不均衡。

### 作者的盲点 / 时代局限

- PPT 未提供指标采集方法、样本量、行业基准和统计口径；正式使用必须标注数据来源、时间窗口和不确定性。
- 不同行业的渗透率、忠诚度和频次口径不同，不能直接套用同一阈值。

### 容易混淆的邻近方法论

- 品牌健康不是投放复盘，ROI 只是其中一个短期指标。
- 复购低不一定是品牌问题，可能是品类低频、交付差、售后差或用户生命周期短。
