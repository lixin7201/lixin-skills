# 人物故事 DNA

- **适用场景**：逝者纪念、名人一生、历史人物成败、普通人的真实事件，并由人物命运提炼生活智慧。
- **标题 DNA**：姓名 + 年龄/现状 + 人生判断；去世/重大节点 + 反差生平 + N 句话；事故事实 + 普遍原则。
- **开头 DNA**：最新节点或代表性场景先行，再用 5—8 个短段勾出人物气质与一生反差，随后明确本文要从其人生学到什么。
- **推进链**：人物钩子 → 关键生平节点 → 3—8 个主题章节/人生选择 → 每节一段生活映射 → 最终命运或精神遗产 → 致意/自我提醒。
- **材料偏好**：访谈、传记、公开报道、作品、人物言论、历史材料。人物行动必须比评价多；用细节证明“通透、坚韧、善良”，不要只贴标签。
- **段落节奏**：句长中位 26 字；全量中位正文约 3129 字，较账号整体更长。可以按时间线展开，也可以用“8 句话”主题式，但两种骨架不要混乱切换。
- **情绪温度**：7/10。纪念稿克制温柔，事故稿严肃警醒，历史人物稿冷静评析；避免消费死亡。
- **结尾 DNA**：回到人物最能代表的一句话/行动，再落到读者自己的生活；纪念稿只做致意，不强行营销互动。
- **事实核查**：出生死亡、亲属、疾病/事故原因、生平事件、历史评价、引语均需至少双源；在世人物避免传闻，逝者避免猎奇。事故个案的责任归因以官方结论为准。
- **像 / 不像警告**：像的是“用事件显人格”；不像为配合主题重排或虚构人物经历。本类内部至少有三条不能强并的子路线：纪念/讣告、人物智慧清单、历史成败评传；另有事故警示稿应优先按热点事实治理。
- **深读样本与置信度**：`1408e97645c0154b`《蔡澜去世：无儿无女，散尽千金，8句话道尽一生智慧》、`15b7cf14dfa37dd5`《68岁陈道明：人生走到最后，最亲的不是子女和老伴，而是这一个人》、`13a7ee522fe6225a`《一家四口三亚溺水遇难：世上从无侥幸，失去的都是人生》、`6717b8f398546fc4`《悲情吕布：做人的格局，决定了人生的结局》。**置信度：中**；“人物承载观点”稳定，但子路线差异大，不能共用一套开头和情绪档位。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
