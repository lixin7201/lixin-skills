# 紫杉路线 DNA

- **最擅长类型**：观点与生活方式、成长疗愈，其次为人际和金钱职场；语料高度集中在 2021—2022 年。
- **典型切口**：一个人人都懂的困扰，例如心累、独处、不想上班、赚钱，再用经典引语和多个简短故事证明一个直接判断。
- **标题与开头**：标题短、像一句口号或祝贺；开头常用书中金句、身边观察或网络话题，很快亮出中心论点。
- **结构**：中心判断 → 3 个故事/人物 → 每段一条金句 → 重复压实中心 → 简短行动号召。框架清楚，复杂性低。
- **句段节奏**：中位约 2,258 字，为较短路线；每千字 35.30 段、段落中位 26.5 字；粗体约 8.32/千字，高于基线。整体像节奏紧凑的经典公众号观点文。
- **材料习惯**：书籍和身边故事最强，辅以网络人物、少量影视；研究数据不多。
- **情绪强度**：中等。痛点直接、判断鲜明，但多是安静、自爱、赚钱、自律等熟悉价值，不追求复杂争议。
- **与账号基线差异**：更短、更金句化、更依赖重复中心判断；时间分布早，代表账号较早阶段的观点文模板。
- **误判警告**：不能把早期模板当成当前全账号风格。若用于现代题目，应保留简洁骨架，但减少过度绝对化和“心态决定一切”的归因，避免忽略结构性问题。
- **证据与置信度**：整体统计 88 篇；训练候选 8 篇；深读 3 篇（含 1 篇早期异常高互动加权样本）。**置信度：中高**，但有明显年代局限。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
