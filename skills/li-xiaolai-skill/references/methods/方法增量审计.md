# 方法增量审计：G01 / G02 / G04

> 目的：判断本轮公众号、访谈、决策与近年 AI 材料是否揭示了昨日 27 个方法核之外的独立方法。  
> 状态：G01/G02 降级合并；G04 通过预审，等待用户轻确认后才构造。  
> 隔离：只用训练侧研究和既有方法核，没有读取 holdout。

## 1. cangjie 阶段 0：合集骨架

### 类型与主旨

- **类型**：跨著作、文章、讲演和决策记录的方法论合集。
- **一句话主旨**：通过澄清概念、校准现实、主动换焦点、进入真实行动并用反馈修订，让能力和选择在长期中复利。
- **核心问题**：在信息不完整、环境变化和个人能力有限时，怎样把“想明白”变成可运行、可复核、可退出的行动系统。

### 五个一级结构

1. 概念与现实：定义、分类、比较、因果、前提和证据；
2. 学习与生产：阅读、教学、作品、交付和反馈；
3. 选择与长期：注意力、论文、周期、风险与退出；
4. 新结构与转向：转换焦点、探索/利用和有界进入；
5. 环境与责任：受众反向塑造、服务边界和影响力外部性。

### 关键术语

个人操作系统、践行、转换焦点、主动地被动、反向塑造、财富自由/时间选择权、长期、复利、教练、完整动作链。

### 批判与局限

1. 个人成功和公开复盘存在幸存者偏差、选择性叙事和不可复制资源；
2. 强命名和强语气可能超过证据，尤其在投资、健康和群体判断中；
3. 早期材料对个人能动性强调较强，制度、资源、权力和照护约束需要补入；
4. 2017 前后市场实践显示，新趋势洞察和行动速度不能替代治理、合规、外部性和系统刹车；
5. 近年 AI 材料处于人机协作环境，不能把成文结果全部认证为稳定个人能力或文风。

### 可 Skill 化边界

- 可独立 Skill 化：有清晰触发、步骤、停止条件，并通过跨域、预测力、排他性和相邻方法诱饵的程序。
- 只进入人物认知层：能解释观察顺序，但独立步骤与现有方法高度重叠。
- 不 Skill 化：单次轶事、历史市场判断、医疗个案、身份宣言和没有独立证据的结果。

## 2. G01｜概念卫生：定义—推理—行动链

### 候选程序

1. 找出承担多个判断的关键词；
2. 写最小定义、非定义、范围与相邻概念；
3. 检查定义怎样改变推理、选择和行动；
4. 用事实、反例与结果回测，必要时重命名。

### 三重验证

- **V1 跨域：通过**。学习、财富、AI、语言、支付/清算和社会标签中重复。
- **V2 预测力：通过**。面对“远程工作不适合我”，可先拆“远程”“不适合”“效率/孤独/管理”再导出不同试验。
- **V3 排他性：不通过（独立 Skill）**。“先定义清楚再推理”是广泛常识；独特部分主要是作者化命名与强调强度，不能只靠措辞通过。

### 相邻方法审计

- 已发生的含糊问题：`accurate-restatement-feedback-loop`；
- 发布主张的事实/确信/未知：`speaker-claim-consistency-audit`；
- 现实前提：`reality-constraint-premise-audit`；
- 非共识与证据：`correctness-nonconsensus-evidence-matrix`。

### 结论

不新建。作为 M1 的认知入口和 H01 的总控动作，按场景路由现有方法。

## 3. G02｜以教促学—直接使用—反馈闭环

### 候选程序

1. 选一个需要向真实对象解释或交付的任务；
2. 教、写、造或直接使用；
3. 记录复述失败、使用错误和交付缺口；
4. 回到最低知识缺口并迭代。

### 三重验证

- **V1 跨域：通过**。教学、英语、阅读、家庭教育、写作、软件和产品中重复。
- **V2 预测力：通过**。面对“学完 SQL 还不会分析”，能导出为真实业务问题做报告、让他人复核并回补缺口。
- **V3 排他性：不通过**。learning by teaching / learning by doing 是广泛方法，不属于足够独特的新单元。

### 相邻方法审计

- 是否接近真实受益者：`production-distance-usefulness-audit`；
- 讲解与帮助做到的责任：`instruction-coaching-responsibility-split`；
- 必要动作和反馈是否完整：`whole-action-chain-validity-audit`；
- 内容是否会繁殖技能和行动：`evergreen-content-fertility-filter`。

### 结论

不新建。作为 M2 与 H04，通过 2—3 个既有方法组合执行。

## 4. G04｜转换焦点—新结构优先

### 候选名称

- slug：`world-first-focus-shift`
- 中文名：新结构焦点转换

### 候选程序

1. **冻结旧身份问题**：写出“这个新东西怎样帮助现在的我/旧业务”的原问题；
2. **列新结构增量**：相对旧结构，哪些能力、成本、角色、关系和约束发生了真实变化；
3. **重写世界优先问题**：不假定旧身份必须保留，问“新结构中什么问题现在最值得解决”；
4. **有界试进入**：选一个可逆、低损失、能接触真实受益者的动作，设置证据门和退出条件。

### 三重验证

- **V1 跨域：通过**。
  - 职业与投资转向：从原有教学/写作身份转向互联网与区块链结构；
  - 微信生态：从“用微信宣传旧业务”转向持续写作、社群、支付和内容产品；
  - 内容付费：从书/文章转向订阅和长期服务；
  - AI：从辅助旧写作流程转向软件、研究代理、跨语言生产与小说。
- **V2 预测力：通过**。
  - 新问题：“AI 代理火了，我是咨询顾问，应该给旧服务加什么功能？”
  - 推导：先暂停功能清单，研究代理如何改变问题发现、交付、持续反馈和责任边界；可能值得重做服务结构，而不是给旧流程加外挂。
- **V3 排他性：通过**。
  - 常见建议是“评估新工具怎样提升现有工作”或“先广泛探索”；该方法把**问题重写**放在探索/利用之前，并允许旧身份不再是中心。
  - “转换焦点”在多次公开材料和重大转向中有稳定作者化用法。

### 相邻方法诱饵

| Prompt | 应触发 | 原因 |
|---|---|---|
| “AI 代理来了，我只想给旧培训课加客服，是否漏掉了更原生的机会？” | G04 | 需要先重写旧身份中心的问题 |
| “方向已有可重复信号，我还要不要继续广泛尝试？” | `explore-exploit-mode-switch` | 已经进入搜索模式选择，不是焦点重写 |
| “这条 AI 热搜到底可信吗？” | `novelty-information-distortion-audit` | 先审计输入信息，不是决定观察中心 |
| “团队很忙，但离真实用户价值有多远？” | `production-distance-usefulness-audit` | 已有方向，需审计受益者和生产距离 |

### 盲点与边界

- 新结构叙事可能是营销包装；必须先过新鲜度、证据和现实门。
- 不以“未来”为名忽略现金流、照护、健康、合规和不可逆损失。
- 亲自进入仍可能形成偏样本和沉没成本；试验必须有预算与退出门。
- 高风险金融、医疗、法律和安全领域不得降低专业标准。

### 结论与检查点

G04 通过三重预审，建议进入 cangjie 阶段 2 构造与阶段 4 压力测试。按 cangjie 硬门，用户确认前不创建新 Skill、不安装、不改变昨日 27 个方法核。
