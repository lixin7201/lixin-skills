# 视觉风格指南

## 视觉任务

十点读书式图文不是把正文切碎，而是让读者在“生活场景—人物故事—判断转折—行动建议”之间换气。视觉元素服务情绪承接和材料可信度。

## 配图策略

- 生活方式/成长：日常空间、背影、手部动作、通勤与家庭物件，避免虚假摆拍式成功学。
- 婚恋/亲子：关系距离、家庭场景、共同动作；避免夸张冲突、可识别未成年人和羞辱性画面。
- 书影/人物：封面、剧照、公开肖像和时代环境；明确版权来源。
- 热点社会：以公开通报、场景图和规则截图为主；不传播未经证实的现场图、隐私和猎奇画面。
- 健康：使用机构公开图示或中性场景；不生成症状对照图来代替诊断。

## 版式参数

- 训练中位：约 4.27 张图/千字；正常波动 3.68–5.10。
- 图片间至少隔一个完整信息单元；同一案例不因句子多而重复插图。
- 短段用于停顿、反手判断、对话与分节承诺；解释、事实和方法要保持完整。
- 粗体强调中位约 5.93 处/千字，正常波动 3.93–8.81。

## 输出契约

用户未给图片时，只输出：`位置 + 画面功能 + 可用来源类型 + 隐私/版权提醒`。不得假称“配图如下”或制造不存在的原始素材。
