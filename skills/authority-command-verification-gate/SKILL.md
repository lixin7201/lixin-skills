# 权威指令独立核验门

## R — 原文 (Reading)

> “选择将权力交给谁时要很谨慎，因为权威人物一旦上台……就很难被推翻。”
>
> — 查理·芒格，第三讲；提取文本第 4024–4048 行

## I — 方法论骨架 (Interpretation)

权威身份不能改变物理、会计、法律和伦理事实。高影响指令进入执行前，接令者先复述目标、对象、理由和限制，再用独立证据检查授权、可逆性和明显异常。若关键条件不满足，使用既定挑战与升级路径，而不是在公开场合争夺地位。发令者也要减少无意的命令信号，并明确欢迎事实性挑战。

## A1 — 书中的应用 (Past Application)

### 案例：护士误读指令

- **问题**：医嘱缩写被机械执行，即使结果与常识明显冲突。
- **方法论的使用**：芒格用该案例说明权威会压制独立判断和澄清动作。
- **结论**：高风险指令必须回读、澄清对象并检查明显异常。
- **结果**：成为训练质疑权威的警示；医疗流程应以当前专业标准为准。

### 案例：将军的动作被当作命令

- **问题**：新飞行员把高位者的动作误解为指令并执行。
- **方法论的使用**：把权威暗示、沟通模糊和缺少核验放进同一事故链。
- **结论**：发令者和接令者都应控制无意权威信号。
- **结果**：说明仅要求下属“勇敢”不足，必须有制度化回读和挑战门。

## A2 — 触发场景 (Future Trigger)

1. 上级要求跳过备份、审批、测试、审计或安全护栏。
2. 指令与事实、常识、授权或书面流程明显冲突。
3. 团队害怕让权威难堪，因而不复述、不澄清、不上报。

语言信号：“领导说直接做但我觉得不对”“能不能拒绝这个命令”“authority gradient”“先回读确认”。

与相邻 Skill 的区分：本 Skill处理一条具体权威指令；`lollapalooza-bias-stack-audit` 处理权威与从众、承诺、压力等多机制叠加。普通沟通误解则使用沟通闭环，不必升级为权威审计。

## E — 可执行步骤 (Execution)

1. **回读指令**：复述目标、对象、时间、理由、授权和不可触碰约束。
   - 完成标准：发令者确认复述，含糊缩写和隐含假设被展开。
2. **独立核验**：检查事实、系统状态、书面程序、权限、可逆性和伦理/合规红线。
   - 完成标准：至少一个不依赖发令者身份的证据源。
3. **分级响应**：可执行则留痕；可澄清则暂停；明显异常则挑战并按预案升级。
   - 判停条件：不可逆、高危、越权、违法或无备份时不执行，立即走正式升级/应急路径。
4. **安全表达**：私下、事实优先、面向共同目标提出异议；重大风险不得因“给面子”隐瞒。
   - 完成标准：异议、决定者、理由和最终授权有记录。
5. **复盘**：记录误解来自语言、层级、流程还是文化；由发令者修正无意信号并演练下一次挑战路径。

## B — 边界 (Boundary)

- 不鼓励无视合法应急指挥、擅自建立并行指挥或公开羞辱权威。
- 失败模式：把地位当证据；照做后甩锅；只鼓励“勇敢发声”却没有回读与升级流程。
- 盲点：书中轶事不能替代航空、医疗、军队或生产系统的当前专业协议。
- 表达策略不能压过安全、法律和伦理红线；高风险时必须留下正式记录。
