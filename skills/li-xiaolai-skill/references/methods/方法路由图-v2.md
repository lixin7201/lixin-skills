# 28 个方法核路由图

> 版本：2026-07-21，用户确认新增 `world-first-focus-shift` 后生效。模型先选角度，方法再执行；默认只调用 1—3 个最窄方法。

## 总路由

```text
P-1 新结构焦点重写（仅在旧身份锁定时）
→ P0 事实、风险、表达边界
→ P1 问题归属、目标、资源与受益者
→ P2 学习/方案选择与信息模式
→ P3 执行、长期与复盘
→ P4 沟通、教学与发布
→ P5 平台、受众与商业闭环

高风险旁路：技巧/运气 → 多周期 → 后见偏差
```

## P-1｜新结构焦点重写

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `world-first-focus-shift` | 新技术/平台出现，问题仍被旧职业、旧产品和旧流程锁定，需要先问新结构真正改变了什么 | 趋势真假未证先走 P0；已确定方向后的广搜/深挖走 P2；不可逆跨界先走现实与风险门 |

**P-1 验收**：旧身份假设、结构增量、世界优先问题、真实受益者和有界试进入齐全；保留旧路径也是合法结论。

## P0｜事实、风险与表达边界

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `speaker-claim-consistency-audit` | 发布主张，需区分事实、个人确信、组织立场和未知 | 真实性不能替代证据，也不能伪造确信 |
| `novelty-information-distortion-audit` | 热点、算法、营销或 FOMO 迫使立刻改方向 | 不拖延可靠安全告警和关键事实变化 |
| `reality-constraint-premise-audit` | 计划依赖速成、零交换、完美、全知或瞬时改变 | 不把接受现实变成消极放弃或压制求助 |
| `correctness-nonconsensus-evidence-matrix` | 共识与自己的判断冲突，需验证少数观点 | 非共识不等于正确；高风险不得越过预算和专业标准 |

## P1｜问题归属、互动目标、资源与受益者

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `problem-ownership-routing` | 不确定应接手、协助、转交、升级还是退出 | 不以归属逃避安全、合规、照护或岗位责任 |
| `discussion-goal-routing` | 对话从求真滑向争胜，需决定继续、修复、退出或升级 | 不用“不争论”压制申诉、举报和安全异议 |
| `attention-allocation-ledger` | 很忙但重要事项未推进，或平台/争论持续占用注意力 | 不切断必要关系、治疗、照护和职责 |
| `production-distance-usefulness-audit` | 评估学习、工作或产品是否接近真实受益者和交付 | 不以短期收入否定公共服务、照护和基础研究 |

## P2｜学习、方案选择与信息模式

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `explore-exploit-mode-switch` | 不知道应广泛试探还是沿已验证路径深挖 | 不做无预算随机试错或不可逆重仓 |
| `premature-reference-dual-speed-reading` | 材料循环依赖、初读卡在未定义术语 | 法律合同和安全步骤首轮仍需精确 |
| `decentralized-teacher-source-ladder` | 没有单一老师、资料冲突，需要来源升级 | 不拒绝合格导师，不让社区替代专业责任 |
| `interest-after-competence-diagnostic` | 尚未入门就以“没兴趣”退出 | 不强迫长期坚持，不忽略价值冲突和有害环境 |
| `familiarity-weighted-estimation` | 首次/陌生任务只能给单点工期承诺 | 不用于决定方向是否值得，也不替代紧急处置 |

## P3｜执行、长期与复盘

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `whole-action-chain-validity-audit` | 一次成功被当成整套策略，或链条缺进入/交付/退出/复盘 | 不为“完整”增加无价值流程 |
| `decision-node-error-multiplier-audit` | 策略依赖连续多次临场正确和不断加规则 | 不删除必要安全检查和关键责任 |
| `long-change-intensity-budget` | 写作、运动、学习反复启动又放弃 | 不把低强度变成无限拖延，不单独处理严重成瘾 |
| `active-choice-passive-hold-protocol` | 已研究长期方向却被短期噪声诱发频繁改动 | 不永久持有坏对象；前提破裂必须重开 |

## P4｜沟通、教学与发布

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `misunderstanding-map-preflight` | 发布前担心规则、文章或产品被系统性误读 | 主张尚未证实时先回事实层；个别反馈用复述闭环 |
| `accurate-restatement-feedback-loop` | 提问、投诉或评审含糊，双方可能答不同问题 | 不拖延紧急处置，不迫使受害者反复解释 |
| `audience-distance-conclusion-ordering` | 面向支持者、陌生人和反对者决定先结论还是先证据 | 不延迟披露安全、法律和财务风险 |
| `instruction-coaching-responsibility-split` | 课程把讲清与帮助做到混成一个承诺 | 不越过医疗、心理、法律资质，不把大社群当必需 |
| `evergreen-content-fertility-filter` | 判断材料是否正确、有用、必备、耐久且会产生行动 | 不淘汰所有时效内容，不先包装后核验 |

## P5｜平台、受众与商业闭环

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `audience-reverse-shaping-audit` | 流量上涨但目标客户流失，受众奖励正在带偏方向 | 不贬低意外受众，也不机械拒绝自然演化 |
| `platform-commerce-closure-audit` | 有流量/粉丝却没有需求、支付、履约或复购 | 无商业目标时不强行变现；不得绕过合规与退款 |

## 高风险旁路

| 方法 | 触发 | 不要误用 |
|---|---|---|
| `skill-luck-spectrum-routing` | 不确定结果主要靠训练还是运气 | 不做宿命论，也不事后贬低成果 |
| `multi-cycle-trend-evidence-gate` | 用单段上涨或一个景气期外推长期趋势 | “两个周期”不是自然定律，结构变化时不得机械外推 |
| `extreme-price-volume-hindsight-audit` | 用历史最高/最低点评价当时决策 | 不否认真实流程错误，也不输出买卖建议 |

金融、法律、医疗、安全和高影响力公开表达默认先走 P0；历史案例只分析过程。

## 常用最小组合

| 任务 | 组合 | 顺序 |
|---|---|---|
| 新趋势是否改变旧业务中心 | `novelty-information-distortion-audit` + `world-first-focus-shift` + `production-distance-usefulness-audit` | 趋势真 → 重写问题 → 验证受益者 |
| 陌生领域自学 | `decentralized-teacher-source-ladder` + `premature-reference-dual-speed-reading` + `production-distance-usefulness-audit` | 来源 → 阅读 → 真实输出 |
| 长期习惯 | `attention-allocation-ledger` + `long-change-intensity-budget` | 腾资源 → 设稳定强度 |
| 长期方向/资产论文 | `multi-cycle-trend-evidence-gate` + `active-choice-passive-hold-protocol` | 证据门 → 条件化少干预 |
| 文章/演讲发布 | `speaker-claim-consistency-audit` + `misunderstanding-map-preflight` + `audience-distance-conclusion-ordering` | 主张真 → 误解测试 → 排序 |
| 产品从原型到交付 | `production-distance-usefulness-audit` + `whole-action-chain-validity-audit` + `platform-commerce-closure-audit` | 受益者 → 全链 → 商业闭环 |
| 冲突与投诉 | `discussion-goal-routing` + `accurate-restatement-feedback-loop` + `problem-ownership-routing` | 分目标 → 建共同模型 → 定责任 |
