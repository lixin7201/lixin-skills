# 思考视角路由

## 分层原则

思考 Skill 只负责把素材想透，不负责最终文风。最多选择 1 个主视角；只有重要判断需要反证时，追加 1 个反方视角。

运行人物 Skill 时：

1. 只读取其心智模型、决策启发式、研究协议和边界；
2. 忽略第一人称角色扮演、口头禅和表达 DNA；
3. 先产出内部思考备忘录，再交给写作层；
4. 正文不得出现“某某会怎么看”、人物口吻或人物 Skill 名；
5. 当前公司、市场、平台、政策和人物事实仍需实时核验。
6. 按 `thinking-memo-schema.json` 输出内部 JSON；进入写作层前删除人物名、角色第一人称、口头禅、政治立场和身份攻击。

## 内部备忘录与写作交接

内部备忘录必须符合 `thinking-memo-schema.json`，包含 `main_skill/counter_skill/mode` 供路由审计。写作前新建只含七个白名单字段的对象并校验 `writing-handoff-schema.json`：`problem/facts/unknowns/mechanisms/counterevidence/boundary/action`。禁止把原始备忘录直接交给写作层。

## 选择规则

1. 真实经历本身已经有强矛盾时，可以不调用人物 Skill。
2. 同时命中多个时，选择最窄、最贴近当篇主问题的一个。
3. 需要反证时，优先选择机制不同的视角，例如 Jobs 的体验判断配 Feynman 的验证，Naval 的杠杆判断配 Taleb 的尾部风险。
4. 人物 Skill 没有当前事实时只提供模型，不生成事实。
5. 思考备忘录完成后清除人物语气，再进入原生写作 DNA 融合。

## 复利与反馈专项

命中“复利、长期主义、反馈太慢、容易放弃、学习很多但没结果”时，内部 memo 必须回答：

1. 当前所谓“复利”具体积累的资产是什么；
2. 是没有最终结果，还是连中间反馈都没有；
3. 哪些学习已经进入作品、能力或真实行动，哪些只是知识摄入；
4. 继续与停止各自最强的反证是什么；
5. 哪个矛盾目前仍未解决，不能被文章强行收口。

最终语言继续由李鑫口语 DNA 所有，不把这些问题写成概念课。
