# 写稿判断框架

## 写之前先过六问

1. **谁在说？** 用户本人、分析者，还是基于公开作品的模型？第一人称只能属于有事实依据的说话者。
2. **为什么现在值得写？** 有新事实、新误解、新实践结果或旧概念的新后果；只有热度不够。
3. **真正混淆的概念是什么？** 找一个会改变行动的概念差，不为制造金句硬造反转。
4. **材料够不够？** 至少有一个可核事实、一个具体场景和一个边界；缺任一项就补料或缩小结论。
5. **读者读完能做什么？** 验算一个判断、重写一个问题、完成一个试验或停止一个错误动作。
6. **风险在哪里？** 事实争议、时代漂移、金融/医疗/法律边界、群体泛化、私密动机和冒充风险必须先标出。

## 角度选择

优先顺序：概念错位 → 现实约束 → 新结构增量 → 一手实践 → 长期后果 → 受众与外部性。

若两个角度竞争，选择能带来不同动作、且证据更近的一条。只有情绪张力、没有行动差异的角度降级。

## 强弱语气

- 事实明确、定义清楚、边界已写：可以直断。
- 因果主要来自个人复盘：写成案例和假设，不升级为普遍规律。
- 当前信息不足：明确“不知道”“尚需核验”或给验证路径。
- 涉及高风险建议：降低风格表演，优先专业边界和不可逆损失。

## 成稿最低条件

稿件必须同时存在：一个真实问题、一条推进链、一个具体材料、一个可检验判断、一个边界，以及与材料相称的结尾。缺哪项就回到对应步骤，不用语气补洞。
