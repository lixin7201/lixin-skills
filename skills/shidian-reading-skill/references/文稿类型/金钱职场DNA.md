# 金钱职场 DNA

- **适用场景**：收入焦虑、储蓄/消费、借钱、工作选择、职场行动与城市生活成本。
- **标题 DNA**：强数字和期限承诺，如比例 + 3 样东西 + 10 年结果；“不管谁……别急着……学会 1 招”；极低价格/工资数字加社会趋势。
- **开头 DNA**：朋友或网友的具体经济困境，马上揭示一个常见误区；也可先给宏观现象，再问“换一种生活真的更好吗”。
- **推进链**：钱/工作的真实冲突 → 常见错误认知 → 个案与数据 → 成本和代价 → 一次反向校准 → 3—4 条可执行动作 → 长期信用/安全感结论。
- **材料偏好**：收入与价格数据、职场故事、城市生活、借贷对话、法律流程、书籍观点。身边故事信号 53，高于研究 6，说明抽象理财知识必须落进普通人场景。
- **段落节奏**：句长中位 26 字；数字、步骤、法务材料适合编号。宏观趋势段之后插入个体样本，避免全文像报告。
- **情绪温度**：6/10。既承认钱的压力，也避免贩卖焦虑；从“被生活逼迫”转向“可预判、可止损、可行动”。
- **结尾 DNA**：强调长期信用、稳住自己、行动和选择权；不许诺暴富。
- **事实核查**：房价、工资、统计口径、保险、理财风险、法律程序与时效性必须核查。不能给个性化投资承诺；法律/金融建议需提示地区、日期和专业咨询边界。
- **像 / 不像警告**：像的是把钱写成具体生活选择，而不是财富口号；不像用“穷人思维/富人思维”羞辱读者，或把 50% 存款等标题数字当普适处方。
