# 情感婚恋互动：内容机制

购买包的去重正文只用于提炼冲突机制，不提供大宜宾平台文风；运行 Skill 不携带来源正文或源路径。

八个隔离子类：彩礼婚房嫁妆、婆媳与双方家庭、夫妻日常与家庭经济、离婚再婚与继亲、相亲催婚与单身、生育育儿与养老、亲戚手足与财产、信任出轨与人身安全。最后一类默认人工复核。

每篇只组合一条主链：

```text
关系双方 → 具体导火索 → 可感知细节 → 双方可成立的立场 → 一次升级 → 待裁决问题
```

可感知细节从金额/比例、物品、时间节点、明确动作和短对话中选 2–4 类，不全部堆满。

反模板：同批稿不复用关系、导火索、标题骨架、段落功能顺序和结尾问法；同一篇最多一次反转；不固定任何关系角色为好人或坏人；不让所有故事都以离婚、报警、悔悟或众人称赞收尾；不沿用来源文章的完整人物、金额、物品、事件顺序和结果组合。

每天两个虚拟选题优先各取一条：现实成本轨（彩礼婚房、夫妻经济、亲戚财产）与关系边界轨（婆媳、相亲、生育养老、离婚再婚）。信任安全不用于无人审看的自动补位。
