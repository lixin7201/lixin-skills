# 节气生活美学 DNA

- **适用场景**：春节、清明、四季物候、食物、花木、家居、仪式感与慢生活。核心价值必须来自具体感官和时间节点，而不是泛泛“生活小事”。
- **标题 DNA**：年份/节日 + N 件仪式小事；带季节触感的短句；“把春天吃进嘴里”式感官转换；纪念日与季节意象相连。
- **开头 DNA**：日历节点、天气、食物、花木或家人正在做的一件事；用气味、颜色、声音、温度把读者带入，而后再谈意义。统计上判断/铺垫 4/8，高于引用。
- **推进链**：节令/物候 → 一组感官场景 → 风俗或个人记忆 → 3—9 个可参与的小仪式 → 家庭/文化意义 → 温柔祝愿。
- **材料偏好**：日常细节、家人、食物、古诗词、风俗、城市/乡野观察。材料要“可闻可见可触”，不能只列抽象价值。
- **段落节奏**：句长中位 28 字；全量正文中位约 2314 字，是较轻的一类；短段比例 0.308，图片密度为 11 类最高。文字应留白，不要解释完每个意象。
- **情绪温度**：5/10。温暖、怀旧、清新，偶有纪念性的哀伤；不做高强度说教。
- **结尾 DNA**：回到节令或眼前小事，用祝愿、邀请分享仪式/照片收口。
- **事实核查**：节气日期、风俗地域、食材与健康说法、诗词出处、人物纪念日都要核查；避免把地方风俗说成全国传统。
- **像 / 不像警告**：像的是“先有季节和感官，再有人生感悟”；不像给普通成长清单套一个“春天/新年”壳。训练高分样本中《不要在小事上，和任何人对抗》和《能让你变幸福的20件小事》主脊柱是成长/生活清单，不应当作节气 DNA 的核心证据。
- **深读样本与置信度**：`8c7b5939ee31539d`《能让你变幸福的20件小事》、`07e1015e36f88595`《不要在小事上，和任何人对抗》、`25b657e1c338e3c2`《张国荣逝世18年：春天该很好，你若尚在场》、`2c9978a9fa1c899e`《2023，最有仪式感的9件小事》。**置信度：中低**；全量仅 56 篇，且 4 篇高分样本中有 2 篇明显跨类。生产时应收窄为真正的节令/感官/仪式路线。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
