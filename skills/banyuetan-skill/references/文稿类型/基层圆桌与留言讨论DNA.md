# 基层圆桌与留言讨论 DNA

## 适用场景

适合围绕一个基层话题汇总留言、归纳症结、提出制度建议，网友发言要分组推进。

## 结构指标

- 训练样本：65
- 每千字段落数：18.83
- 段落中位字数：42.0
- 20 字以内短段比例：0.34
- 连续短段 run 中位：5.0
- 图片数中位：21.0
- 常见推进链：话题引入 -> 网友留言分组 -> 症结归纳 -> 建议收束 -> 互动口

## 写稿方式

1. 开头说明讨论从哪个基层话题来，随后按留言观点分组。
2. 每组先归纳症结，再给少量代表性材料；最后用“谈谈说”式判断收束。

## 反例

- 不要把留言当事实调查。
- 不要只堆观点不归纳。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
