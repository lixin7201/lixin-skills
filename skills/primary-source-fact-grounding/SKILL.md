# 原始材料事实接地

## R — 原文 (Reading)

> "调查必须参照原始文本，到现场充分确认。"
>
> — 大岛祥誉，《麦肯锡工作法》第3课

## I — 方法论骨架 (Interpretation)

判断越重要，越不能只靠被加工过的信息。
二手资料、媒体报道、AI 摘要和转述观点都可以作为线索，但不能直接充当事实底座。
先列出当前结论依赖哪些关键事实，再为每个事实寻找更接近源头的材料：原始文本、官方口径、现场观察、一手访谈、原始数据或可复核记录。
同时核对定义、时间、样本、采集方式和加工过程。
如果拿不到一手材料，也要明确写出替代证据、限制和不确定性，而不是假装已经核实。
它的目的不是"多查资料"，而是让假设和行动接到可追溯事实上。

## A1 — 书中的应用 (Past Application)

### 案例 1: 咖啡店早晨招徕顾客
- **问题**: 作者想判断早晨如何吸引顾客，单看市场信息不够。
- **方法论的使用**: 到现场与顾客交谈、观察顾客、统计店铺前人流量，再结合顾客意见和接待感触验证假说。
- **结论**: 原始材料能发现一般市场信息看不到的顾客需求和分店假设。
- **结果**: 作者产生了借鉴便利店分店战略开设咖啡店分店的想法。

### 案例 2: 物流仓库调查
- **问题**: 物流相关问题缺少所需数据。
- **方法论的使用**: 作者前往仓库，花三天了解出入库情况。
- **结论**: 对关键问题，现场原始数据比二手资料更能支撑判断。
- **结果**: 调查获得了可用于验证问题的第一手材料。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 方案、文章、汇报或创业判断引用了 AI 总结、媒体报道、二手研报或传闻。
2. 数据口径、样本、时间范围、定义或采集方式不清。
3. 用户要决定是否相信某个行业趋势、客户需求、竞品结论或增长机会。
4. 关键结论会影响投入、定价、招聘、投资、产品路线或公开表达。
5. 用户想把调研从"网上搜一圈"升级为现场、一手访谈或原始数据验证。

### 与相邻 skill 的区分

- 与 `issue-hypothesis-logic-tree-loop` 的区别: 逻辑树负责提出关键假设；本 skill 负责判断这些假设需要什么原始材料来验证。
- 与 `sky-rain-umbrella-action-chain` 的区别: 空雨伞从事实推行动；本 skill 先确认事实能不能站住。
- 与一般搜索/资料整理的区别: 本 skill 必须输出事实分层、源头证据、口径限制和停止条件。

## E — 可执行步骤 (Execution)

1. **列关键判断**
   - 把用户的方案、文章或决策拆成 3-7 个必须为真的事实判断。
   - 完成标准: 每个判断都能写成"如果它错了，结论会受影响"。

2. **给来源分层**
   - 标注每个判断目前来自一手材料、原始文本、官方/原始口径、二手资料、AI 摘要、传闻还是经验直觉。
   - 完成标准: 所有二手或不明来源都被显式标红。

3. **设计接地动作**
   - 为高影响、高不确定的判断找到更接近源头的证据：原始报告、法规原文、数据表、客户访谈、现场观察、后台记录、合同原文或实验日志。
   - 完成标准: 每个接地动作有来源路径、采集方法、样本范围和合法权限说明。

4. **核对口径**
   - 检查定义、时间、地域、样本、采集方式、加工过程和遗漏。
   - 完成标准: 能说明这个事实适用于什么范围，不适用于什么范围。

5. **更新结论等级**
   - 把结论标为已核验、部分支持、待验证、不可验证或被推翻。
   - 完成标准: 输出可引用事实、不可引用材料、限制声明和下一步。
   - 停止条件: 一手材料成本超过决策价值、权限不合法或隐私风险不可控时，停止采集并披露限制。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 只是低风险闲聊、创意发散或不需要事实严谨性的草稿。
- 事实已经有清晰原始来源，用户只需要表达、排版或结论先行。
- 获取一手材料需要越权、侵犯隐私、绕过系统权限或接触商业秘密。
- 用户要求用单一事实证明复杂因果时，本 skill 只能标注证据等级，不能承诺因果成立。

### 作者在书中警告的失败模式

- 依据二手信息制定战略，而信息本身可能遗漏、被编辑或错误。
- 只看一般市场信息，无法发现新假设。
- 不确认信息加工过程或定义，就把公开材料当作原始事实。

### 作者的盲点 / 时代局限

- 书中鼓励到现场获取信息，但现实会受到隐私、成本、授权、样本偏差和安全限制。
- 一手材料也可能有观察者偏差，不能因为"亲自获取"就自动视为真相。

### 复盘方式

- 复盘哪些原始材料真正改变了判断，哪些只是增加工作量。
- 记录最容易出错的口径字段，如时间、样本、定义、地域和统计方式。
- 对 AI 摘要和二手资料建立降级标签：线索可以保留，未经核验不得当事实引用。
