# 十点读书账号排版规范

数据口径：7,751 篇互动加权 top 80% 训练稿；holdout 不参与规则生成。

## 正文节奏范围

- 成稿常态 2,300–3,194 字，中位约 2,672 字；题材复杂度决定长度，不能机械补足。
- 每千字 29.6–37.6 个自然段，中位约 33.7。
- 单篇段落长度中位数通常 25–32 字；不是“一句一段”的命令。
- 20 字及以下短段占比通常 19.5%–33.8%，连续短段常见 2–5 段。
- 超过 5 个连续短段时，检查是否把同一事实链、解释链、案例或方法拆碎；同一功能应合并。
- 数字分节、粗体小标题和图片共同承担换气。没有明确分节需要时，不为追求模板硬加 `一二三`。

## 强调与图片

- 粗体强调常态约每千字 3.9–8.8 处；强调对象应是本节判断、关系变化或关键事实，不是每句金句化。
- 图片常态约每千字 3.7–5.1 张。没有真实图片时输出“配图建议”，不得编造截图、聊天记录、网友评论或现场照片。
- 图片优先放在：开头建立场景后、长故事换场、观点转折前后、方法清单前后。
- 书影稿优先用有授权的封面/剧照；人物与热点稿先确认版权和隐私；亲子、医疗、未成年人内容不使用可识别隐私图。

## 视觉层级

1. 标题只承担一个主承诺。
2. 开头 3–6 个短段完成“对象—处境—为什么与读者有关”。
3. 每个长案例之后必须有 1–3 段解释，不能连续堆故事。
4. 粗体判断不连续轰炸；相邻两处若功能相同，保留更有推进力的一处。
5. 结尾互动口与商业卡片属于渠道组件，不算正文 DNA；只有用户明确要求时才生成。

## 失败信号

- 普通正文超过一半段落不足 20 字。
- 每个段落长度几乎相同，像机器切片。
- 连续 3 节都用“故事—金句—道理”的同构骨架。
- 用表情、加粗或换行掩盖材料不足。
- 把图片当装饰，和事实/情绪推进没有关系。
