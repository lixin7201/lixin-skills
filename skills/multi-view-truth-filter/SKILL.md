# 多观点真相过滤器

## R — 原文 (Reading)

> 如果你问过3个人，他们都持同一个观点，那就去寻找第4个人，直到出现不同的观点。
>
> — 姜胡说，第二章、第六章

---

## I — 方法论骨架 (Interpretation)

这个方法处理的核心不是“知道更多”，而是把一个模糊问题变成可观察、可验证的行动结构。

拆分事实与预测，主动寻找反例和利益相反者，列出两套竞争解释，再设计能推翻主张的验证。

它的独特性在于：独特处在于把事实—观点审计与主动寻找不同声音合成一个可执行过滤器。

使用时先确认输入和边界，再运行最小步骤；没有证据的地方要标为假设。

输出必须包含下一步、完成标准和停止条件，不能停在口号或概念解释。

## A1 — 书中的应用 (Past Application)

### 案例 1: 达利欧用多位专家意见避免重大误诊路径
- **问题**: 达利欧被初步诊断为可能发展成食管癌，并先后得到切除食管、持续检查等相互冲突的意见。
- **方法论的使用**: 他主动让多位专家交叉会诊，最终组织检查显示没有异常。 案例说明重大决策不能把单一权威意见当成真相，应主动扩展选项并核验。
- **结论**: 该案例为方法提供了真实场景证据，同时保留其条件限制。
- **结果**: 避免沿首个高风险手术方案行动，最终检查未发现异常。

### 案例 2: 李录像调查记者一样研究添柏岚
- **问题**: 李录先以低市净率筛选添柏岚，再读财报验证高资本回报，追查“好生意为何被冷落”，并实地了解控股家族和管理层。
- **方法论的使用**: 疑问逐项解除后才进入买入决策。 作者借此提取出“估值—基本面—低估原因—团队验证”的研究模式。
- **结论**: 该案例为方法提供了真实场景证据，同时保留其条件限制。
- **结果**: 形成作者用于教学的低估值选股完整模式；案例原讲述用于说明李录的投资研究。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **拆分主张**
   - 完成标准: 分别列事实、推断、价值判断和表达包装

2. **审计来源**
   - 完成标准: 标注一手/二手、利益关系、时间和可核验性
   - 判停条件: 若关键输入无法取得或风险超过授权范围，停止推进并转为补证/求助。

3. **主动找异议**
   - 完成标准: 找到至少一个机制不同或利益相反的可信来源

4. **设计推翻条件**
   - 完成标准: 写出什么证据会改变结论，并据此给出暂定判断

### 整体验收与停止

- **完成标准**: 四步均有可检查产物；事实、假设与建议分开；用户能直接执行下一步。
- **停止条件**: 输入不足、越过专业/安全/资金授权边界、用户拒绝关键验证，或继续行动将不可逆时，停止并明确缺口。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 无争议的简单事实查询、时间极紧的低风险选择，或把所有观点错误地当成同等可信。
- 只有主题词相似、但没有 A2 所列任务与触发信号时，不要激活。

### 作者在书中警告的失败模式

- 因为同一观点被很多人重复、又符合情绪，就把它当成事实。 重复提高熟悉感，情绪迎合降低审查意愿，群体共识替代了证据。

### 作者的盲点 / 时代局限

- 观点数量不等于证据质量；科学共识不能被一个低质量反方自动抵消。

### 容易混淆的邻近方法论

- `proven-pattern-transfer` 与 `case-to-method-pattern`：先比较目标产物、输入证据和停止条件，再决定调用哪个。
