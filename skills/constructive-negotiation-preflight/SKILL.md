# 建设性谈判预案

## R — 原文 (Reading)

> "谈判定义为'达成提高彼此满意度的方案的过程'。"
>
> — 高杉尚孝，序章

## I — 方法论骨架 (Interpretation)

谈判前不要只准备一个想要的价格或一句强硬话。  
这个方法要求先写清己方目标、最低可接受条件、谈崩后的 B 计划、对方可能的真实关切，以及 3 个以上可交换替代方案。  
建设性不是软弱让步，而是在保护己方利益的同时寻找更高满意度的方案。  
若对方行为已经进入欺诈、胁迫、骚扰、违法或安全风险，建设性谈判停止，改为留痕、退出、求助或专业处理。

## A1 — 书中的应用 (Past Application)

### 案例 1: 求职者用 B 计划保护谈判力
- **问题**: 求职谈判如果只有一个选择，就容易被对方条件牵着走。
- **方法论的使用**: 作者用求职者是否有其他选择说明 B 计划的价值。
- **结论**: 谈崩后的替代方案决定底线和谈判力。
- **结果**: 有 B 计划时，谈判者不必把成交本身当成唯一目标。

### 案例 2: 航班取消后主动主张补偿
- **问题**: 航班取消后，旅客若只沉默接受安排，权益可能受损。
- **方法论的使用**: 旅客明确提出住宿费、餐费、电话和交通补偿。
- **结论**: 合理主张是建设性谈判的一部分。
- **结果**: 展示"沉默不是金"在权益保护中的意义。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 客户要求降价、供应商要求预付款、合作方提出新条件。
2. 要谈薪资、合同范围、付款、交付、资源或时间安排。
3. 不想得罪对方，但又不想被单一条件压住。
4. 谈判前没有底线、B 计划和替代方案。

### 语言信号

- "客户要求降价 30%，我怎么谈?"
- "我的底线怎么设?"
- "B计划/BATNA 怎么准备?"
- "negotiation preflight / constructive negotiation"

### 与相邻 skill 的区分

- `negotiation-real-intent-listening` 用于谈判中追问表面要求背后的利益；本 skill 用于上桌前准备。

## E — 可执行步骤 (Execution)

1. **写己方四件套**
   - 目标、最低可接受条件、不可让步边界、谈崩后的 B 计划。
   - 完成标准: 每项都是可判断条件，不是"尽量好"。

2. **写对方关切假设**
   - 价格、风险、现金流、时间、面子、内部审批、责任、长期关系。
   - 判停条件: 若对方存在威胁、欺诈、违法或拒绝留痕，停止谈判预案，转安全/法律/组织支持。
   - 完成标准: 至少 3 个对方真实关切假设和要验证的问题。

3. **生成替代方案**
   - 至少 3 个组合: 价格/范围/期限/付款/保障/试点/退出条款。
   - 完成标准: 每个方案都说明对己方和对方的好处、成本和不可接受点。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 欺诈、骚扰、威胁、人身安全、违法合同、强权压迫或无法自由退出。
- 高金额合同、劳动争议、税务、法律、医疗等事项需要专业意见。
- 对方拒绝书面留痕或持续改变条件时，不继续靠善意协商。

### 作者在书中警告的失败模式

- 没想清谈崩后怎么办，只能被对方条件牵着走。
- 因害怕冲突而沉默，不表达合理主张。

### 作者的盲点 / 时代局限

- 原书偏商务管理与面对面谈判，平台交易、跨境合规和弱势劳动者场景需重新核验。
- "双方满意"不适用于对方目标是控制、剥削或规避责任的场景。

### 容易混淆的邻近方法论

- B 计划是谈崩后的自保路径；替代方案是谈成更好的可交换选项。
- 建设性不是妥协一切，而是有底线、有证据、有退出。
