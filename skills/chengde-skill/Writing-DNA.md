# Writing-DNA

> 补齐说明：本文件只做承德新鲜工作室现有 DNA 的总索引，不新增、不改写账号、类型或小编写稿 DNA。执行时仍以被索引文件的原文规则为准。

## 六层映射

| 层级 | 本 skill 已有承载文件 | 使用方式 |
|---|---|---|
| L1 表层语言 | `账号语言底线.md`、`小编风格/事儿哥-DNA.md` | 先守事实和语言底线，再按稳定小编线补充口语、短判断和情绪强度。 |
| L2 文章结构 | `文章结构模板.md`、`账号排版规范.md`、`文稿类型/*DNA.md` | 先按账号排版和主类型正文结构组织，不把所有类型揉成一个模板。 |
| L3 选题逻辑 | `账号选题判断框架.md`、`文稿类型/*DNA.md` | 先判断承德本地人群、事实锚点、读者收益和类型路线。 |
| L4 素材策略 | `账号总风格.md`、`文稿类型/*DNA.md` | 只使用用户提供或可核验的现场、截图、公告、价格、时间、当事人说法和官方来源。 |
| L5 认知框架 | `账号总风格.md`、`账号选题判断框架.md` | 保持“本地事实 + 强判断 + 人味叙事”的账号判断方式。 |
| L6 视觉风格 | `账号排版规范.md`、`文章结构模板.md` | 图片和截图作为事实节点、现场感或情绪转折，不作纯装饰。 |

## 执行读取顺序

1. 先读 `账号总风格.md`、`账号选题判断框架.md`、`账号语言底线.md`。
2. 再读 `文章结构模板.md` 和对应 `文稿类型/*DNA.md`。
3. 用户指定 `事儿哥` 时，再叠加 `小编风格/事儿哥-DNA.md`。
4. 原味/高保真请求时读 `原味指纹.md`。
5. 诊断时读 `像不像判别器.md`。
6. 终稿去 AI 味时读 `去AI味保真补丁.md`。

## 禁止覆盖

- 不用本文件替代任何已有 DNA 文件。
- 不把多类型稿合成平均模板。
- 不把样本不足小编强行写成稳定个人 DNA。
- 不为了补齐格式而发明新标题、句式、素材习惯或认知结论。
