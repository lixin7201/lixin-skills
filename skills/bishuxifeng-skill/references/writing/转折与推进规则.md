# 转折与推进规则

训练集 101/101 篇都有因果、条件、转折和设问装置。可迁移的是推进关系，不是连接词数量。

## 六种有效推进

### 1. 追问推进

从结果问到变量：发生了什么 → 为什么第一解释不够 → 哪个变量控制结果 → 如何验证。连续问句不得停在情绪。

### 2. 否定重构

先承认表面解释覆盖的部分，再补出遗漏变量。比固定“不是 X，而是 Y”更自然：

> 努力当然有用。问题是，努力没有进入真实反馈时，它只能证明投入，不能证明能力。

### 3. 换层级

从个人动作抬到产品、行业或制度，再降回个人位置。每次抬高后必须回答“这对当前读者改变了什么”。

### 4. 换角色

依次看决策者、执行者、付费者、受益者、风险承担者和否决者。换位用于重算账本，不用于断言动机。

### 5. 条件/反事实

用“如果关键支持消失，结论是否还成立”检查依赖；用“哪些信号出现就改判”避免事后解释。

### 6. 类比回落

抽象机制 → 新鲜日常场景 → 明确映射与失配 → 回原问题。类比之后仍需事实或验证。

## 转场句库

- “可这只解释了结果，没有解释谁承担成本。”
- “把时间拉长一层，账会变。”
- “换到付费者的位置，再算一次。”
- “这里先别猜动机，看实际投入。”
- “如果这个前提拿掉，结论还剩多少？”
- “换句话说，真正可验证的是……”
- “说到这里，还差一个边界。”

同一篇不要重复同一句式；转场句若没有改变观察层级、角色、时间或证据状态，直接删掉。

## 编号和小标题

- 长稿用编号标记论证阶段，不给每个短段加小标题。
- 同级事实/案例合并到一个小节，避免 AI 式碎片化。
- 小标题优先是问题或变量，不是“背景介绍、深度分析、总结建议”。
- 结构可以不对称：关键部分更长，边界可以单列短段。
