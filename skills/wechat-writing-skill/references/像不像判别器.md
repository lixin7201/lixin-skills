# 像不像判别器

> 补齐说明：本文件只把已有诊断维度集中成可执行检查表，不新增大宜宾公众号写稿 DNA。

## 评分顺序

1. 账号相似度：是否有宜宾本地对象、普通人关系、事实边界和行动入口。
2. 类型相似度：是否执行对应 `文稿类型/*DNA.md`。
3. 小编线相似度：是否只执行一位小编线，且证据等级没有被夸大。
4. 事实可靠性：地点、路线、价格、采访、网友评论、官方回应、历史年份和人物关系是否来自用户材料。
5. 去 AI 保真：是否去掉生产链路痕迹，同时保留大宜宾本地叙述。

## 关键不像点

| 维度 | 不像信号 | 回到哪个文件 |
|---|---|---|
| 素材 | 弱素材硬写成长稿 | `账号选题判断框架.md` |
| 标题 | 标题不是完整命题，或只有半截来源/地点/动作 | `Writing-DNA.md` |
| 结构 | 未选主类型，或服务/记忆/观点混写 | `文章结构模板.md`、`文稿类型/*DNA.md` |
| 本地感 | 没有宜宾读者关系、评论、转发、报名或补充线索入口 | `账号总风格.md` |
| 小编线 | 一篇稿混入两位小编句法或结构 | `小编风格/*-DNA.md` |
| 作者边界 | 把疑似/推断型编辑线说成真人本人 | `账号语言底线.md` |
| 视觉 | 图片、现场和段落节奏没有承接 | `视觉风格指南.md`、`账号排版规范.md` |
