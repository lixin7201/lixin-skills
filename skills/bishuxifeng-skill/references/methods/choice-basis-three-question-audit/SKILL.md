# “基于什么选择”三问审计

## R — 原文（Reading）

> 遇到任何选择题，你都问自己，该不该，能不能，爱不爱。
>
> — 碧树西风，BXSF-061 · 2024-01-29

> 选择不是重点，基于什么选择才是。
>
> — 碧树西风，BXSF-116 · 2026-05-07

## I — 方法论骨架（Interpretation）

1. 不要从 A/B 标签开始，而要先列选择所依据的目标、概率、资源、期限和限制。
2. ‘该不该’检查责任、规则和对他人的影响；‘能不能’检查能力和资源证据；‘爱不爱’检查是否愿意承受过程与较坏结果。
3. 三者常不一致。决策的核心是明确放弃什么，而不是寻找没有代价的完美选项。
4. 内部判断不能先骗过自己；证据不足时应做小验证或保留未知，不替用户拍板。

## A1 — 语料中的应用（Past Application）

### 案例 1：人事窗口前的情绪离职

- **问题**：作者转述同事因眼前不公离职，并判断半年后可能出现晋升窗口。
- **方法论的使用**：把短期情绪、能力、机会窗口与可承受等待分别审计。
- **结果与证据边界**：反事实晋升没有发生，作者判断不能当确定事实。
### 案例 2：无法复制前交易员

- **问题**：作者自述即使每日交流，也无法复制对方的年龄、资产、性格和目标。
- **方法论的使用**：选择不能脱离选择者的条件，同一动作对不同人不是同一决策。
- **结果与证据边界**：财务结果未披露。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 skill？

1. 重要 A/B 选择陷入摇摆
2. 喜欢与合适冲突
3. 责任、能力和意愿不一致
4. 别人成功路径是否适合自己

### 语言信号

- “我该选喜欢的还是合适的”
- “这两个工作到底选哪个”
- “别人这样成功，我是不是也该做”
- “我知道应该做，但我不想做”

### 与相邻 skill 的区分

- 与 `cycle-endgame-optionality-map` 的区别：三问澄清选择者条件，周期 skill 再检查长期选项。
- 与 `bottleneck-time-allocation` 的区别：选择目标后，用兄弟 skill 把资源集中到当前瓶颈。

## E — 可执行步骤（Execution）

1. **写选择依据**
   - 完成标准：列出目标、期限、概率、资源、约束和未知项。
   - 判停/转向：只剩选项名称、没有依据时不得比较。
2. **问该不该**
   - 完成标准：写出责任、法律伦理、对他人影响和必须承担的代价。
   - 判停/转向：伤害或违规无法消除时排除该选项。
3. **问能不能**
   - 完成标准：用过去交付、资源、时间和最坏情景检验可行性。
   - 判停/转向：只有自信或自卑标签时设计小验证。
4. **问爱不爱**
   - 完成标准：区分结果幻想与过程体验，说明较坏结果是否仍愿意承担。
   - 判停/转向：短暂念头未经代价检验时降权。
5. **声明取舍并验证**
   - 完成标准：写出选择、放弃项、触发复审条件和最小可逆实验。
   - 判停/转向：无法接受任何放弃时先不做不可逆承诺。

## B — 边界（Boundary）

### 不要在以下情况使用

- 替用户决定价值排序
- 低成本日常选择
- 用‘爱’覆盖法律责任或对他人伤害

### 作者在语料中警告的失败模式

- 选择时拒绝承认取舍
- 把一时念头当长期理想
- 把选择当不改变自己的中奖彩票
- 用标准化二选一处理非标问题

### 作者盲点与证据局限

- 三问会压缩复杂情境，必要时增加事实调研和多方沟通
- 作者部分性别与阶层例子带有概括性偏见，不可沿用其标签

### 统一安全边界

- 这是从公开文章中提炼的方法，不代表作者本人对新问题的真实意见。
- 不复制作者亲历，不冒充作者，不把自述案例当作独立核验事实。
- 涉及时效事实、法律、医疗或财务高风险问题时，先获取当前可靠资料并明确不确定性。
