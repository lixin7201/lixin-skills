# 财务自由存活期检查

## R — 原文 (Reading)

> 财富就是支撑一个人生存多长时间的能力，或者说，如果我今天停止工作，我还能活多久？
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸穷爸爸》第3章

## I — 方法论骨架 (Interpretation)

这个方法把“富有”从面子、收入和净值数字，改成停止主动收入后的存活时间。
核心指标是: 非劳动现金流或可动用安全资金，能覆盖当前必要支出多久。
它适合做转型、创业、学习投入和生活方式选择前的安全边界。
它不要求人立刻退休，而是要求每个行动都能增加自由月数，或至少不让自由月数失控下降。

## A1 — 书中的应用 (Past Application)

### 案例 1: 1985无家可归到1994财务自由
- **问题**: 罗伯特和金没有稳定工资，生活压力极大，但目标不是找回传统安全感。
- **方法论的使用**: 他们围绕资产现金流和自由时间推进，而不是只追求更高工资。
- **结论**: 自由不是高收入瞬间，而是资产现金流能覆盖生活支出的状态。
- **结果**: 书中叙述他们在1994年达到财务自由。
### 案例 2: 现金流游戏中的老鼠赛跑
- **问题**: 高收入玩家仍可能无法跳出老鼠赛跑，因为支出和负债同步扩大。
- **方法论的使用**: 游戏把资产收入、支出和被动收入覆盖率可视化。
- **结论**: 自由阈值取决于现金流覆盖，不取决于职业光鲜度。
- **结果**: 玩家通过报表练习识别自己需要改变的现金流结构。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户问自己是否可以辞职、创业、长期学习或减少主动工作。
2. 用户想设定财务自由、安全垫、转型缓冲期指标。
3. 用户把高收入误认为自由，需要改成覆盖率判断。

### 语言信号 (用户的话里出现这些就应激活)

- "我还能撑多久"
- "财务自由差多少"
- "被动收入够不够"
- "能不能辞职"
- "安全垫怎么算"

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **确认口径**
   - 操作: 区分必要支出、弹性支出、债务最低还款和一次性风险。
   - 完成标准: 支出被分成必要、可削减、风险三类。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **计算自由月数**
   - 操作: 用现金安全垫加稳定非劳动净现金流，除以必要月支出。
   - 完成标准: 得到当前可存活月数和缺口。
 3. **找增量路径**
   - 操作: 列出三条能增加自由月数的动作: 降低固定支出、增加资产现金流、延长主动收入 runway。
   - 完成标准: 每条都有责任人和时间点。
 4. **设停止线**
   - 操作: 若自由月数低于底线，暂停高风险创业、杠杆或大额消费。
   - 完成标准: 停止线被写成明确数字。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户想获得具体投资标的或收益率承诺时。
- 用户有紧急债务、医疗、法律危机时；先处理危机和专业支持。

### 作者在书中警告的失败模式

- 把高工资、房产估值或融资到账当作自由，而忽略支出和债务。
- 在自由月数不足时做不可逆创业或高杠杆决策。

### 作者的盲点 / 时代局限

- 作者用自由月数做强启发，但没有替代保险、家庭责任、签证、医保和行业风险评估。
- 被动收入稳定性必须按真实数据验证，不能只用理想收益率。

### 容易混淆的邻近方法论

- 与 `asset-liability-cashflow-audit` 的区别: 本 skill 看整体自由月数，不判断单个对象的资产负债属性。
- 与 `cashflow-quadrant-income-map` 的区别: 本 skill 算结果指标；后者看收入来源和迁移路径。
