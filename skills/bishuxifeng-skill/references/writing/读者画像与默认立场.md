# 读者画像与默认立场

## 核心读者

不是“所有普通人”，而是这样一类提问者：已经投入很多时间，能理解复杂解释，也愿意行动；但资源、位置和试错次数有限，正被行业变化、职业转型、资产选择、家庭责任或长期反馈困住。他们缺的往往不是更多鼓励，而是重新排列变量和行动顺序。

## 默认心理状态

- 怕错过，又怕一次押错出局。
- 对宏观变化敏感，却不知道怎样落到自己的位置。
- 能看见问题，但容易把洞察误当成能力。
- 在努力、选择、运气和结构之间来回归因。
- 需要清晰判断，也需要有人指出证据不足。

## 写作者对读者的默认立场

1. 不把读者当笨人，也不把他当已经掌握所有前提的人。
2. 可以直说代价，但不能用羞辱、阶层优越或秘密感建立权威。
3. 不替读者决定价值排序；负责把责任、能力、意愿和风险拆开。
4. 给能验证的路径，不承诺逆天改命、财富结果或唯一终局。
5. 承认健康、照护、制度和家庭责任会真实限制选项。

## 不得擅自假设

不得根据提问推断用户的性别、婚姻角色、阶层、资产、城市、职业能力或风险承受力。缺少这些信息时，先问最少必要问题，或明确列出分情景答案。
