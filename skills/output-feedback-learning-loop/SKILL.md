# 作品反馈学习闭环

## R - 原文依据

> 只要紧盯“输出”这个目标，输入端的质量就会发生变化。

来源：周岭《认知觉醒：开启自我改变的原动力》，第四章第二节：深度学习；第五章第三节：输出。本 Skill 依据已抽取文字版、候选卡片和 Stage 1.5 验证记录生成，不凭记忆使用。

## I - 解释

- 学习的关键不是看懂，而是能否在真实场景中产出并接受反馈。
- 输出目标会倒逼输入筛选，让读书、听课、练习变得更有方向。
- 反馈要尽量来自作品、用户、读者、测试或真实任务，而不是自我感觉。

## A1 - 案例与反例

正例：
- 刘传从输入转向产出，把学到的内容做成作品并获得反馈，学习效率显著变化。
- 作者强调写作和讲述能迫使知识重新组织，暴露理解漏洞。

反例：
- 看了很多书和课程，却没有任何可被别人检查的产出。
- 只追求公开发布数量，不接受有效反馈，也会变成另一种表演。

## A2 - 迁移与边界

适合调用的触发条件：
- 学习一门技能超过两周，仍没有一个作品或可测试结果。
- 读完一本书只剩摘要，没有改变任务、文章或行为。
- 创业想法停留在想象，没有原型、访谈或付费反馈。
- 写作只在本地反复修改，从不让目标读者看。

不适用或需要降级的边界：
- 输出不等于公开表演，早期可以是小范围、匿名或内部测试。
- 不适合尚未获得基础安全知识的高风险技能。
- 反馈必须和目标场景相关，否则会误导迭代。

## E - 执行协议

触发后按以下步骤执行：

1. **定义最小作品**：选择一个小到3天内能完成的产出，如短文、原型、演示、练习题。
2. **限定输入**：只输入完成作品所必需的材料，避免继续泛学。
3. **交给真实对象**：找读者、用户、同事、测试或市场行为给反馈。
4. **提取一条改进**：只选一条最关键反馈做下一版，避免同时改全部。
5. **形成循环**：设定下一版提交时间，直到达到完成标准或停止条件。

完成标准：
- 有一个可被他人查看、使用或测试的产出。
- 获得至少一条来自真实对象的反馈。
- 完成至少一轮基于反馈的改动。

停止条件：
- 涉及隐私、商业机密或未授权资料时，不公开发布，改用安全小范围反馈。
- 如果反馈对象不是目标用户，不能把反馈当市场结论。
- 当产出已经达到当前阶段目标，停止打磨，进入下一轮学习。

复盘方式：
- 记录每轮输入、作品、反馈、改动和下一版。
- 每月统计学习主题中有多少转成了作品或行动。
- 复盘反馈是否改变了输入质量和问题意识。

## B - 行为化提示

当用户的请求符合触发条件时，先把问题改写为“当前触发是什么、我要获得什么证据、下一步动作是什么”。输出时不要只给励志总结，必须给出可执行步骤、完成标准、停止条件和复盘方式。若请求触及医疗、法律、财务安全、人身安全、严重心理危机或组织权力伤害，先提示边界并转向专业支持、现实求助或低风险准备动作。
