# 正文结构模板

## 结构指标

训练全集每千字约 24.86 个可见块，段长中位 21、P90 107；句长中位 33、P90 92。短块与长推演共存。生成稿不能用“每句一段”模仿短段，也不能抹成整页长段。

## 五种正文骨架

### S1 概念校正链

常见说法 → 两个概念的差别 → 为什么会混淆 → 具体案例 → 行动后果 → 边界 → 更精确的说法。

适合：学习、选择、沟通和价值判断。不要每节都写成“不是 A，而是 B”。

### S2 个人试验链

起点/原判断 → 做了什么 → 观察到什么 → 哪个假设被改写 → 可迁移方法 → 哪些条件不能复制。

适合：用户提供真实经历或公开可核案例。禁止补造过程和结果。

### S3 新结构焦点链

旧身份问题 → 结构真实增量 → 世界优先问题 → 受益者/责任 → 有界试进入 → 保留/桥接/退出。

适合：AI、平台、职业和产品转型。必须外接证据与风险门。

### S4 问答推进链

读者问题 → 初答 → 最强反对意见 → 修正初答 → 再问一层 → 条件化结论。

适合：争议、讲解和长回答。每个问句都要改变论证位置。

### S5 长期选择链

选择对象 → 前提与基准率 → 风险预算 → 短期噪声 → 少干预协议 → 重开/退出条件 → 复盘窗口。

适合：长期项目和一般决策。金融场景只分析过程，不输出买卖建议。

## 变化规则

- 同一骨架连续使用两次后，下一篇必须更换开头动作、材料顺序或结尾落法；
- 列表只承载真正并列的条件、步骤或比较；
- 每 800—1500 字至少出现一次材料—抽象—边界的往返；
- 短段用于转向、问题、直断或余味；事实链、解释链和同级案例合成自然段；
- 章节标题只在长文或教程中启用，经典论说不强制小标题。

## 预警阈值

- 普通正文超过一半段落都 ≤20 字：检查机械碎段；
- 连续 5 个 ≤20 字段落：逐段证明功能不同，否则合并；
- 全文只有一种段长或每节同构：判定模板化；
- 问句只制造气氛、不被回答：回炉。
