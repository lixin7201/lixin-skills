# 现金流象限收入地图

## R — 原文 (Reading)

> 我们做什么不要紧，以何种方式挣钱才最关键。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸财务自由之路》第1章

## I — 方法论骨架 (Interpretation)

现金流象限把人按收入来源分成 E 雇员、S 自雇者/小企业主、B 企业所有者、I 投资者。
它不是身份鄙视链，而是询问: 钱来自自己的时间、自己的专业、别人和系统，还是资本和资产。
迁移象限不是换一个头衔，而是换安全感来源、语言、关系、风险承受方式和能力结构。
这个 skill 的重点是画出现状、目标和代价，不替用户做人生选择。

## A1 — 书中的应用 (Past Application)

### 案例 1: 现金流象限定义四种收入来源
- **问题**: 很多人按职业名称理解自己，却看不清收入到底来自哪里。
- **方法论的使用**: 作者用 E/S/B/I 四格解释工资、自雇、系统所有权和投资收入的差异。
- **结论**: 真正的转变是收入机制变化，而不是名片变化。
- **结果**: 读者可先定位当前主收入，再判断目标象限需要补什么。
### 案例 2: 从无家可归到财务自由的象限迁移
- **问题**: 作者夫妇处在高压力低安全感状态，但目标不是回到雇佣工资。
- **方法论的使用**: 他们把精力放在资产、企业和投资现金流上。
- **结论**: 象限迁移需要现金流、学习、心理和试错同时改变。
- **结果**: 书中把这段经历作为转向右侧象限的核心案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户想知道自己的收入结构属于 E、S、B、I 哪一类。
2. 用户要比较上班、副业、自由职业、创业、投资的下一步。
3. 用户想从亲自劳动转向系统或资产收入。

### 语言信号 (用户的话里出现这些就应激活)

- "我属于哪个象限"
- "从打工到创业"
- "自由职业是不是创业"
- "怎么转到B象限"
- "收入来源太单一"

### 与相邻 skill 的区分

- 与 `s-to-b-system-check` 的区别: 本 skill 先画收入地图；后者专门检查 S 型业务能否系统化为 B。
- 与 `work-to-learn-skill-stack` 的区别: 本 skill 看收入机制；后者看当前工作训练什么能力。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **列收入来源**
   - 操作: 按每项收入的产生机制、占比、稳定性和是否依赖本人时间列清楚。
   - 完成标准: 所有主要收入都有象限候选。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **定位现状**
   - 操作: 把收入放入 E/S/B/I，并标出混合收入和伪装收入。
   - 完成标准: 当前主象限和副象限明确。
 3. **定义目标**
   - 操作: 写出目标象限、想获得的自由、可承受代价和不想牺牲的东西。
   - 完成标准: 目标不是口号，有边界。
 4. **拆迁移台阶**
   - 操作: 选择低风险台阶: 学习、兼职实验、系统化、投资教育、顾问审计。
   - 完成标准: 下一步可在30天内行动。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户只是想听哪个象限更高级，或要求你贬低稳定工作。
- 用户财务安全垫不足却想立即裸辞；先用自由存活期检查。

### 作者在书中警告的失败模式

- 把开店、自由职业或个人 IP 直接当成 B，实际还是本人不在就停。
- 把投资人身份当标签，而没有财务报表、风险控制和信息能力。

### 作者的盲点 / 时代局限

- 四象限是简化地图，现实收入常是混合形态。
- 不同法域、职业、家庭责任和身份限制会影响迁移路径，不能套模板。

### 容易混淆的邻近方法论

- 与 `s-to-b-system-check` 的区别: 本 skill 先画收入地图；后者专门检查 S 型业务能否系统化为 B。
- 与 `work-to-learn-skill-stack` 的区别: 本 skill 看收入机制；后者看当前工作训练什么能力。
