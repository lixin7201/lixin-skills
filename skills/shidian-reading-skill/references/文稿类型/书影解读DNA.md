# 书影解读 DNA

- **适用场景**：用一本书、一部剧、电影或歌曲解释普通人的关系、选择、生存与成长。
- **标题 DNA**：`《作品》：生活判断`；“看懂了《作品》，就搞懂了 X”；热点剧大结局加“你的人生也在其中”。8 篇中 6 篇直接命中“书影对象加判断”。
- **开头 DNA**：一句作品评价/读者感受 → 作品影响力或核心矛盾 → 明确承诺“这部作品将回答什么”。引用/金句开路占 7/8。
- **推进链**：中心命题 → 按人物阶段或 3 个冲突切分剧情 → 每一段剧情后提炼一个生活原则 → 将人物命运映射到读者 → 汇总成可记忆模型 → 祝愿/互动。
- **材料偏好**：作品本身必须占主导；作者背景、改编信息和少量现实映射只能辅助。歌曲路线可用“作品片段—创作者人生阶段—普通人处境”交替推进。
- **段落节奏**：句长中位 29 字，为 11 类最长；短段比例低于账号平均。允许剧情段稍长，但每个段落群只解释一个命题，避免流水账复述。
- **情绪温度**：6/10。沉浸、感慨、反思为主；作品悲剧可以悲，但生活结论通常留出希望。
- **结尾 DNA**：把 2—4 个分论点合成一句生活模型，再回到读者自己的选择。互动可问最喜欢的作品/角色，不必强行点赞。
- **事实核查**：版本、出版/上映信息、人物关系、情节顺序、作者生平、台词出处必须核查；不要混淆原著与改编。歌词和原文只做必要短引，不大段复刻。
- **像 / 不像警告**：像的是“作品为骨、人生判断为肉”；不像的是剧情梗概后突然贴三条鸡汤，或借作品名讲与原作无关的观点。
- **深读样本与置信度**：`3219c1762e745979`《〈凡人歌〉大结局：你的人生未必在剧中，但一定在李宗盛的歌里》、`695f40e53d16192e`《路遥〈人生〉：人生好坏，都藏在你的选择里》、`f0140d4dc9a11dcc`《看懂了〈许三观卖血记〉，就搞懂了普通人的最佳生存法则》、`6a3b65234ab93377`《〈飘〉：最好的爱情，是势均力敌》。**置信度：高**；题材边界、标题和分段机制都最稳定。

> 运行规则：先服从账号总 DNA 与事实门禁；本卡只决定该类型的证据脊柱、情绪曲线和结构差异。
