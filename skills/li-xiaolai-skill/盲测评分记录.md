# 盲测评分记录

## 隔离链

1. `test-prompts.json` 先由用户确认并冻结；
2. 运行包删除 expected traits、forbidden outputs 和 scoring focus；
3. 无 Skill 与带 Skill 执行者使用独立上下文，禁止互读；
4. holdout 先制成匿名题包，执行者在生成前后均看不到原文；
5. A/B 标签按题随机，两名评审看到互补顺序；
6. 评审先冻结逐题结果，再揭示各自映射；
7. 所有运行与评审均为 full test，`dry_run=0`。

## 解释边界

Darwin 结构总分过线不等于相对基线必胜。训练基线本身极强，Skill 绝对完成度高但增加了路由与风格约束，部分题上反而过度处理。holdout 提供了真实泛化增益证据，但仍需通过 Soul 消融和针对 t19 等弱项的 Pareto 回归。
