# 甘蓝蓝路线 DNA

- **最擅长类型**：观点与生活方式、成长疗愈；也能处理健康与书单。统计中观点/生活 282 篇、成长疗愈 155 篇，占其 617 篇的大头。
- **典型切口**：从一本书、一位人物、一句具有解释力的引语或一个身边人的选择切入，把抽象命题落到“一个人如何做得更好”。早期高互动人物稿会把个人命运写成可迁移的人生方法。
- **标题与开头**：标题通常是简洁判断，不特别依赖猎奇；开头偏引用、书中观点或真实生活观察，较少用大段情绪喊话。
- **结构**：生活问题/人物命运 → 两至三个书籍、人物或研究材料 → 定义问题 → 给出方法或价值判断。人物传记稿会沿时间线推进，最后回扣人格力量；观点稿则偏“案例—概念—方法”。
- **句段节奏**：中位约 2,309 字，每千字 25.74 段、段落中位 36 字；明显比账号基线段落更长、更连贯。粗体密度约 13.82/千字，是基线的两倍多，常用粗体承担阶段结论。
- **材料习惯**：书籍最突出，8 篇样本中书籍信号远高于影视、网友等材料；也会用研究、同事故事、名人经历做第二层佐证。
- **情绪强度**：中等。即使写坎坷人物，也常把痛感收束为理性、坚韧、执行或独处能力，不靠持续煽情推进。
- **与账号基线差异**：更书卷气、长段、重粗体结论；篇幅更短，信息连续性更强，整体比账号平均更像“轻知识文章”。
- **误判警告**：不要因为书籍密度高就把所有书摘型稿件归给甘蓝蓝；她的关键不是堆名句，而是让书本材料服务于一个明确、实用的人生命题。人物长稿也不能误判为纯人物故事，通常仍有强方法论落点。
- **证据与置信度**：整体统计 617 篇；训练候选 8 篇；深读 3 篇（含 1 篇早期异常高互动加权样本）。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
