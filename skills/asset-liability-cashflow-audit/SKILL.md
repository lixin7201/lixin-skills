# 资产负债现金流审计

## R — 原文 (Reading)

> 资产是能把钱放进你口袋里的东西。负债是把钱从你口袋里取走的东西。
>
> — 〔美〕罗伯特·清崎；〔美〕莎伦·莱希特等, 《富爸爸穷爸爸》第3章

## I — 方法论骨架 (Interpretation)

这个方法把财务判断从“名字好不好听、价格贵不贵、别人说是不是资产”拉回到现金流方向。
一个对象只要持续把现金、时间、注意力或能力带入口袋，就是候选资产；只要持续拿走这些资源，就先按负债处理。
它不是会计准则，也不是投资估值模型，而是行动前的第一道分类闸门。
迁移到学习、工作、创业和写作时，同样看一个投入是在产生复利，还是在制造更高的固定成本和维护负担。

## A1 — 书中的应用 (Past Application)

### 案例 1: 富爸爸用简图定义资产负债
- **问题**: 罗伯特和迈克还没有会计语言，容易把房子、车和高收入混同为财富。
- **方法论的使用**: 富爸爸用现金流箭头解释资产和负债，让两个孩子看钱是流进口袋还是流出口袋。
- **结论**: 资产与负债先按现金流方向判断，不按社会标签判断。
- **结果**: 这个简图成为五册书反复使用的底层判断尺。
### 案例 2: 把房子、车、消费品重新放回现金流表
- **问题**: 很多中产家庭拥有看似体面的东西，但月供、维护、税费持续抽走现金。
- **方法论的使用**: 书中用财务报表把收入、支出、资产项和负债项分开，暴露现金流真实方向。
- **结论**: 名义资产如果持续吞现金，就不能直接当成自由来源。
- **结果**: 读者被要求先积累产生收入的资产项，再升级消费。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户在问一个对象“到底算资产还是负债”。
2. 用户准备买房、买车、买设备、买账号、开项目或投入学习，但没有算持续现金流。
3. 用户收入提高却觉得更不自由，需要判断资源到底流向哪里。

### 语言信号 (用户的话里出现这些就应激活)

- "这个算资产还是负债"
- "值不值得买"
- "是不是投资"
- "现金流怎么看"
- "买了会不会拖累我"

### 与相邻 skill 的区分

- 与 `financial-freedom-runway-check` 的区别: 本 skill 判断单个对象或项目的现金流属性；后者计算整体自由覆盖率。
- 与 `good-bad-debt-screen` 的区别: 本 skill 不以债务为中心；债务进入时才用后者细判谁还款、最坏损失和停止条件。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

 1. **列出对象**
   - 操作: 写清对象、购买/投入成本、维护成本、预期收入、占用时间和退出方式。
   - 完成标准: 对象边界明确，不把多个东西混成一团。
   - 判停条件: 若缺少关键事实，先向用户索取或标注假设，不继续给强结论。
 2. **画现金流**
   - 操作: 把每月流入、流出、一次性成本、沉没成本和隐性时间成本分栏。
   - 完成标准: 能看出净流入或净流出，而不是只有口头判断。
 3. **分类**
   - 操作: 正现金流且可持续、可审计的列为候选资产；负现金流或只能靠升值想象的列为候选负债。
   - 完成标准: 每个分类都有数字或可验证事实支撑。
 4. **设行动**
   - 操作: 资产候选进入小额验证、维护和复盘；负债候选进入延迟、砍成本、寻找资产支付或放弃。
   - 完成标准: 有下一步动作、完成标准和复盘日期。
   - 判停条件: 若出现法律、税务、医疗、证券投资或债务危机，停止给具体方案并建议专业支持。

### 完成标准

- 已给出一个明确分类、路径、排序或下一步实验，而不是泛泛建议。
- 已写明关键事实、假设、风险、停止条件和复盘指标。
- 若涉及钱、债务、税务、法律、证券或房地产，已提醒需要按当前地区和真实数据复核。

### 复盘方式

- 记录本次判断所依据的事实与假设。
- 在 7-30 天后检查行动是否发生、指标是否改善、风险是否扩大。
- 若结果偏离预期，把偏离原因写成下一次可检查规则。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要具体买哪只股票、哪套房、哪种币或具体收益预测时；那需要外部实时资料和专业判断。
- 用户问正式会计、税务、法律分类时；本书定义不是当地法规。

### 作者在书中警告的失败模式

- 把会升值、很体面、别人都买的东西直接叫资产，却不看净现金流。
- 把一次性收入、想象中的转卖收益或面子价值当作稳定现金流。

### 作者的盲点 / 时代局限

- 作者把资产/负债定义简化为现金流方向，便于行动，但不等同于会计准则。
- 房地产、杠杆和税务收益高度依赖城市、利率、法域和个人现金流，需要重新核验。

### 容易混淆的邻近方法论

- 与 `financial-freedom-runway-check` 的区别: 本 skill 判断单个对象或项目的现金流属性；后者计算整体自由覆盖率。
- 与 `good-bad-debt-screen` 的区别: 本 skill 不以债务为中心；债务进入时才用后者细判谁还款、最坏损失和停止条件。
