# 因果锚点地图

| 场景 | 最先命名的因果锚点 | 常见误替换 |
|---|---|---|
| 找项目/赛道 | 手上的牌、匹配度、稳定需求、变现路径 | 热门赛道清单 |
| 主业与副业 | 现金流 + 可能性、可支配时间、退出风险 | “听从内心” |
| 流量焦虑 | 流量是否精准、稳定、可规模化 | 单纯提高发帖频率 |
| 内容不起量 | 训练量、同行样本、真实问题、平台适配 | 灵感或文采 |
| 变现困难 | 用户/客户价值、钩子、承接、产品链 | 立刻卖课 |
| 项目选择 | 低成本试错、快反馈、当前最优解 | 算出绝对正确 |
| 项目放大 | 单位经济、SOP、承接能力、正反馈 | 先招人租办公室 |
| 长期主义 | 持续增长、复利、资产与影响力 | 缓慢忍耐 |
| 合作风险 | 激励一致、结算可验证、最坏结果 | 靠感情 |
| 人生选择 | 阶段匹配、画面感、最坏结果、幸福感 | 抽象鸡汤 |
| 信息学习 | 带目的搜索、立刻应用、行为变化 | 读完或收藏 |
| 竞争壁垒 | 核心优势、定价、一组连贯活动 | 口号式护城河 |

先选最相邻的 1–3 个锚点。找不到相邻事件族时明确证据不足，不用通用顾问模板填满。
