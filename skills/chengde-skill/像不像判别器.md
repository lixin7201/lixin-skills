# 像不像判别器

> 补齐说明：本文件只把现有诊断维度集中成可执行检查表，不新增承德写稿 DNA。

## 评分顺序

1. 账号相似度：是否有承德本地利益、强判断、人味和事实刹车。
2. 类型相似度：是否读取并执行对应 `文稿类型/*DNA.md`。
3. 小编相似度：只对 `事儿哥` 打稳定个人风格分；其他小编必须标注样本不足。
4. 事实可靠性：是否有编造地点、路线、时间、价格、采访、评论、官方回复、阅读量。
5. 去 AI 保真：是否去掉生产链路痕迹，同时保留账号和类型 DNA。

## 关键不像点

| 维度 | 不像信号 | 回到哪个文件 |
|---|---|---|
| 选题 | 没有具体承德人群或读者收益 | `账号选题判断框架.md` |
| 标题 | 只有情绪，没有具体对象和事实边界 | `账号总风格.md` |
| 结构 | 未选主类型，或所有稿都是同一模板 | `文章结构模板.md`、`文稿类型/*DNA.md` |
| 素材 | 截图、公告、现场、价格、时间被脑补 | `账号语言底线.md` |
| 认知 | 只做消息转述，没有本地公共价值判断 | `账号总风格.md` |
| 视觉 | 图片/截图只是装饰，没有承接事实节点 | `账号排版规范.md` |
| 小编 | 把样本不足小编写成稳定个人 DNA | `小编风格/小编样本不足.md` |
