# 授权准备度与领导方式匹配检查

## R — 原文 (Reading)

> 布置任务时要确保清晰明确；员工需要真心承诺工作；不仅指员工的能力，还有态度；对工作进行全面控制。
>
> — 《分章节P2-05 领导力和执行力》Slide 12, lines 156-168

> 高能力高承诺、低能力高承诺等状态，对应支持式、教练式、授权式、指令式领导。
>
> — 《分章节P2-05 领导力和执行力》Slide 15, lines 202-259

## I — 方法论骨架 (Interpretation)

授权不是“放手”或“不放手”的二选一，而是根据任务难度、下属能力、承诺状态、资源条件和风险可逆性选择领导方式。能力低但热情高的人需要具体指导；能力低且信心不足的人需要指导加支持；有能力但信心波动的人需要支持；能力和承诺都高的人才适合充分授权。

这个 skill 先检查任务 4C：清晰、承诺、胜任、控制；再判断能力/承诺；最后匹配指令、教练、支持或授权。它还要防止把流程、规则、资源、目标错误都压成“个人执行力差”。

## A1 — 书中的应用 (Past Application)

### 案例 1: 初学者热情高但不会做

- **问题**: 新员工愿意做，但能力低。
- **方法论的使用**: PPT 将其归为 S1/低能力高承诺，建议指导为主、支持为辅。
- **结论**: 此时不应完全放手，也不需要过度情绪支持。
- **结果**: 管理者把成长任务拆成具体步骤和检查点。

### 案例 2: 高能力高承诺员工

- **问题**: 下属已经有能力也有信心。
- **方法论的使用**: PPT 对应 S4 授权式领导，提供资源和信任支持。
- **结论**: 过度管控会降低效率和责任感。
- **结果**: 授权前确认目标、权限、边界和验收即可。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 带新人、布置复杂任务、交接项目或决定是否放手。
2. 下属执行偏差，用户不确定是没听懂、不会做、不想做还是资源不够。
3. 团队需要在个人任务、团队流程和组织规则三层分清责任。
4. 用户想给不同成熟度成员匹配不同管理方式。

### 语言信号

- “我该放手还是盯紧？”
- “新人很积极但不会做”
- “怎么授权不失控？”
- “delegation readiness / situational leadership / 4C”

### 与相邻 skill 的区分

- 与 `communication-understanding-execution-loop` 的区别: 沟通 skill 检查理解与执行闭环；本 skill 检查能力/承诺和授权方式。
- 与 `instruction-coaching-responsibility-split` 的区别: 该 skill 偏责任分配和教练边界；本 skill 偏任务前置准备度和领导风格匹配。

## E — 可执行步骤 (Execution)

1. **检查任务 4C**
   - 完成标准: 写清任务目标、承诺、胜任条件和控制点。
   - 判停条件: 目标、权限、预算、安全或合规边界不清时，不进入授权。

2. **判断问题层级**
   - 完成标准: 标注是个人任务、团队流程还是组织规则问题；组织问题不得压给个人。

3. **评估能力与承诺**
   - 完成标准: 用实际行为、历史结果、训练情况和任务难度判断，不贴人格标签。

4. **匹配领导方式**
   - 完成标准: 低能力高承诺用指令；低能力低承诺用教练；有能力但信心波动用支持；高能力高承诺用授权。

5. **设置授权边界**
   - 完成标准: 明确权限、资源、检查点、升级条件、验收标准和复盘时间。

6. **复盘调整**
   - 完成标准: 根据结果和反馈更新能力/承诺判断，必要时切换领导方式。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 目标本身不合理、资源不足、权限缺失或组织流程有问题。
- 任务高风险且不可逆，不能直接授权试错。
- 用户想用“能力差/态度差”标签替代证据。

### 作者在书中警告的失败模式

- 不看任务层级，把组织规则和团队流程问题归因给个人。
- 布置任务时缺少清晰、承诺、胜任和控制。
- 对不同准备度员工使用同一种管理方式。

### 作者的盲点 / 时代局限

- PPT 未充分展开心理安全、劳动合规和跨文化管理；正式使用时要保留员工申诉和资源协商空间。

### 容易混淆的邻近方法论

- 沟通复述不等于授权成熟；听懂了也可能不会做。
- 支持不是放任，授权不是甩锅。
