# 瑾山月路线 DNA

- **最擅长类型**：书影解读最突出，其次是观点与生活方式；人物传记与女性成长是高识别路线。整体 101 篇中书影解读 49 篇。
- **典型切口**：一位历史/文化人物、一本文学作品或一个反直觉人格命题。通过人物完整命运去证明专注、觉醒、藏锋等人生原则。
- **标题与开头**：标题常为“人物名 + 半生/命运判断”“真正的某类人看起来怎样”或女性觉醒判断。开头偏历史场景、访谈金句或书中人物设定。
- **结构**：戏剧化历史场景/金句 → 人物生平或小说情节 → 2—3 个阶段主题 → 人格命题 → 诗性共勉。比普通观点稿更强调连续叙事和人物弧光。
- **句段节奏**：中位约 3,018 字，每千字 34.01 段、段落中位 29 字；接近基线但稍长。短段占比仅 0.215，叙事连贯性高。
- **材料习惯**：书籍信号压倒性突出；辅以历史资料、影视角色、名人故事。个人身边故事较少。
- **情绪强度**：中高但文学化。用命运起伏、时代压力、女性困境和精神修行制造情绪，而不是靠网络口水战。
- **与账号基线差异**：更文学、更传记化，连续长叙事更多；适合把一本书或一个人物写成精神启示录。
- **误判警告**：不要把任何书影稿都归给瑾山月。她强调“人物弧光 + 一个贯穿始终的精神母题”，不是剧情复述。历史人物事实和文学作品内容必须核验，不能为了戏剧感虚构细节。
- **证据与置信度**：整体统计 101 篇；训练候选 8 篇；深读 3 篇有效正文，另检查 1 篇正文不完整样本并剔除；含 1 篇早期异常高互动加权人物稿。**置信度：中高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
