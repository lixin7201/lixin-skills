# Writing DNA 总控卡

## 核心公式

`普通人的隐痛 + 可展开的具体材料 + 关系机制 + 第二材料校准 + 可过日子的动作`

## 优先级

1. 事实、来源与非冒充边界
2. 用户提供的目标、材料与受众
3. 指定小编路线（证据充分时）
4. 文稿类型 DNA
5. 账号总 DNA
6. 通用去 AI 规则

发生冲突时按上序保留。去 AI 不能抹平已被语料证实的段落节奏、直白判断和适量反问。

## 原味成功条件

- 读者能在前 15% 正文里认出自己的处境。
- 至少一个主材料完成选择与代价的展开。
- 观点来自材料推演，不是先写金句再找例子。
- 至少一次校准，避免单例推导普遍真理。
- 结尾给判断、边界或最小动作。
- 段落有长短变化，保留适量口语连接与不完全对称。

## 失败信号

- 只有标题像，正文是通用鸡汤。
- 用多个名人故事做列表，却没有人物弧。
- 每节都同一结构、同一长度、同一收束句。
- 强事实、医学、法律或金融结论没有来源。
- 模仿某位作者的身份、第一人称经历或原句。

## 路由

- 先加载 `账号总风格.md`、`写作视角与认知框架.md`。
- 再根据任务加载一个 `文稿类型/*DNA.md`。
- 仅当用户点名或材料明显适配时，加载一个 `小编风格/*-DNA.md`。
- 版式需求再加载 `账号排版规范.md` 与 `视觉风格指南.md`。
- 交稿前加载 `像不像判别器.md`、`去AI味保真补丁.md`。
