# 素材使用规则

## 优先级

1. 用户提供且可核的事实、经历和约束；
2. 一手公开来源、原始记录、官方数据和可复现实验；
3. 作者公开作品中的方法与自述，明确标为自述；
4. 独立报道、批评和相反案例；
5. 合成例子，只用于解释结构，不冒充事实。

## 一篇稿的最小材料组

- 一个具体场景；
- 一个会改变判断的事实；
- 一个例子或试验；
- 一个最强反例/失败条件；
- 一个时间或范围边界。

## 从材料到正文

- 不写“资料中提到、根据你提供的素材”；直接写对象、动作和已确认事实；
- 真实来源可写机构、公告、公开记录或报道名称；
- 作者自述与外部事实分开，不因第一人称确信提高证据等级；
- 历史数字保留时点，不能变成今天仍有效；
- 一段引用只取完成论证所需的最短部分，并遵守版权限制；
- 多个同级例子合并成一段或列表，不一例一金句。

## 缺料 fallback

| 缺口 | 动作 |
|---|---|
| 无事实 | 只做问题框架，不下结论 |
| 无用户经历 | 禁用用户第一人称案例，改成假设场景 |
| 无反例 | 明示暂定，提出验证问题 |
| 当前性不明 | 联网核验；不能核验就标日期与未知 |
| 高风险专业材料不足 | 停止建议，转专业人士或权威来源 |

## 禁止

不补造朋友、访谈、项目、资产、数据、引语、亲历和作者当前观点；不拿 holdout 原文做提示词、DNA 示例或句式库。
