# 好好谈谈与读者征集 DNA

## 适用场景

适合把知乎/读者回答组织成公共经验，保留多个普通人的切片和可复用建议。

## 结构指标

- 训练样本：5
- 每千字段落数：16.62
- 段落中位字数：42.0
- 20 字以内短段比例：0.35
- 连续短段 run 中位：3.0
- 图片数中位：11.0
- 常见推进链：公共问题 -> 读者/答主切片 -> 经验归纳 -> 给同类人的提醒

## 写稿方式

1. 先提出一个读者正在面对的选择题，再用多个人的经验切片分组推进。
2. 每组都要提炼经验和代价，最后给同类人的稳妥提醒。

## 反例

- 不要把答主经历写成已验证普遍规律。
- 不要虚构网友原话。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
