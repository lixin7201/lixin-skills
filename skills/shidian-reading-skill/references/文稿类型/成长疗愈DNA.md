# 成长疗愈 DNA

- **适用场景**：疲惫、低能量、焦虑、不配得感、人生停滞、情绪压抑，以及“如何重新动起来”。
- **标题 DNA**：直接点名读者状态并给承诺；常用“致很累的你”“人生建议：别再……”“养好 X，等 Y”“做这 3 件事”。数字承诺是该类最常见标题信号。
- **开头 DNA**：列出 4—6 个日常症状，让读者先完成自我识别；或以一句名言/人物困境起笔。不要第一段就给空泛鼓励。
- **推进链**：症状清单 → 命名问题 → 解释形成机制 → 影视/朋友/自述呈现代价 → 允许脆弱或反转旧认知 → 2—4 个起步动作 → 希望性回收。
- **材料偏好**：当代影视、纪录片、网友/朋友、作者自述与少量心理学框架。材料要服务“从失能到恢复”的变化，不要只收集苦难。
- **段落节奏**：句长中位 24 字；共情句、判断句常独立成段。工具段可编号，但每条必须有具体动作，不写“爱自己、提升认知”式空命令。
- **情绪温度**：7/10。前半承认真实疲惫，中段允许崩溃，后半把能量逐步抬高；不是一直煽情，也不是强迫积极。
- **结尾 DNA**：给一个“今天就能开始”的最小动作，再落到生命力、当下或自我照顾，常用祝愿或提问邀请分享。
- **事实核查**：心理学诊断、治疗建议、百分比效果、纪录片内容、研究结论和名言必须核查。心理困境不能用单一原因解释，更不能替代专业医疗。
- **像 / 不像警告**：像的是先准确描述“你为什么累”，再给小步恢复；不像的是将所有困境归因于“不够自律”，或把治愈写成三步必效。
- **深读样本与置信度**：`f92aa5e0680786d7`《致很累很累的你：人到中年，不想透支自己，千万记得做这3件事》、`2fa84e20b173088a`《一个女人穷惯了，身上会有这3种坏习惯，希望你没有》、`8661db9eeecc4c88`《人生建议：别再过“临时生活”》、`e0db97a71078e3cf`《养好生命力，等人生豁然开朗》。**置信度：高**；四篇都稳定呈现“识别—解释—行动/希望”结构，但书影型长叙事可与本类组合而不应覆盖其疗愈目的。
