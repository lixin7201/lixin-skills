# 苏善书路线 DNA

- **最擅长类型**：观点与生活方式、婚恋关系、热点社会观察；能做强叙事的书影/人物评论。
- **典型切口**：冲突性数据、争议事件、热门电影或社会热梗。先亮出争议双方，再通过具体故事为某一方建立道德和情感正当性。
- **标题与开头**：标题锋利，爱问“谁后悔”、写“他们怕了”、揭开被误解的真相。开头很快给数据或结果，不绕行。
- **结构**：争议/数据 → 多个长故事或电影细节 → 逐条回应反方 → 提炼立场 → 行动号召。婚恋稿会采用三位当事人口述式样本；热点稿常用“先承认局限，再反击批评”的辩论结构。
- **句段节奏**：中位约 3,074 字，每千字 37.62 段、段落中位 24 字，短段占比 0.353；比基线更短、更有鼓点感。反问、断句和单句段推动明显。
- **材料习惯**：影视与书籍都强，网友、新闻、人物故事并用；更重故事冲突和可感细节，而非纯理论。
- **情绪强度**：高。常有愤怒、意难平、同情、女性共鸣和反击感，结尾再转为普通人的力量或理智边界。
- **与账号基线差异**：更锋利、更戏剧化、更擅长论战；短段和粗体结论均高于基线。
- **误判警告**：不要把“立场强”误写成无证据站队。该路线有效之处是先铺事实与具体故事，再表达态度。涉及历史翻案、法律或医学事实时尤其要独立核验，不能把情绪当证据。
- **证据与置信度**：整体统计 192 篇；训练候选 8 篇；深读 3 篇。**置信度：高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
