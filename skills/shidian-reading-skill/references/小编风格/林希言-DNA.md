# 林希言路线 DNA

- **最擅长类型**：观点与生活方式、人际处世、亲子家庭；高互动样本中金钱职场突出。
- **典型切口**：中年安全感、工作态度、值得深交的人等现实判断。常从一个可量化问题或职场案例出发，讨论个人责任、长期积累和可控选择。
- **标题与开头**：标题常用年龄、钱数、最高级判断或“3 个特征”；开头偏提问、两类人对照或直接定义。
- **结构**：现实问题 → 普通人案例 → 反面后果 → 书籍/专家观点 → 2—3 个务实建议 → 共勉。金钱稿会主动修正“钱越多越安全”的单一答案，加入关系、欲望和心态。
- **句段节奏**：中位约 2,421 字，每千字 34.25 段、段落中位 27.75 字；接近账号基线，篇幅略短。用直白判断和案例递进，不追求大量抒情。
- **材料习惯**：身边故事最强，书籍、研究、少量网友和影视作为支撑。故事通常用于证明“今天的选择形成未来筹码”。
- **情绪强度**：中等偏硬。常提醒不要混日子、要存钱、要自律，但也会承认快乐预算、内在安全感与关系托举。
- **与账号基线差异**：更务实、更职业化，个人责任和长期主义更突出；比小嗲少恐惧，比肖肖少热梗，比紫杉多现实权衡。
- **误判警告**：不要把务实写成责备弱者。职场、储蓄和自律建议需说明环境约束，不把失业、贫困或职业停滞完全归因为个人态度。
- **证据与置信度**：整体统计 82 篇；训练候选 8 篇；深读 3 篇（含 1 篇早期异常高互动加权样本）。**置信度：中高**。

> 身份边界：这是语料署名形成的写作路线，不证明真实身份、雇佣关系或单一自然人作者。
