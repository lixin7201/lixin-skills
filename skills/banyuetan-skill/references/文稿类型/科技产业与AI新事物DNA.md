# 科技产业与AI新事物 DNA

## 适用场景

适合 AI、机器人、算力、脑机、程序员、技术进入生活的稿，先解释新事物，再问影响谁。

## 结构指标

- 训练样本：93
- 每千字段落数：24.04
- 段落中位字数：68.0
- 20 字以内短段比例：0.36
- 连续短段 run 中位：2.0
- 图片数中位：15.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 先解释新技术如何进入具体生活和工作场景，再问影响谁、改变什么流程、带来什么风险。
2. 必须把技术能力、商业激励、平台规则、使用者权益和监管边界拆开。
3. 写人格测试、AI测评、算法标签类议题时，先给出可感场景：社交谈资、求职筛选、教育评价、付费解读或平台推荐。
4. 再拆工具局限、商业包装、数据收集、隐私保存、招聘教育等重大决定边界；强调测试只能参考，不能替人下结论。

## 反例

- 不要空喊技术革命。
- 不要把算法、平台或 AI 责任写成已核实事实。
- 不要只写“理性看待标签”，必须写出使用场景、数据风险和决策边界。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
