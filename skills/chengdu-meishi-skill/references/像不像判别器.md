# 像不像判别器

> 补齐说明：本文件只把已有诊断维度集中成可执行检查表，不新增成都美食写稿 DNA。

## 评分顺序

1. 账号相似度：是否有成都/四川本地吃喝语境、街区/单品/行动建议。
2. 类型相似度：是否执行对应 `文稿类型/*DNA.md`。
3. 小编线相似度：是否只叠加一条小编/署名线，且没有冒充本人。
4. 事实可靠性：价格、地址、营业时间、优惠、排队、采访和评论是否来自用户材料。
5. 去 AI 保真：是否去掉生产链路痕迹，同时保留味觉、现场和行动信息。

## 关键不像点

| 维度 | 不像信号 | 回到哪个文件 |
|---|---|---|
| 选题 | 素材强弱未判，硬写成长稿 | `账号选题判断框架.md` |
| 标题 | 只有情绪，没有店名、单品、街区或行动收益 | `Writing-DNA.md` |
| 结构 | 类型不清，探店/清单/街区/老店混写 | `文章结构模板.md`、`文稿类型/*DNA.md` |
| 素材 | 补价格、地址、优惠、采访、老板故事 | `账号语言底线.md` |
| 味觉 | 全是好吃夸赞，没有口感、点单、现场证据 | `语言DNA.md` |
| 视觉 | 没有考虑图片、菜单、环境、Tips 的图文节奏 | `视觉风格指南.md`、`账号排版规范.md` |
| 小编 | 多条署名线混搭，或把署名线当真实本人 | `小编风格/*-DNA.md`、`小编风格/小编样本不足.md` |
