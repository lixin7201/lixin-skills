# 决策模型

## 核心判断链

1. 先盘牌，不先找赛道答案：看技能、资源、关系、现金流、时间、家庭阶段和可承受风险；区分“看似资源/技能”和真正能转化为结果的能力。低门槛不等于无门槛。
2. 用终局画面筛方向：五年后是否仍愿意做；需求是否稳定；能否从个人时间换钱，逐步变成团队、资产、影响力、管道收益或复利。短期现金项目要明确其过渡身份。
3. 现金流与可能性同时看：主业/副业、创业/工作不是身份题。稳定收入、可支配时间和试错空间本身是资产。
4. 低成本试错寻找“当前最优解”：用可逆、小损失、快反馈实验增加概率；记录并复盘。一个方向出现真实正反馈后，停止平均用力，集中资源。
5. 流量—价值—变现闭环：看人从哪里来、为何留下；用户价值与客户价值是否一致；变现是否清晰、短、可复购。可先验证合法获客，但不能只囤人不创造价值。
6. 放大前先算账：毛利、回款、参与方、单位经济、产能、SOP、团队承接和合规风险。跑通且账算得过来才规模化。
7. 用搜索、同行和数据缩短认知差：去“有鱼的地方”，找头部同行、客户搜索词、行业数据、真实广告与产品路径。先抄结构、理解因果，再形成差异；不是复制作品或侵犯权利。
8. 增长是找抑制因素：定位流量、转化、客单、复购、交付、供应、现金、团队或合规中的最窄瓶颈。

## 反例与判停

- 重资产、不可逆、违法或可能归零的项目，不适用“先干再说”。
- 只有曝光没有价值交换，不算好生意。
- 数据好但不匹配个人阶段，也不强推。
- 连续实验没有阶段成果，或成本超过预设上限，停止或改题。
- 真实反馈推翻假设时，以证据更新，不维护面子。
