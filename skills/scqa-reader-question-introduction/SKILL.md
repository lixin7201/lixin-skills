# SCQA 读者问题序言

## R — 原文 (Reading)

> 叙述式的序言说明了发生冲突的背景，以及冲突引发的疑问，而这个疑问正是你的文章将要回答的。
>
> — 芭芭拉·明托，《金字塔原理》第2章

## I — 方法论骨架 (Interpretation)

SCQA 不是“开头写背景”的模板，而是把作者想说的话接到读者已经在意的问题上。
S 是读者已知并能接受的背景；C 是背景中发生的变化、矛盾或困扰；Q 是读者因此自然会问的问题；A 是正文顶端答案。
好的序言让读者感到“这正是我要问的”，而不是被作者拖进一堆铺垫。
如果序言包含读者不知道或不相信的信息，读者会先质疑背景，正文答案就失去入口。

## A1 — 书中的应用 (Past Application)

### 案例 1: 董事会备忘录
- **问题**: 原备忘录直接列董事会组成、角色、任期等议题，读者不知道为什么要讨论。
- **方法论的使用**: 明托先写新机构接管日常事务、董事会需要转向长期战略这一背景与冲突，再提出三项变革建议。
- **结论**: 序言先建立“为什么现在必须讨论”的问题感。
- **结果**: 议题清单变成了变革建议。

### 案例 2: DDT 文件数字化系统
- **问题**: 原研究目的含糊，没有抓住委员会关心的可行性问题。
- **方法论的使用**: 用旧流程 7-10 天邮寄和新流程一小时电子传送的对比，引出“低成本电子文件传输系统是否可行”。
- **结论**: 流程改造类序言应从旧流程问题和新流程可能性引出疑问。
- **结果**: 研究入口从技术介绍转成决策问题。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 写报告、提案、汇报、邮件、演讲开头，担心读者不知道为什么要看。
2. 开头像背景堆叠、项目介绍或目录播报，但没有引出问题。
3. 用户已经有一个答案，但不知道如何让读者自然接受这个答案的入口。
4. 要把客户问题、流程变化、市场变化写成有说服力的开场。

### 语言信号

- “这个报告开头怎么写”
- “帮我用 SCQA 写序言”
- “怎么引出这个建议”
- “读者为什么要关心这件事”
- “situation / complication / question / answer”

### 与相邻 skill 的区分

- 与 `conclusion-first-pyramid-report` 的区别: 本 skill 只负责序言入口和读者第一个问题；结论先行负责整份内容的顶端答案和支撑结构。
- 与 `problem-definition-r1-r2-diagnostic-tree` 的区别: SCQA 可把已界定的问题写成开头；R1/R2 用于问题本身还没界定清楚。
- 与 `horizontal-grouping-logic-check` 的区别: SCQA 管背景、冲突、疑问、答案；横向检查管正文同层要点。

## E — 可执行步骤 (Execution)

1. **确认读者已知背景 S**
   - 写 1-3 条读者已经知道、承认或容易验证的事实。
   - 完成标准: 每条背景都不需要在序言中额外证明。
   - 判停条件: 如果背景对读者有争议，先补证据或换成更稳的共同事实。

2. **写出冲突 C**
   - 找出变化、异常、机会、约束或矛盾，让背景不再稳定。
   - 完成标准: 冲突能自然让读者停下来问“那怎么办/意味着什么”。

3. **定位读者问题 Q**
   - 把冲突引发的问题写成一句读者会问的话。
   - 完成标准: Q 不是作者想讲的主题，而是读者为了行动或判断必须知道的事。
   - 判停条件: 如果同一读者可能有多个 Q，拆分受众或先问清主读者。

4. **给出答案 A**
   - 用一句完整判断直接回答 Q，并作为正文金字塔顶端。
   - 完成标准: A 和 Q 一一对应；读者不需要猜作者答案。

5. **压缩成自然开头**
   - 根据场景把 S/C/Q/A 写成显式四段或自然一段，短邮件可压缩但不能省略答案。
   - 完成标准: 读者读完开头能复述“背景是什么、变化是什么、作者要回答什么、答案是什么”。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 读者背景未知，且无法判断他是否承认 S。
- 用户需要的是全文结构、根因分析或 PPT 单页检查，而不是开头。
- 文案目标是制造悬念、情绪或品牌记忆，不要求立即给答案。

### 作者在书中警告的失败模式

- 序言放入读者不知道或不信的内容。
- Q 是作者想讲的问题，不是读者真实会问的问题。
- 冲突和答案不匹配，导致正文答非所问。

### 作者的盲点 / 时代局限

- 标准 SCQA 假设读者愿意顺着逻辑读下去，对权力、利益和传播场景考虑不足。
- 当读者并不认可共同背景或问题定义时，序言需要更多事实校准。

### 复盘方式

- 让目标读者只看序言，说出他以为正文要回答的问题；若不等于 Q，重写 S/C。
- 检查 A 是否直接回答 Q；若 A 只是相关内容，回到问题定位。
