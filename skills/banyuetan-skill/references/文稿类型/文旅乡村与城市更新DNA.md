# 文旅乡村与城市更新 DNA

## 适用场景

适合县城、乡村、社区、文旅、城市治理、地方产业，突出一个地方如何被看见和改变。

## 结构指标

- 训练样本：22
- 每千字段落数：30.0
- 段落中位字数：65.5
- 20 字以内短段比例：0.46
- 连续短段 run 中位：2.0
- 图片数中位：14.0
- 常见推进链：地方/对象开场 -> 做法展开 -> 变化解释 -> 可复制经验

## 写稿方式

1. 从一个地方、一个场景或一个具体做法开头，写它如何被看见和改变。
2. 中段写资源、产业、治理、游客体验和本地生活之间的关系。
3. 写地方文旅出圈时，必须区分传播门槛、公共承载、产品链条、收益分配、居民参与、复游率和口碑沉淀。
4. 把流量转化写成产业能力：交通住宿卫生投诉等基础承载，文化体验和特色产品延长消费链，本地商户和居民真实受益。
5. 结尾讲可持续条件，不只夸流量。

## 反例

- 不要写成景区软文。
- 不要只写出圈热闹。
- 不要把短期客流直接等同于稳定收入和持续就业。
- 不要写成新华社通稿式材料堆叠。
- 不要写成自媒体情绪宣泄。
- 不要把所有类型都套成同一个三段论；必须保留本类型的材料入口和推进链。
