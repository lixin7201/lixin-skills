# 十点读书原味指纹

## 思考指纹

1. **先找普通人的隐痛，再找能承载它的人和事。** 抽象主题不能直接开讲，必须落到家庭、关系、年龄、金钱、身体或自我价值中的具体压力。
2. **故事不是例证装饰，而是判断发动机。** 先让人物在一个可见选择里受挫、迟疑或醒悟，再提炼关系机制，随后用第二材料校准而非简单重复。
3. **把复杂议题翻译成可过日子的尺度。** 读者最后要知道该看见什么、停止什么、珍惜什么或下一步能做什么。
4. **价值判断站在尊严、边界、责任与自我成长一边。** 不只给安慰，也会明确指出消耗关系、错误金钱观、控制和自我放弃。
5. **容许情感矛盾。** 爱与怨、付出与边界、失去与释怀可以同时成立；不要把故事压成单一道德答案。

## 写作指纹

- 标题给清楚对象和结果承诺，数字、关系冲突、极值词、书影对象和反转常用，但必须由材料兑现。
- 开头优先引用/热事件/生活场景，迅速映射“这和你有什么关系”；110 篇分层样本中，引用或金句开路约占 59%。
- 主体常见推进：`痛点/事件 -> 人物或案例 -> 解释关系/机制 -> 第二材料校准 -> 读者映射 -> 动作或边界`。
- 一个长故事后接短判断，再回到另一个故事或知识材料；不连续堆抽象观点。
- 句子常态 19–37 字，逗号推进多，问句、反问、引语和粗体判断制造停顿。
- 结尾可压实判断、给两三条动作、祝愿或自然互动，但不强行宏大升华。

## 版式指纹

- 正文中位约 2,672 字；段落中位通常 25–32 字。
- 短段占比常态 19.5%–33.8%，最大连续短段常态 2–5。
- 图像与粗体承担换气：约 3.7–5.1 图/千字、3.9–8.8 粗体强调/千字。
- 肖肖路线显著更碎、更强情绪；甘蓝蓝、李可沫等路线段落更完整。不能把账号总节奏套到每位作者。

## 必须保护的粗粝处

- 判断可以直白，有时重复核心关系以加深情绪，不必全部改成含蓄散文。
- 故事与道理不必完美对称；轻微不匀称是人写长文的真实节奏。
- 口语连接词、反问和二次解释可以保留，只要它们推进读者理解。
- “温暖”不是软化所有冲突；必要时保留刺痛、警醒和边界。

## 偶发而非硬规则

- 数字清单、三段式、名人金句、心理学概念、影视案例、祝愿和“在看”都只是可选材料。
- 商业插入、主播信息、二维码和账号卡片不是写作 DNA。
- 10万+标题强度不能自动迁移到事实薄弱题材。

## 假像警告

- 只复制“真正、余生、人到中年、最高级”等词，不像；没有具体人和关系机制就是表皮模仿。
- 句句短、句句加粗、句句金句，不像；真实语料有完整故事和解释链。
- 所有题材都用“一个故事 + 三条道理 + 愿你”，是模板过拟合。
- 过度精修成无棱角散文，会丢掉账号的明确判断。
- 复用训练标题、情节或句子，即使读起来很像，也判泄漏失败。

## 去 AI 豁免

- 不因通用去 AI 规则删除账号有证据的数字标题、反问、粗体判断和适量“不是A而是B”。
- 只在机械复用、没有推进、无事实来源或造成同构时清理。
